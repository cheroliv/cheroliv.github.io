پڑھنے کا وقت : 8 minutes

ہفتوں دو پہلے، میں نے لانچ کیا`capsule-gradle`— ایک پلاگین جو ڈیک کو تبدیل کرتا ہے reveal.js کے ساتھ WebM ویڈیو کیپسول میں TTS. آج، میں ایک نئی پلاگین شامل کر رہا ہوں: hyperframes-gradle. وہ کچھ کرتا ہے جو capsule-gradle نہیں کرتا : AsciiDoc کو مستقیم MP4 ویدیو میں تبدیل کریں، reveal.js سے गुज़ے بغیر۔

یہاں یہ پلاگ ان کیوں موجود ہے، اور یہ موجودہ نظام کے ساتھ کیسے منسلک ہے، اور HeyGen کے HyperFrames انجن محتوا کی تولید کے پائپ لائن میں کیا لاتا ہے؟

ویڈیو پائیپ لائن میں خلا

میرے دستاویزی پائیپ لائن دو قسم کے ویڈیوز بناتی ہے :

  1. کپسول تجدید نظر (capsule-gradle) — ایک ڈیک reveal.js ویب ام میں کپچر کیا گیا کے ساتھ

ناریشن ٹی ٹی ایس. موڈیول دوبارہ دیکھنے کے لیے مناسب۔

  1. Slides d’animation (slider-gradle) — ایک deck reveal.js HTML متاعمل کے لئے

پہلا use case اہم ہے : خودکارانہ طور پر کیسے بنائیں 60 سیکنڈ کی ویڈیو جو ایک پروژے یا ماڈیول کو دکھاتی ہے، GSAP انیمیشنز کے ساتھ narration TTS, اور موسیقی پس منظر — تمام چیزیں اسی فائل AsciiDoc سے اسلائڈز کے بارے میں ?

Capsule-gradle جواب نہیں दे سакتی ہے: اسے déjà ایک reveal.js ڈیک درکار ہے۔ slider-gradle اس ڈیک کو اچھی طرح پیدا کرتا ہے، لیکن اس کا ڈیزائن ویڈیو رینڈرنگ کے لیے نہیں ہے۔ ضروری تھا ایک direct پائلائن : AsciiDoc → ویدیو۔

HyperFrames : انجن

میں نے دریافت کیاhttps://github.com/heygen-com/hyperframes[ہائیپر فریمز] il y a کئی دن۔ یہ ایپاچی 2.0 (آپیشن-سورس) فریم ورک ہے جو ہیجن نے بنایا ہے، AI ویڈیو کی ایکورن۔ GitHub پر 22 700 ستارے۔ پچ میں ہے ایک جملہ :

HTML لکھیں۔ ویدیو رینڈر کریں۔ ایجنٹس کے لیے بنایا گیا.

اصول : آپ HTML لکھتے ہیں ساتھ`data-*`خصوصیات، آپ حوالہ دے رہے ہیں ایک GSAP انیمیشن (یا CSS، Lottie، Three.js…)، اور انجن سب کچھ MP4 میں render کر دیتا ہے via Puppeteer (headless Chrome) + FFmpeg. نتیجہ معیاری : وہی input, ایک جیسے فریم، ایک جیسے ویڈیو

<div id="stage" data-composition-id="intro" data-start="0" data-width="1920" data-height="1080">

         src="background.mp4" muted playsinline></video>

  <h1 id="title" class="clip" data-start="1" data-duration="4" data-track-index="1">

HyperFrames Remotion سے کیسے مختلف ہے؟ React نہیں، Bundler, JSX نہیں۔ راؤ HTML جن کو AI ایجنٹس فطری طور پر لکھ سکتے ہیں۔ یہ میرا پائپ لائن کے لیے بالکل موزوں ہے : planner-gradle ساتھ deepseek یہ HTML SPG/SPD کے منصوبے سے بنایا جا سکتا ہے، اور ایک Gradle پلاگین۔ یہ اسے MP4 میں تبدیل کر سکتا ہے۔

AsciiDoc DSL

پلاگ ان کی سچی اضافہ‑قیمتی AsciiDoc DSL ہے۔ صارف وہ کبھی بھی HTML نہیں لکھتا۔ وہ اپنے موجودہ AsciiDoc دستاویز پر نوٹس شامل کرتا ہے:

:hyperframes-width: 1920
:hyperframes-height: 1080
:hyperframes-fps: 30

[hyperframes-composition, id="intro"]
== Introduction

Le titre apparaît avec un fondu GSAP sur fond vidéo.

[hyperframes-track, index=0, start=0, duration=6]
video::assets/background.mp4[muted, playsinline]

[hyperframes-track, index=1, start=1, duration=4]
Formation Docker & Kubernetes

[hyperframes-animation, type=gsap]

docinfo کیخصوصیات (:hyperframes-width:) بعدے کی ابعاد طے کرتے ہیں۔ کاستم بلاکس ترکیب اور ٹریک کا تعین کرتے ہیں۔ بلاک `[hyperframes-animation]`یہ GSAP کا خام کود شامل ہے — جسے AI ایجنٹ طبيعتی زبان کی وضاحت سے بن سکتا ہے۔

Node.js بریج

صرف تکنیکی رکاوٹ : HyperFrames Node.js/TypeScript میں ہے, اور میرے پلاگ‑ان Kotlin/JVM میں ہیں۔ حل ایک`ProcessBuilder`:

class RenderHyperframesTask : DefaultTask() {

    @TaskAction
    fun render() {
        val process = ProcessBuilder(
            "npx", "hyperframes", "render",
            "--input", inputHtml.absolutePath,
            "--output", outputMp4.absolutePath
        )
            .inheritIO()
            .start()

        val exitCode = process.waitFor()
        require(exitCode == 0) {
            "HyperFrames render failed with exit code $exitCode"
        }
    }
}

صفر جوڑ JVM ↔ Node.js کا کوڈ. قرارداد کمانڈ لائن کے ذریعے ہے. اور ڈسک پر فائلوں۔ یہ وہی پيٹرن ہے`plantuml-gradle` (جس پلانٹ یو امیل سی ایلی بلاتا ہے) یا`slider-gradle`(جو AsciidoctorJ کو بلاتا ہے). شمس کے نیچے کچھ نیا نہیں — صرف ایک نئے اوزار پر لاگو کیا گیا۔

وہ ایک دوسرے کی جگہ نہیں لیتے۔ وہ ایک دوسرے کو مکمل کرتے ہیں۔ پوری قدر کی زنجیر :

AsciiDoc ──→ slider-gradle ──→ deck reveal.js ──→ capsule-gradle ──→ WebM (کیپسال ترمیم)

یہ کیوں کام کرتا ہے

تین وجوہات :

  1. HyperFrames "agents کے لئے بنایا گیا" ہے میرا پائلپ لائن AI ایجنٹس پر مبنی ہے

(planner-gradle + deepseek) materiaal paida karte hain. HyperFrames qabul kartā hai. خام HTML — وہ فॉرمет جو LLMs سب سے بہتر سمجھتے ہیں۔ React نہیں، نہیں JSX کا نہیں، ایجنٹ کے لیے سیکھنے کا منحنی نہیں.

  1. AsciiDoc DSL فطری ہے. میرا کامل ایکوسسٹم AsciiDoc بولتا ہے۔

slider-gradle, codex-gradle, training-gradle — سب یہ استعمال کرتے ہیں`.adoc`. کاسٹوم بلاکس شامل کریں`[hyperframes-composition]`ایک اِکٹینشن ہے منطق، ایک ٹوٹ نہیں.

  1. Node.js برچ یک ثابت کردہ نمونہ ہے. ProcessBuilder JVM کے باہر،

یہ وہی چیز ہے جو میں پہلے سے PlantUML, Graphviz, Piper کے لیے کرتا ہوں۔ HyperFrames شامل کریں معمارتی میں کوئی تبدیلی نہیں لاتا — یہ صرف ایک بیرونی آلہ ہے Gradle سے چلایا جاتا ہے۔

پٹرن کی سچائی طاقت یہ ہے کہ اس میں کسی بھی NPM کا انحصار نہیں Gradle بناؤ۔ پلاگ ان Node.js کوڈ داخل نہیں کرتا۔ یہ ایک شل کا کمانڈ. اگر HyperFrames تبدیلی کرتا ہے یا ٹوٹ جاتا ہے، پلاگین جوڑا نہیں ہے — کماند کو اپ ڈیٹ کرنا کافی ہے۔

نتیجہ: ناکامل جوڑ

hiperframes-gradle ke saath, mera video pipeline mukammal hai. Mere paas:

  • یہ انٹریکٹیو سلیڈز (slider-gradle)

  • یہ capsules de révision (capsule-gradle)

  • ال ویڈیوز اسٹینڈالون (hyperframes-gradle)

تین فارمیٹ۔ ایک ہی سورس فائل: AsciiDoc.

اگلا هدف HF-1 ہے: پلاگن کو کمپائل کریں اور پیدا کریں پہلا HTML HyperFrames ایک ملاحظے شدہ AsciiDoc دستاویز سے۔ سیشن 001 پہلے سے فریم میں ہے.

hyperframes-gradle موجود ہے۔ گورننس موجود ہے۔ بی‌کلگ یہ لکھا گیا ہے۔ معماری درج شدہ ہے۔ پلاگین پیدا ہوا ہے۔
