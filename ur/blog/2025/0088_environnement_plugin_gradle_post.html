مقدمہ

مقرر شدہ منتخب: گریڈیل پلاگین بنانے میں شروعات کرنے خواہش رکھنے والے ڈویلپرز

Gradle پلاگ‑ains کو مؤثر طور پر ڈویلپ کرنے کے لیے، ایک اچھی طرح سے کنفیگر کردہ ڈویلپمنٹ ماحول ضروری ہے۔ ایک اچھی سیٹ اپ آپ کو وقت بچائے گی، تناؤ کو کم کرے گی اور آپ کے بنائڈز کی تناسق کو یقینی بنائے گی۔

۔یہ گائیڈ چار بنیادی ستونوں پر مرکوز ہے :

  1. Le JDK(Java Development Kit)، چون Gradle اور JBake JVM پر چلتے ہیں۔

  2. Un IDEمودرن (IntelliJ IDEA) جس میں Kotlin اور Gradle کا اچھی طرح سے سبورٹ ہے

  3. Gradleخود، پروژات کو شروع کرنے کے لیے۔

  4. JBake, ہماری ستٹیک سائٹ کا انجن.

ترقیاتی ماحول کے اجزاء
@startuml
!theme plain
node "ڈویلپر کی مشین" {
  component "JDK (JVM)" as JDK

  Gradle --> JDK : utilise
  JBake --> JDK : utilise

1. JDK: Gradle کا انجن

Gradle ایک ایپلیکیشن ہے جو Java Virtual Machine (JVM) پر چلتا ہے۔ لہٰذا، JDK کی ان stalation ایک مطلق پیش شرط ہے۔

کون سی ورژن چنیے؟

Java کی LTS (Long-Term Support) ورژن استعمال کرنے کی سفارش کی جاتی ہے۔ حاضراً,JDK 17 ou JDK 21بہترین اختیارات ہیں۔

Installation via SDKMAN! (موصوفہ)

SDKMAN! ایک شاندار آلة ہے جو众多 SDKs کے وژن منظم کرنے کے لیے استعمال ہوتی ہے، جاوے اور گریڈیل شامل ہیں۔

SDKMAN! Install کریں

curl -s "https://get.sdkman.io" | bash source "$HOME/.sdkman/bin/sdkman-init.sh"

JDK کا ایک ورژن انسٹال کریں

# Pour lister les versions de Java disponibles sdk list java

# Pour installer Java 17 (par exemple, la distribution Temurin)
sdk install java 17.0.8-tem

تنصیب کی جانچ

java -version

آپ کو وہ ورژن جو آپ نے ابھی انسٹال کی ہے دکھائی دینے چاہیے۔

2. ایڈی ای : IntelliJ IDEA

گرےڈل پلاگینز کے لئے ڈیولپمنٹ، Kotlin DSL کے ساتھIntelliJ IDEAیہ انتخاب کا آلہ ہے۔ اس کا انٹیگریشن گریڈیل اور كوتلن کے ساتھ بے نظیر ہے۔

  • کامیونٹی ایڈیشن :مفت اور کافی زیادہ شروع کرنے کے لیے

  • اٹلیمیٹ ایڈیشن :ادا شدہ، ویب ڈیویلمنٹ اور ڈیٹابیس کے لیے ایڈوانس فیچرز فراہم کرتی ہے۔

JetBrains کی ویب سائیٹ سے آپ کے لیے مناسب ورژن ڈاؤنلوڈ کریں: https://www.jetbrains.com/idea/download/

IDE خود بخود آپ کے فائلز کا Discover کرے گا`build.gradle.kts` et settings.gradle.kts, آپ کو طاقتور خود-کمل، کوڈ نویگیشن اور انٹیگریٹڈ ڈیبگنگ ٹولز فراہم کرتا ہے۔

3. گریڈل : بنڈائلنگ آلات

ہر پروجیکٹ گرڈیل ورپر کے ذریعے اپنیخصوصی ورژن استعمال کرے گا، لیکن گرڈیل کی global انسٹالیشن رکھنا مفید ہے، نئے پروجیکٹس کو شروع کرنے جیسے کاموں کے لیے (gradle init).

SDKMAN! کے ذریعے انسٹالیشن

جیسے JDK کے ساتھ، SDKMAN! Gradle کی انسٹالیشن آسان کرتا ہے۔

Gradle انسٹال کریں

sdk install gradle

انسٹالیشن جانچ کریں

gradle -v

یہ کمانڈ Gradle, Kotlin, Groovy اور JDK کے استعمال ہونے والی ورژن دکھائے گی۔

4. JBake : اسٹیک سائٹ جینیریٹر

JBake وہ ٹول ہے جو ہم اپنے ماخذ فائلز (جیسے اس) کوStatic ویب سائٹ میں تبدیل کرنے کے لیے استعمال کریں گے۔ مقامی انسیٹالیشن رکھنا تغیرات کی پیش‌نمائش کرنے میں مفید ہے۔

SDKMAN کے ذریعے نصب!

دوسری ٹولز کی طرح، SDKMAN! سب سے آسان طریقہ ہے۔

JBake انسٹال کریں

sdk install jbake

تنصیب کی جانچ

jbake -v

یہ کمانڈ JBake کی ورژن اور اس کے استعمال ہونے والی Java ماحول کی معلومات دکھائے گی۔

5. Gradle Wrapper : مطلق اچھی عمل

جیسے ہی آپ کا پروجيکٹ بن جاتا ہے (جس پر ہم اگلے مضامین میں بات کریں گے)، آپ بعد یہ عالمی کمانڈ استعمال نہ کریں۔gradle. جگہ کے بجائے، آپ اسے استعمال کریں گےGradle وریپر(./gradlew), ایک اسکرپٹ شامل آپ کے پروژیکٹ میں.

کیوں؟

  • قابلِ تجدید :Wrapper یقینی دلاتا ہے کہ پروجیک پر کام کرنے والی ہر شخص (آپ کے CI/CD سرور شامل)بالکل استعمال کرتا ہےGradle کی ایک ہی ورژن, اس سے مختلف ماحولات کی وجہ سے بنانے کے غلطی ختم ہو جاتی ہیں۔

  • سادگی :پروجیکٹ میں حصہ لینے کے لیے گریڈل کو دستیاب طور پر انسٹال کرنے کی ضرورت نہیں۔

صرف ریپازٹری کلون کر کے chalāein`./gradlew`.

ایک عام کمانڈ اس طرح دکھائی دے گا :

# Ne pas faire : gradle build
# À faire :
./gradlew build

6. ڈاکر اور پورٹینر : ریپروducible بنائید (اختیاری)

اگرچہ انہیں ایک پلاگ‑ان لکھنے کے لیے سख़्त طور پر ضروری نہیں ہے، ڈاکر اور پورتینر modern DevOps آلات ہیں جو قابل تجدید بنائوں کی پیدا آوری اور آپ کے ماحول (environment) کی انتظام میں بڑی مدد دیتے ہیں۔

ڈاکر انجن کا نصب

Docker آپ کو اپنی ایپلیکیشن اور اس کی dependencies ایک کینٹر میں پک کرنے کی اجازت دیتا ہے۔

الرسمی اسکرپٹ کے ذریعے ڈاکر انسال کریں :

curl -fsSL https://get.docker.com -o get-docker.sh sudo sh get-docker.sh

ڈاکر کو sudo کے بغیر (موصیے) :

اپنے صارف کو گروپ میں شامل کریں`docker`.

sudo usod -aG docker $USER
docker run hello-world

Portainer (GUI) کے ساتھ Docker کا انتظام

Portainer ایک ہلके وزن کا ویب انٹرفیس ہے جو آپ کے ڈاکر کنٹینرز کو منیج کرنے کے لیے استعمال ہوتی ہے۔

پورٹینر کے ڈیٹا کے لیے ایک وولوم بنائیں:

docker volume create portainer_data

Portainer کنینر چلائیں :

docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:latest

آب ابھی پورتینر انٹرفیس پر رسائی حاصل کر سکتے ہیں`https://localhost:9443`.

نتیجہ

آپ کا ماحول اب تیار ہے! آپ کے پاس ایک JDK، سب سے موزوں IDE، Gradle اور JBake موجود ہے۔ ڈاکر کے شامل ہونے سے، آپ کینٹرائزڈ اور قابلِ تکرار بنانے کے لیے بھی تیار ہیں۔ یہ مضبوط بنیاد آپ کو صرف ضروری چیزوں پر توجہ مرکوز کرنے کی اجازت دے گی: طاقتور اور مفید پلیگنس کی ترقی۔

اگلے مضمون میں، ہم کوامند استعمال کریں گے`gradle init`پہلا پلاگین پروجیکٹ کی ڈھانچہ بنانے کے لیے
