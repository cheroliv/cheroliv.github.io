مسئله: NAT اور خفیہ پتے

مسئلہ : آپ اپنے Ubuntu مشین پر ویب ایپلیکیشن ڈویلپ کر رہے ہیں اور اسے اپنے گھر کے نیٹورک کے باہر سے可 رسائی بنانا چاہتے ہیں؟ آپ صحیح جگہ پر ہیں! اس مضامین میں، ہم دیکھینگے کہ کس طرح ایک مقامی سروس (جیسے پورٹ 8080 پر) کو انٹرنے پر نمایاں بنانے کے لیے اپنے انٹرنیٹ باکس پر پورٹ فوروارڈنگ کنفیگر کی جاتی ہے۔

ڈیفالٹ طور پر، آپ کی انٹرنیٹ باکس NAT (Network Address Translation) استعمال کرتی ہے تاکہ ایک ہی پبلک IP پتے کو آپ کے گھر کے نیٹ ورک کے تمام ڈвайسز کے درمیان شریک کیا جائے۔ آپ کے مقامی مشین خصوصی IP पतوں (192.168.x.x, 10.x.x.x وغیرہ) استعمال کرتی ہیں جو انٹرنیٹ پر روٹبل نہیں ہیں۔

آپ اپنی اوبونٹو مشین پر ایک سروس چلاتے ہیں (مثلاً پورٹ 8080 پر ایک ویب سرور)، یہ صرف آپ کے مقامی نیٹ ورک سے قابل رسائی ہے۔ اس سے انٹرنیٹ سے رسائی حاصل کرنے کے لیے، ہم پورت فوروارڈنگ کو کنفیگر کریں گے۔

مرحلہ 1: اپنی عوامی IP آدرس کی شناخت کریں

سب سے پہلے، اپنے انٹرنیٹ کنکشن کا عام IP پتہ دریافت کریں :

# Plusieurs méthodes au choix
curl ifconfig.me
curl ipecho.net/plain
wget -qO- http://ipecho.net/plain

# Ou encore
curl -s checkip.amazonaws.com

یہ IP پتہ وہ ہے جو انٹرنیٹ استعمال کرنے والے آپ کی سروس تک رسائی کے لیے استعمال کریں گے۔

مرحلہ 2 : اپنی اوبونٹو مَشین کے مقامی IP پتے جانیں

آپ کی Ubuntu مشین کا مقامی نٹ ورک پر ایک خصوصی IP پتہ ہے۔ جاننے کے لیے :

# Afficher toutes les interfaces réseau
ip addr show

# Ou plus spécifiquement pour l'interface principale
ip route get 1.1.1.1 | awk '{print $7; exit}'

# Alternative avec hostname
hostname -I | awk '{print $1}'

یہ پتا نکالیں (مثلاً`192.168.1.100`), ہم اس کی ضرورت سیٹاپ کے لیے ہوں گے۔

مرحلہ 3: پورٹ فوروارڈنگ کنجگر آپ کے باکس پر

کانفیگریشن آپ کے باکس کے مودل کے مطابق بدلتی ہے، لیکن اصول ایک جیسا رہتا ہے:

اداری انٹرفیس تک رسائی

اپنی براؤزر کھولیں اور اپنے باکس کی ویب انٹرفیس پر جائیں:

  • Freebox:`192.168.1.1` ou mafreebox.freebox.fr

  • Livebox Orange:`192.168.1.1`

  • ایس ایف آر باکس : 192.168.1.1

  • Bbox Bouygues : 192.168.1.254

ری ڈائریکشن کی کنفیگریشن

مرحلہ 4 : اوبونٹو پر خدمت کی تنظیمات

پتہ کریں کہ آپ کی سروس تمام انٹر فیسز پر سن کر رہی ہے، صرف لوکال ہوسٹ پر نہیں:

# ✅ Correct : écoute sur toutes les interfaces
python3 -m http.server 8080 --bind 0.0.0.0

# ❌ Incorrect : écoute seulement en local
python3 -m http.server 8080 --bind 127.0.0.1

پتہ کرنے کے لیے کہ آپ کی سرویس صحیح طریقے سے سن رہی ہے :

# Vérifier les ports en écoute
sudo netstat -tlnp | grep :8080
# ou avec ss (plus moderne)
sudo ss -tlnp | grep :8080

آپ کو کچھ جیسا دیکھنا چاہیے`0.0.0.0:8080`اور نہیں`127.0.0.1:8080`.

مرحلہ 5: اوبونٹو فائرووال کی تنظیم

UbuntuU UFW (Uncomplicated Firewall) کو ڈیفالٹ استعمال کرتا ہے۔ اس کی حالت چیک کریں اور ضرورت پڑنے پر پورٹ کی اجازت دیں :

# Vérifier le statut du pare-feu
sudo ufw status

# Si le pare-feu est actif, autoriser le port 8080
sudo ufw allow 8080/tcp

# Ou plus spécifiquement pour un service web
sudo ufw allow 'Apache'  # si vous utilisez Apache
sudo ufw allow 'Nginx Full'  # si vous utilisez Nginx

مرحلہ 6 : ٹیسٹ اور تصدیق

مقامی نیٹ ورک سے ٹیسٹ

پہلے، اپنے مقامی نेटورك کی کسی اور مشیں سے رسائی کا ٹیسٹ کریں :

# Remplacez par l'IP locale de votre machine Ubuntu
curl http://192.168.1.100:8080

باہر سے ٹیسٹ

اب انٹرنیٹ سے ٹیسٹ کریں، اپنی عوامی IP کا استعمال کرتے ہوئے :

# Remplacez par votre IP publique
curl http://VOTRE_IP_PUBLIQUE:8080

آپ آن لائن ٹولز بھی استعمال کر سکتے ہیں جیسے :

  • https://www.yougetsignal.com/tools/open-ports/

  • https://canyouseeme.org/

بہتر طریقے اور محفوظی

بنیادی سکیورٹی

# Configurer fail2ban pour protéger contre les attaques par force brute
sudo apt update && sudo apt install fail2ban

# Limiter l'accès avec UFW (exemple : autoriser seulement certaines IP)
sudo ufw allow from 203.0.113.0/24 to any port 8080

کنیکشنز کا مانیٹرنگ

# Surveiller les connexions en temps réel
sudo netstat -an | grep :8080

# Logs des connexions (selon votre application)
sudo tail -f /var/log/nginx/access.log  # pour Nginx
sudo journalctl -f -u your-service      # pour un service systemd

ریورس پروکسی کا استعمال

بہتتر امنیتی اور لچکداری کے لیے، نجنکس جیسے ریورس پروکسی استعمال کرنے پر غور کریں

server {
    listen 80;
    server_name votre-domaine.com;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}

پورت فوروارڈنگ کے متبادل

سحابی حلول

  • ngrok: سرنگ محفوظ موقت

  • Cloudflare ٹنلمفت و محفوظ حل

  • serveo.net: سادہ SSH نال

# Exemple avec ngrok
ngrok http 8080

# Exemple avec serveo
ssh -R 80:localhost:8080 serveo.net

VPS اور ریورس پروکسی

حِسّہ ورانہ استعمال کے لیے، خود کے مقامی انفراسٹرکچر سے وائ پی ن کے ذریعے ریورس پروکسی کے ساتھ VPS استعمال کرنے پر غور کریں۔

نتیجہ

لokal سروس کو انٹرنیٹ پر انکشاف کرنے کے لئے پورٹ فوروارڈنگ، سکیورٹی اور مونٹرینگ کی احتیاطي ترتیبات لازم ہیں۔ اگرچہ یہ طریقہ ڈویلپمنٹ یا ذاتی پروجیکٹس کے لیے مناسب ہے، پروڈکشن کے استعمال کے لیے مضبوط alternates (VPS، CDN، كلاود سروسز) پر غور کریں۔

مہत्त्वیہ یہ ہے کہ ہمیشہ محفوظی کو ذہن میں رکھیں: مضبوط پاس ورڈ استعمال کریں، اپنی نظام کو منظم طریقے سے اپ ڈیٹ کریں، اور اپنی ظاہر کردہ سروسز تک رسائی کی نگرانی کریں۔

کبھی بھی ہاتھ نہیں ڈھالیں، اپنی تجربات اور سوالوں کو تبصرے میں شیئر کریں !
