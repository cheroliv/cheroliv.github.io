یہ رہنمای قدم‑به‑قدم بتاتی ہے کہ Xubuntu پر ٹرمینل kitty کو کیسے انسٹال کریں، اسے صحیح طریقے سے کنفیگر کریں، اور bash کی جگہ zsh کو ڈیفالٹ شیل بنائیں۔ کیٹی پروجيکٹ یہاں دستیاب ہے: https://github.com/kovidgoyal/kitty

_ Kitty ایک modern، تیز اور قابلِ تنظیم ٹرمنل ہے، خاص طور پر مطالبہ کرنے والے ڈویلپرز کے لیے مناسب ہے۔ _

کیٹی اور Zsh کو کیوں چنیے؟

Kitty تمیز رکھتی ہے :

  • GPU کی تيسر سے بہتر کارکردگی،

  • ایک پوری طرح ایک متنی فائل پر مبنی تنظیم,

  • فونٹس اور لگچرز کے لیے بہترین حمایت.

Zsh خود ایک طاقتور تعاملی شیل پیشکش کرتا ہے :

  • ایک هوشمند تکملہ,

  • ایک قابلِ تنظیم پروامپٹ,

  • بے حد مناسبیت بیک کے ساتھ۔

Kitty اور Zsh کو ملانے سے، آپ ایک مصنوعات اور خوبصورت ماحول سے فائدہ اٹھاتے ہیں۔

@startuml
title سادہ معماری Kitty + Zsh
actor User

User --> Kitty : Lance le terminal
Kitty --> Zsh : Initialise le shell interactif
Zsh --> System : Interagit avec le système (fichiers, commandes)
@enduml

یہ رہنمای عمداً محدود ہے اسکریپٹ کے ذریعے انسٹالیشن اور Xubuntu تک۔

سیسٹم کی پیشِ ضروریات

شروع کرنے سے پہلے، کرم یقینی بنائیں کہ آپ کے پاس:

  • Xubuntu انسٹال،

  • انترنت تک رسائی,

  • اسکرپٹ چلانے کے لیے ایک فاعل باش شیل۔

اپنی ماحول کی جانچ کریں:

uname -a
lsb_release -a

کیٹی کا ڈاؤنلوڈ اور انسٹالیشن

کٹی اسے ایک رسمی اسکرپٹ کے ذریعے انسٹال کرنے کی سِفارش کرتی ہے جو فائلز کو`~/.local/kitty.app`.

یہ طريقہ پاکج مینیجرز سے مستقل ہے (نہ`apt`).

اسٹال سکرپٹ ڈاؤنلوڈ کریں

کمانڈ درج ذیل کو چلائیں :

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

یہ کمانڈ انجام دےتی ہے :

  • بائنریز ڈاؤنلوڈ،

  • استخراج میں`~/.local/kitty.app`,

  • سائمبولک لنکس کی بناؤ.

@startuml
title Kitty کا ڈاؤنلوڈ اور انسٹال
start
:curl -L installer.sh;
:sh /dev/stdin;
:Décompression dans ~/.local/kitty.app;
:create symlinks;
stop
@enduml

سمبولک لنکس کی تخلیق

انکار کرنے کے لئے`kitty`ٹرمینال سے، ایک سمبولک لنک بنائیں :

ln -s ~/.local/kitty.app/bin/kitty ~/.local/bin/kitty

افزائیں`~/.local/bin`اپنے PATH میں شامل کریں اگر پہلے سے نہیں کیا گیا ہے:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

آپ انسٹالیشن کی جانچ کر سکتے ہیں :

kitty --version

ایکسبونٹو میں کٹی کی انٹیگریشن

Kitty کو ایپلیکیشن مینو میں ظاہر ہونے کے لیے :

ڈیٹاپ فائل کاپی کریں

فائل کاپی کریں`.desktop`مہیا :

cp ~/.local/kitty.app/share/applications/kitty.desktop ~/.local/share/applications/

ڈیسک ٹاپ فائل کو ترمیم کریں

فائل میں ترمیم کریں:

nano ~/.local/share/applications/kitty.desktop

نوائن؟

[Desktop Entry]
Version=1.0
Type=Application
Name=Kitty Terminal
Comment=Fast GPU-based terminal emulator
Exec=/home/$USER/.local/kitty.app/bin/kitty
Icon=kitty
Categories=System;TerminalEmulator;

بدل کیجئے`YOURUSER`آپ کے صارف نام کے ذریعے

@startuml
title Xubuntu مینی میں Kitty کے شمول کی عمل
start
:Copier .desktop;
:Editer les chemins;
:Sauvegarder;
:Menu Applications;
stop
@enduml

کیٹی کو ڈیفالٹ ٹرمینل کے طور پر منسوب کریں (اختیاری)

کہ Kitty عادی طور پر چلنے والا ٹرمینل بن جائے:

sudo update-alternatives --install /usr/bin/x-terminal-emulator x-terminal-emulator ~/.local/kitty.app/bin/kitty 50
sudo update-alternatives --config x-terminal-emulator

منتخب کریں`kitty`منو مُقترح میں

زیش کی انسٹالیشن

اگر Zsh ابھی تک انسٹال نہیں ہے، چلاوئے :

sudo apt install zsh

انستالیشن جانچ کریں :

zsh --version

Zsh کو ڈفلٹ شیل بنائیں

آپ اپنی شیلی کو عالمی طور پر یا صرف Kitty میں تبدیل کر سکتے ہیں۔

ملکی طریقہ (تمام ٹرمنل کے لیے)

پہچانیں مطلق مسار:

which zsh

عام طور پر`/usr/bin/zsh`.

ڈیفالٹ شیل کو بدل دیں :

chsh -s /usr/bin/zsh

خروج ہوں اور پھر لاگ ان کریں

@startuml
title شیل کی عالمی تبدیلی
actor User

User --> Bash : Session actuelle
User --> System : chsh -s /usr/bin/zsh
System --> "/etc/passwd" : Modifie le shell
note right of "/etc/passwd" : Shell par défaut mis à jour
@enduml

کیٹی کے لئے مخصوص طریقہ

اگر آپ کیتی میں صرف شیل تبدیل کرنا چاہتے ہیں، تو تنظیم فائل کو ایڈٹ کریں :

nano ~/.config/kitty/kitty.conf

یہ لائن شامل کریں:

shell zsh

Kitty کو محفوظ کریں اور رِسٹارٹ کریں۔

Zsh کی تنظیمات (اختیاری)

اپنے Zsh کو خودساز بنائیں :

ایک .zshrc فائل بنائیں

touch ~/.zshrc
nano ~/.zshrc

کم سے کم کنفیگریشن کا مثال

export ZSH_THEME="robbyrussell"
export PATH="$HOME/.local/bin:$PATH"
alias ll="ls -la"

کامل ورکفلو کا خلاصہ

نیچے دیا گیا نمودار مکمل عمل کا خلاصہ پیش کرتا ہے

@startuml
title انسٹالیشن اور کنفیگریشن کی ورک فلو
start
:Téléchargement script Kitty;
:Installation dans ~/.local;
:Création symlink;
:Ajout ~/.local/bin au PATH;
if (Zsh installé ?) then (non)
  :sudo apt install zsh;
endif
:Configurer Kitty.desktop;
:Optionnel - changer terminal par défaut;
:Optionnel - chsh -s /usr/bin/zsh;
stop
@enduml

آخری جانچ

کیتی چلائیں:

kitty

آپ کو یہ دیکھنا چاہیے`zsh`فعال ہے :

echo $SHELL

مُتوقع نتیجہ :

/usr/bin/zsh

فونٹ کے سائز کو تبدیل کرنے کے لئےکیٹی, ہمیں پیرامیٹر کو ایجسٹ کرنا پڑتا ہے`font_size`کنفیگریشن فائل میں۔ یہ تفصیلی عمل ہے:

📂 کنفیگریشن فائل کھولیں

م بنیادی تنظیمات فائل عموماً یہاں واقع ہے:

~/.config/kitty/kitty.conf

اگر یہ فایل ابھی تک موجود نہیں ہے، تو آپ اسے بن سکتے ہیں۔ مثال :

nano ~/.config/kitty/kitty.conf

🖋️ اضافہ یا ترمیم `font_size

نیचे دی گئی ہدایت شامل کریں، یا اگر یہ پہلے سے موجود ہو تو اسے تبدیل کریں:

font_size 14.0

یہاں`14.0`خواہش کے حسب سائز سے مطابقت رکھتا ہے۔ آپ کسی بھی اعشاریہ مقدار رکھ سکتے ہیں، مثال کے طور پر`12.0`, 15.5, و غیرہ

💾 محفوظ کریں اور Kitty کو دوبارہ چلائیں

  • محفوظ کریں (Ctrl + O, پھر`Entrée`) aur chlijiye (Ctrl + X) اگر آپ استعمال کر رہے ہیں`nano`.

  • کٹی کی تمام وینڈوز بند کر دیں، پھر ٹرمینل کو دوبارہ شروع کریں تا تبدیل مؤثر ہو جائے۔

✅ تنظیم دیناميک (زوم مؤقت)

اگر آپ موقتاً زوم ان/آؤٹ کرنا چاہتے ہیں، ترکیب تبدیل کیے بغیر، براہِ کرم ڈیفالٹ کی بورڈ شرتکٹ استعمال کریں:

  • فونٹ کے سائز کو بڑھائیں :

Ctrl + Shift + =

  • فونت کے سائز کو کم کریں :

Ctrl + Shift + -

  • سائز ریست کریں:

Ctrl + Shift + Backspace

یہ ترتیبات ٹرمینال کی بند ہونے کے بعد برقرار نہیں رہتی۔

اوہ مای زش کی انسیٹال اور کائنفیگریشن

زیش کو انسٹال کردہ اور ڈیفالٹ شیل بنانے کے بعد، آپ Oh My Zsh کے ذریعے Apni ماحول کو بہتر بن سکتے ہیں — Zsh کی ترتیب‑دینے کا فریم ورک — جو فراہم کرتا ہے:

  • پرمپت کے لیے موضوعات کی ایک مجموعہ,

  • بہت سی پلاگنس،

  • کونفیگریشن کی واضح تنظیم۔

Oh My Zsh کی انسٹالیشن

مطمئن ہوں کہ Zsh فعال ہے:

zsh --version

اگر ضروری ہو، چلاو:

zsh

سپس ڈاؤنلوڈ کریں اور اجرا کریں، رسمی انسٹالیشن اسکرپت :

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

یہ سکرپٹ :

  • فولڈر بنائیں`~/.oh-my-zsh`,

  • ممکناً اپنی فائل محفوظ کریں`~/.zshrc`,

  • نئے پرامپٹ کو خودکار طور پر فعال کرتا ہے۔

ธีม بدلئ

آپ کی تنظیم فائل کھولیں :

nano ~/.zshrc

متغیر کو بدل دیں`ZSH_THEME`ایک دیگر موضوع کو انتخاب کرنے کے لیے (مثلاً`agnoster`) :

ZSH_THEME="agnoster

محفوظ کریں پھر رلوڈ کریں کنفیگریشن :

source ~/.zshrc

تصديق

Kitty کو چلائیں اور جائز لیں کہ پرامپٹ مناسب طور پر بدل گیا ہے۔ آپ تصدیق کر سکتے ہیں کہ Oh My Zsh فعال ہے، اسچلائے :

echo $ZSH

نتیجہ مماثل ہونا چاہیے :

/home/آپ_کا_صارف/.oh-my-zsh

استعمال کے کیس کا ڈائگرام

@startuml
title Use case Oh My Zsh کی انسٹالیشن اور استعمال
actor Utilisateur as User

package "کیٹی ٹرمینال" {
  component "Zsh شل" as Zsh
}

component "اوہ می زش فریم ورک" as OhMyZsh

User --> Kitty : Lance Kitty
Kitty --> Zsh : Initialise Zsh
Zsh --> OhMyZsh : Charge configuration (~/.zshrc, thèmes, plugins)
User --> OhMyZsh : Personnalise le thème et les plugins

@enduml

Kitty میں شفافیت فعال کریں

Kitty کی سب سے زیادہ محبوب خصوصیات میں سے ایک ٹرمینل کی پس منظر میں شفافیت شامل کرنے کی قابلیت ہے۔ یہ نیچے الوالا ماحول (ویندو، ڈیسکٹاپ، وغیرہ) کو ہلکا سا دکھاتا ہے، جس کا استعمال مالتِٹاسک میں خاص طور پر مفید ہے۔

شفافیت کے لئے پیش شرط

کٹی میں شفافیت اس پر مبنی ہےکھڑکیوں کا مُصَنّفگرافیکی ماحول توسط استعمال کیا جاتا ہے Xubuntu پر (XFCE پر مشتمل)، یقینی بنائیں کہکمپوزیشن فعال ہے.

جانچ کرنے کے لیے :

  • راست کلیک ڈیسکاپ پر > ترتیبات >ویindow مینیجر کی تنظیمات,

  • ٹابموزِق نگار: بکس ترکیب فعال کریں چیک کرنا ضروری ہے۔

@startuml
title Use Case - Kitty میں شفافیت فعال کریں
actor Utilisateur

rectangle "گرافیکی ماحول (XFCE/Xubuntu)" {
  usecase "کامپوزیشن فعال کریں" as UC1
}

rectangle "کیٹی ٹرمینل" {
  usecase "کٹی کنف میں شفافیت سیٹ کریں" as UC2
}

Utilisateur --> UC1
Utilisateur --> UC2

@enduml

kitty.conf میں شفافیت کی ترتیب

آپ کی کنفیگریشن فائل کھولیں`~/.config/kitty/kitty.conf` :

nano ~/.config/kitty/kitty.conf

شامل کریں یا ترمیم کریں بعد کی líneas:

background_opacity 0.85

یہ پیرامیٹر درجہ بیں قدر قبول کرتا ہے :

  • 1.0→ بے شفاف (کوئی شفافیت نہیں),

  • 0.0→ کاملاً شفاف (استعمال نہیں)

  • درمیانی قيمتیں جیسے`0.90`, 0.75, و غیرہ

ایک خوبصورت بصری تسالمعام طور پر درمیان`0.85` et 0.95.

کٹی کو دوبارہ شروع کریں

Kitty کے تمام انسینسز بند کر دیں، پھر نئی وینڈو لاونچ کریں تاکہ تبدیلیاں اثر کر سکیں:

kitty

ممکن مکملات

اگر آپ ایک کسٹم ٹرمنل پس منظر استعمال کر رہے ہیں، تو آپ ایک پس منظر کا رنگ بھی شفافیت کے ساتھ (RGBA میں) سیٹ کر سکتے ہیں:

background #1e1e2eff

آخری جزو (ff) بے شفافیت ظاہر کرتا ہے (de`00` à ff).

سیکنسی ڈائگرام - Kitty کی انشئلائزیشن شفافیت کے ساتھ

@startuml
title کیٹی کے transparency کے ساتھ شروع ہونے کی سیکوانس
actor User
participant "کیٹی" as Kitty
participant "XFCE کمپوزٹر" as XFCE
participant "جي بي يو/وینڈو مینیجر" as WM

User -> Kitty : Lance Kitty
Kitty -> kitty.conf : Lit configuration
Kitty -> XFCE : Vérifie composition activée
XFCE --> Kitty : Composition = active
Kitty -> WM : Demande allocation fenêtrée transparente
WM --> Kitty : OK (rendu avec alpha < 1)
Kitty -> User : Affiche terminal translucide

معروفة محدودیتیں

الشفافیت کام نہیں کرتی اگر : - XFCE کی کمپوزر غیر فعال ہے, - نامطابق window manager استعمال ہوتا ہے, - آپ Kitty کو ایک tmux کے پس منظر موڈ میں استعمال کر رہے ہیں جس میں شفافیت کا سپورٹ نہیں ہے۔

آواز سے���� (آؤڈبیل بیل) کو غیر فعال کریں

ڈفلٹ پر Kitty ایک bip آواز پیدا کرتی ہے جب غلط 커맡نڈ داخل کی جاتی ہو یا ٹرمینل کے أي sự kiện سے یہ چلایا جائے۔ یہ آواز جلد ہی متنافر بن سکتی ہے، مخصوصاً tez taraqqiyati mohit میں۔

اس سلوک کو غیر فعال کرنے کے لیے، درج ذیل ہدایات کو فائل میں شامل کریں`~/.config/kitty/kitty.conf`:

audible_bell no

آپ بھی بصری فِeedبَک فعال کر سکتے ہیں بج کی آواز کی جگہ پر :

visual_bell yes

کیتی کا اپ ڈیٹ

کیونکہ Kitty اسکرپٹ کے ذریعے انسٹال کیا گیا ہے، پیکنج مینیجر نہیں۔ اپ ڈیٹ رسمی انسٹال اسکرپٹ کو دوبارہ چلایا کر کیا جاتا ہے۔ یہ آپ کو سب سے نئی ورژن ڈاؤنلوڈ کرنے اور اپنی موجودہ انسٹال کو اپ ڈیٹ کرنے میں اجازت دیتا ہے۔~/.local/kitty.app.

لاحق`.app`راستے میں`~/.local/kitty.app`یہ Kitty کے لنکس پر رسمی سکرپٹ کے ذریعے انstalیشن کی رواج ہے، اور اس کا کوئی بھی مطلب نہیں ہے کہ صرف macOS کے ساتھ متوافق ہے۔

آپ ڈیٹ کامینڈ چلانے سے پہلے، یقینی بنائیں کہ آپ اپنے گھر کے ڈائریکٹری میں ہیں (~)

اپنی ہوم ڈائریکٹری سے درج ذیل فرمان اجرائیں :

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

یہ اسکرپٹ ذمہ دار ہوگا :

  • نیا ورژن کے بائنریز ڈاؤنلوڈ کریں

  • فائلوں کو نکال کریں`~/.local/kitty.app`.

  • ضرورت ہونے پر سمبولک لنکس کو اپ ڈیٹ کریں۔

آپ ڈیٹ کرنے کے بعد، تمام Kitty کے انسٹنسز بند کر کے پھر سے چلا دینے کی تجویز دی جاتی ہے تاکہ نئی ورژن صحیح طور پر مان لی جائے۔
