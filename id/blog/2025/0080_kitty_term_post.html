Panduan ini menjelaskan langkah demi langkah cara menginstal terminal kitty di Xubuntu, mengonfigurasi dengan benar, dan mengganti bash dengan zsh sebagai shell default. Proyek kitty tersedia di sini: https://github.com/kovidgoyal/kitty.

_ Kitty adalah terminal modern, cepat dan dapat dikonfigurasi, sangat sesuai untuk pengembang yang sangat menuntut. _

Mengapa memilih Kitty dan Zsh?

Kitty membedakan dengan:

  • Performa lebih tinggi dengan akselerasi GPU,

  • Sebuah konfigurasi yang sepenuhnya berbasis pada satu file teks tunggal,

  • Dukungan excellent untuk font dan ligatur.

Zsh justru merupakan shell interaktif yang kuat yang menawarkan:

  • Penyelesaian cerdas,

  • Sebuah prompt yang dapat dipersonalisasi,

  • Kompatibilitas besar dengan bash.

Dengan menggabungkan Kitty dan Zsh, Anda mendapatkan lingkungan yang produktif dan estetis.

@startuml
title Arsitektur sederhana Kitty + Zsh
actor User

User --> Kitty : Lance le terminal
Kitty --> Zsh : Initialise le shell interactif
Zsh --> System : Interagit avec le système (fichiers, commandes)
@enduml

Panduan ini sengaja terbatas pada penginstalan melalui skrip dan Xubuntu.

Prasyarat sistem

Sebelum memulai, pastikan Anda memiliki :

  • Xubuntu terinstal,

  • akses ke internet,

  • sebuah shell bash yang berfungsi untuk menjalankan skrip.

Periksa lingkungan Anda :

uname -a
lsb_release -a

Pengunduhan dan pemasangan Kitty

Kitty merekomendasikan menginstalnya melalui skrip resmi yang menempatkan file-file di`~/.local/kitty.app`.

Ini metode adalah independen dari manajer paket (tanpa`apt`).

Unduh skrip instalasi

Jalankan perintah berikut:

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

Perintah ini melakukan :

  • unduhan biner,

  • ekstraksi dalam`~/.local/kitty.app`,

  • pembuatan tautan simbolik.

@startuml
title Unduhan dan instalasi Kitty
start
:curl -L installer.sh;
:sh /dev/stdin;
:Décompression dans ~/.local/kitty.app;
:create symlinks;
stop
@enduml

Pembuatan tautan simbolis

Agar dapat memanggil`kitty`dari terminal, buat sebuah tautan simbolik :

ln -s ~/.local/kitty.app/bin/kitty ~/.local/bin/kitty

Tambahkan`~/.local/bin`tambahkan ke PATH Anda jika belum dilakukan :

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

Anda dapat memeriksa instalasi :

kitty --version

Integrasi Kitty di Xubuntu

Agar Kitty muncul di menu aplikasi:

Menyalin file desktop

Salin berkas`.desktop`disediakan :

cp ~/.local/kitty.app/share/applications/kitty.desktop ~/.local/share/applications/

Ubah file desktop

Edit berkas :

nano ~/.local/share/applications/kitty.desktop

Periksa atau ubah baris berikut :

[Desktop Entry]
Version=1.0
Type=Application
Name=Kitty Terminal
Comment=Fast GPU-based terminal emulator
Exec=/home/$USER/.local/kitty.app/bin/kitty
Icon=kitty
Categories=System;TerminalEmulator;

Ganti`YOURUSER`dengan nama pengguna Anda.

@startuml
title Proses integrasi Kitty dalam menu Xubuntu
start
:Copier .desktop;
:Editer les chemins;
:Sauvegarder;
:Menu Applications;
stop
@enduml

Mengaitkan Kitty sebagai terminal default (opsional)

Agar Kitty menjadi terminal yang diluncurkan secara default :

sudo update-alternatives --install /usr/bin/x-terminal-emulator x-terminal-emulator ~/.local/kitty.app/bin/kitty 50
sudo update-alternatives --config x-terminal-emulator

Pilih`kitty`dalam menu yang ditawarkan

Instalasi Zsh

Jika Zsh belum terinstal, jalankan :

sudo apt install zsh

Periksa instalasi:

zsh --version

Tetapkan Zsh sebagai shell default

Anda dapat mengubah shell secara global atau hanya di Kitty.

Metode global (untuk semua terminal)

Identifikasi jalur mutlak:

which zsh

Secara umum`/usr/bin/zsh`.

Ubah shell default :

chsh -s /usr/bin/zsh

Keluar dan masuk kembali.

@startuml
title Perubahan shell global
actor User

User --> Bash : Session actuelle
User --> System : chsh -s /usr/bin/zsh
System --> "/etc/passwd" : Modifie le shell
note right of "/etc/passwd" : Shell par défaut mis à jour
@enduml

Metode khusus untuk Kitty

Jika Anda hanya ingin mengubah shell di Kitty, edit file konfigurasi :

nano ~/.config/kitty/kitty.conf

Tambahkan baris ini :

shell zsh

Simpan dan restart Kitty.

Konfigurasi Zsh (opsional)

Untuk menyesuaikan Zsh Anda :

Buat file .zshrc

touch ~/.zshrc
nano ~/.zshrc

Contoh konfigurasi minimal

export ZSH_THEME="robbyrussell"
export PATH="$HOME/.local/bin:$PATH"
alias ll="ls -la"

Ringkasan workflow lengkap

Skema di bawah ini merangkum seluruh proses:

@startuml
title Alur kerja instalasi dan konfigurasi
start
:Téléchargement script Kitty;
:Installation dans ~/.local;
:Création symlink;
:Ajout ~/.local/bin au PATH;
if (Zsh installé ?) then (non)
  :sudo apt install zsh;
endif
:Configurer Kitty.desktop;
:Optionnel - changer terminal par défaut;
:Optionnel - chsh -s /usr/bin/zsh;

@enduml

Verifikasi akhir

Jalankan Kitty :

kitty

Anda seharusnya melihat bahwa`zsh`aktif :

echo $SHELL

Hasil yang diharapkan :

/usr/bin/zsh

Untuk mengubah ukuran font diKitty, harus menyesuaikan parameter`font_size`dalam file konfigurasi. Berikut adalah prosedur detailnya:

📂 Membuka file konfigurasi

File konfigurasi utama biasanya berada di:

~/.config/kitty/kitty.conf

Jika file ini belum ada, Anda dapat membuatnya. (No source text provided, so nothing to translate.)

nano ~/.config/kitty/kitty.conf

🖋️ Tambah atau ubah `font_size

Tambahkan direktif berikut, atau ubah jika sudah ada:

font_size 14.0

di sini`14.0`sesuai dengan ukuran yang diinginkan. Anda dapat memasukkan nilai desimal apa pun, misalnya`12.0`, 15.5, dst.

💾 Menyimpan dan mulai ulang Kitty

  • Catat (Ctrl + O, lalu`Entrée`) dan tinggalkan (Ctrl + X) jika Anda menggunakan`nano`.

  • Tutup semua jendela Kitty, kemudian restart terminal agar perubahan berlaku.

✅ Penyesuaian dinamis (Zoom sementara)

Jika Anda ingin melakukan zoom in/out sementara tanpa mengubah konfigurasi, gunakan pintasan keyboard default:

  • Perbesar ukuran font(empty)

Ctrl + Shift + =

  • Kurangi ukuran font:

Ctrl + Shift + -

  • Reset ukuran:

Ctrl + Shift + Backspace

Pengaturan ini tidak persisten setelah terminal ditutup.

Instalasi dan konfigurasi Oh My Zsh

Setelah Zsh terinstal dan dikonfigurasi sebagai shell default, Anda dapat memperkaya lingkungan Anda dengan Oh My Zsh, sebuah framework manajemen konfigurasi Zsh yang menawarkan:

  • sebuah kumpulan tema untuk prompt,

  • banyak plugin,

  • organisasi yang jelas dari konfigurasi.

Instalasi Oh My Zsh

Pastikan Zsh aktif:

zsh --version

Jika diperlukan, mulai :

zsh

Kemudian unduh dan jalankan skrip instalasi resmi:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

Skrip ini:

  • Buat folder`~/.oh-my-zsh`,

  • cadangan opsional file Anda`~/.zshrc`,

  • mengaktifkan secara otomatis prompt baru.

Mengubah tema

Buka file konfigurasi Anda :

nano ~/.zshrc

Ubah variabel`ZSH_THEME`untuk memilih tema lain (misalnya`agnoster`) :

ZSH_THEME="agnoster

Simpan lalu muat ulang konfigurasi :

source ~/.zshrc

Verifikasi

Jalankan Kitty dan pastikan bahwa prompt telah berubah dengan baik. Anda dapat memastikan bahwa Oh My Zsh aktif dengan menjalankan :

echo $ZSH

Hasilnya seharusnya serupa dengan :

/home/pengguna_anda/.oh-my-zsh

Aktifkan transparansi di Kitty

Salah satu fitur paling digemari dari Kitty adalah kemampuan menambahkan transparensi pada latar belakang terminal. Ini memungkinkan Anda untuk melihat sedikit lingkungan di bawahnya (jendela, desktop, dll.), yang sangat berguna saat multitasking.

Prasyarat untuk transparansi

Transparansi dalam Kitty berdasarkan lekomposer jendeladigunakan oleh lingkungan grafis. Di Xubuntu (berbasis XFCE), pastikan bahwakomposisi diaktifkan.

Memeriksa :

  • klik kanan di desktop > Pengaturan >Pengaturan manajer jendela,

  • tabkomposer: kotak "Activer la composition" harus dicentang.

@startuml
title Use Case - Mengaktifkan transparansi di Kitty
actor Utilisateur

rectangle "Lingkungan grafis (XFCE/Xubuntu)" {
  usecase "Mengaktifkan komposisi" as UC1
}

rectangle "Terminal Kitty" {
  usecase "Menentukan transparansi dalam kitty.conf" as UC2
}

Utilisateur --> UC1
Utilisateur --> UC2

@enduml

Konfigurasi transparansi dalam kitty.conf

Buka file konfigurasi Anda`~/.config/kitty/kitty.conf` :

nano ~/.config/kitty/kitty.conf

Tambahkan atau ubah baris berikut:

background_opacity 0.85

Parameter ini menerima nilai antara:

  • 1.0→ opak (tidak ada transparansi),

  • 0.0→ sangat transparan (tidak dapat digunakan)

  • nilai tengah seperti`0.90`, 0.75, dll.

Sebuah kompromi visual yang baik biasanya berada di antara`0.85` et 0.95.

Mulai ulang Kitty

Tutup semua instance Kitty, lalu buka kembali jendela baru agar perubahan berlaku :

kitty

Suplemen yang mungkin

Jika Anda menggunakan latar belakang terminal khusus, Anda juga dapat mengatur warna latar belakang dengan transparansi (dalam RGBA):

background #1e1e2eff

Komponen terakhir ()ff) menunjukkan opasitas (de`00` à ff)

Keterbatasan yang diketahui

Transluciditas tidak berfungsi jika: - kompositor XFCE nonaktif, - manajer jendela yang tidak kompatibel sedang digunakan, - Anda menggunakan Kitty dalam mode tmux di latar belakang tanpa dukungan transparansi.

Nonaktifkan bip suara (audible bell)

Secara default, Kitty mengeluarkan suara bip ketika perintah salah dimasukkan atau sebuah acara terminal memicu-nya. Bunyi ini dapat dengan cepat menjadi mengganggu, terutama di lingkungan pengembangan yang intensif.

Untuk menonaktifkan perilaku ini, tambahkan direktif berikut ke file`~/.config/kitty/kitty.conf`( empty )

audible_bell no

Anda juga dapat mengaktifkan umpan balik visual sebagai pengganti bip suara dengan :

visual_bell yes

Pembaruan Kitty

Karena Kitty diinstal melalui skrip dan bukan melalui manajer paket, pembaruan dilakukan dengan menjalankan ulang skrip instalasi resmi. Ini memungkinkan Anda mengunduh versi terbaru dan memperbarui instalasi Anda yang ada di`~/.local/kitty.app`.

akhiran`.app`di jalan`~/.local/kitty.app`adalah konvensi instalasi Kitty di Linux melalui skrip resmi-nya, dan tidak menunjukkan sama sekali kompatibilitas eksklusif dengan macOS.

Sebelum menjalankan perintah pembaruan, pastikan Anda berada di direktori rumah Anda (~)

Jalankan perintah berikut dari direktori home Anda :

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

Skrip ini akan mengurus :

  • Unduh binari versi baru.

  • Ekstrak file di dalam`~/.local/kitty.app`.

  • Memperbarui tautan simbolik jika diperlukan.

Setelah pembaruan, disarankan untuk menutup semua instance Kitty dan menjalankannya kembali untuk memastikan bahwa versi baru diterima dengan baik.
