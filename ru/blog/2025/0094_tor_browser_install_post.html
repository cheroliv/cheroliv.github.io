Введение

В мире, где цифровая конфиденциальность всё больше подвергается угрозе, Tor Browser остаётся важным инструментом для сохранения анонимности и свободы информации. Однако важно никогда не запускать загруженное программное обеспечение без наличияпроверил его подлинность. Эта статья представляет полный метод для:

  1. Скачать Tor Browser и его подпись`.asc`

  2. Проверить валидность скачанного файла

  3. Установить и запустить Tor Browser в Ubuntu

  4. Добавить его в меню рабочего стола для повседневного использования

  5. Исследуйте образовательные ресурсы и этичный OSINT через Tor

Скачивание Tor и его подписи

Создайте отдельную папку для браузера Tor:

mkdir -p ~/workspace/tipiak/tor
cd ~/workspace/tipiak/tor

Затем загрузите архив браузера Tor и его подпись:

wget https://www.torproject.org/dist/torbrowser/14.5.7/tor-browser-linux-x86_64-14.5.7.tar.xz
wget https://www.torproject.org/dist/torbrowser/14.5.7/tor-browser-linux-x86_64-14.5.7.tar.xz.asc

Криптографическая проверка подписи

Этот этап естьнезаменимыйчтобы убедиться, что загруженный файл действительно взят из Tor Project и не был изменён.

1. Импортировать открытый ключ проекта Tor

gpg --auto-key-locate nodefault,wkd --locate-keys torbrowser@torproject.org

Проверьте, что ключ импортирован правильно :

gpg --list-keys torbrowser@torproject.org

2. Проверить подпись

gpg --verify tor-browser-linux-x86_64-14.5.7.tar.xz.asc tor-browser-linux-x86_64-14.5.7.tar.xz

Если все правильно, будет отображаться следующее сообщение :

gpg: Good signature from "Tor Browser Developers (signing key)"

При предупреждении о неподтверждённом ключе это просто означает, что вы ещё не подписали доверенный ключ проекта Tor, но подпись остаётся действительной.

Практический пример: Подпись действительна, но ключ не сертифицирован

Часто встречается сообщение такого вида при проверке :

gpg --verify tor-browser-linux-x86_64-14.5.7.tar.xz.asc tor-browser-linux-x86_64-14.5.7.tar.xz
gpg: Signature faite le mar. 16 sept. 2025 14:26:26 CEST
gpg:                avec la clef RSA CAAE408AEBE2288E96FC5D5E157432CF78A65729
gpg: Bonne signature de « Tor Browser Developers (signing key) <torbrowser@torproject.org> » [inconnu]
gpg: Attention : cette clef n'est pas certifiée avec une signature de confiance.
gpg:          Rien n'indique que la signature appartient à son propriétaire.
Empreinte de clef principale : EF6E 286D DA85 EA2A 4BA7  DE68 4E2C 6E87 9329 8290
     Empreinte de la sous-clef : CAAE 408A EBE2 288E 96FC  5D5E 1574 32CF 78A6 5729

Это сообщение указывает, что подпись технически «хорошая» (файл не был изменён), но ваша система GPG не может подтвердить доверие к самому ключу. Для устранения этого сомнения необходимо сравнить отпечаток главного ключа (EF6E 286D DA85 EA2A 4BA7 DE68 4E2C 6E87 9329 8290) с той, опубликованной на официальном сайте Tor Project.

Согласно официальному сайту, ожидаемый отпечаток:`EF6E286DDA85EA2A4BA7DE684E2C6E8793298290`.

Поскольку отображаемый отпечаток от`gpg`соответствует точно той, что на официальном сайте, вы можете быть уверены, что ключ легитимный и файл безопасен. Предупреждение о «несертифицированном ключе» тогда является информацией о вашей локальной конфигурации GPG, а не о действительности подписи или подлинности файла.

Зачем проверять подпись?

Проверка подписей GPG — это фундаментальный акт цифровой безопасности. Она позволяет:

  • Гарантироватьподлинностьзагруженного программного обеспечения

  • Предотвратить установку скомпрометированного файла злоумышленником

  • участвовать вцифровой суверенитетиндивидуальная

  • Способствовать формированию ответственной и этичной цифровой культуры

Извлечение и запуск Tor Browser

Распакуйте загруженный архив :

tar -xvf tor-browser-linux-x86_64-14.5.7.tar.xz
cd tor-browser

Затем запустите браузер:

./start-tor-browser.desktop

При первом запуске откроется окно настройки для установления соединения с сетью Tor.

Интеграция в рабочий стол Ubuntu

Чтобы добавить Tor Browser в меню приложений:

./start-tor-browser.desktop --register-app

Вы можете затем:

  • Запустить Tor Browser из меню приложений

  • Добавить в избранное док

  • Создать сочетание клавиш, если требуется

@startuml
start
:Téléchargement de Tor;
:Importation de la clé GPG;
:Vérification de la signature;
if (Signature valide ?) then (Oui)
:Extraction du navigateur;
:Lancement du navigateur Tor;
:Enregistrement dans le bureau;
else (Non)
:Supprimer le fichier compromis;
endif
stop
@enduml

Исследовать образовательные ресурсы с помощью Tor

Tor — это не только инструмент анонимности. Он представляет собой портал доступа к образовательным и исследовательским ресурсам, в частности в следующих областях :

  • OSINT (Открытые источники разведки)

  • https://inteltechniques.com

  • https://osintframework.com

  • Образовательный обмен и open source

  • https://archive.org(доступ через Tor для большей конфиденциальности)

  • https://github.com/(доступно через Tor)

  • https://librarygenesis.pro(доступ к свободной научной литературе)

  • Передача знаний и понимание человека в цифровом обществе

  • Ресурсы о цифровой культуре, свободе выражения и доступе к знаниям

  • Свободная документация о кибербезопасности и этике технологий

Обновление Tor Browser

Для обеспечения оптимальной безопасности крайне важно поддерживать Tor Browser в актуальном состоянии. Браузер имеет встроенный механизм автоматического обновления, который может быть запущен из командной строки.

Из каталога установки Tor Browser достаточно перезапустить стартовый скрипт :

cd ~/workspace/tipiak/tor/tor-browser
./start-tor-browser.desktop

При запуске Tor Browser автоматически проверит наличие новой версии. Если она есть, он загрузит и установит её для вас.

Этот простой метод гарантирует, что у вас всегда будут последние исправления безопасности и новейшие улучшения, что необходимо для безопасного просмотра.
