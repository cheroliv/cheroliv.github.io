Введение

Интернационализация (i18n) статического сайта может показаться сложной на первый взгляд, но JBake в сочетании с Thymeleaf предоставляет элегантные решения для создания многоязычного сайта. В этой статье я покажу, как я внедрил i18n в свой блог, охватывая как шаблоны, так и управление статьями на нескольких языках.

Архитектура интернационализации

Наш подход опирается на два столпа:

  1. i18n шаблонизации: использование файлов сообщений Thymeleaf для элементов интерфейса

  2. Локализация содержимогоорганизация статей по языку в специализированной структуре каталогов

Почему такой подход?

Это разделение позволяет:

  • Поддерживать согласованность в интерфейсе независимо от языка

  • Управлять содержимым и переводами статей независимо

  • Облегчить добавление новых языков без значительного рефакторинга

  • Разрешить статьи, доступные только на некоторых языках

Использование в шаблонах

В ваших шаблонах Thymeleaf используйте синтаксис`#{}`для доступа к сообщениям :

<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
    <title th:text="#{site.title}">Mon Blog</title>
    <meta name="description" th:content="#{site.description}" />
</head>
<body>
    <nav>
        <a th:href="@{/}" th:text="#{nav.home}">Accueil</a>
        <a th:href="@{/blog/}" th:text="#{nav.blog}">Blog</a>
        <a th:href="@{/about.html}" th:text="#{nav.about}">À propos</a>
    </nav>

    <footer>
        <p th:text="#{footer.copyright}">Copyright</p>
    </footer>
</body>
</html>

JBake --> thymeleaf: article.fr.html trouvé

Настройка локали в JBake

В вашем файле`jbake.properties`, установите локаль по умолчанию :

# Locale par défaut
thymeleaf.locale=fr

# Encodage
template.encoding=UTF-8

I18n статей: организация по папкам

Схема потока (Flow) - Генерация

@startuml
start

:Lire jbake.properties;
:Charger configuration i18n;

partition "Для каждого файла AsciiDoc" {
  :Lire métadonnées\n(:jbake-lang:, :jbake-article-id:);
  :Parser contenu AsciiDoc;
  :Stocker en mémoire avec langue;
}

partition "Для каждого шаблона" {
  :Charger template Thymeleaf;
  :Identifier langue cible;
  :Charger messages_{lang}.properties;

  partition "Фильтрация содержимого" {
    :Filtrer articles par langue;
    :Grouper traductions\npar article-id;
  }

  :Appliquer template avec i18n;
  :Générer HTML dans /{lang}/;
}

:Copier assets statiques;
:Générer sitemap multilingue;
:Générer flux RSS par langue;

stop
@enduml

Структура папок

Вместо использования суффиксов в именах файлов я выбрал организацию по папкам, которая обеспечивает большую ясность и поддерживаемость :

content/blog/
├── 2024/
│   ├── fr/
│   │   ├── introduction-jbake.adoc
│   │   ├── guide-thymeleaf.adoc
│   │   └── astuces-asciidoc.adoc
│   └── en/
│       ├── introduction-jbake.adoc
│       ├── thymeleaf-guide.adoc
│       └── asciidoc-tips.adoc
└── 2025/
    ├── fr/
    │   └── internationalisation-jbake.adoc
    └── en/
        └── jbake-internationalization.adoc

Преимущества этого подхода

Эта структура имеет несколько преимуществ:

  • Чёткое разделение: каждый язык имеет своё собственное пространство

  • Гибкое именование: файлы могут иметь разные имена в зависимости от языка

  • Масштабируемость: легко добавить новый язык

  • Естественная организация: следует временной логике JBake

Метаданные статей

Каждая статья должна содержать метаданные для обеспечения связи между переводами. Вот пример :

Французская версия(2025/fr/internationalisation-jbake.adoc) :

= Internationalisation d'un site statique JBake
:jbake-type: post
:jbake-status: published
:jbake-date: 2025-10-20
:jbake-lang: fr
:jbake-article-id: jbake-i18n-thymeleaf
:jbake-tags: jbake, thymeleaf, i18n
:jbake-description: Guide pour mettre en place l'i18n avec JBake

Английская версия(2025/en/jbake-internationalization.adoc) :

= Internationalizing a JBake Static Site
:jbake-type: post
:jbake-status: published
:jbake-date: 2025-10-20
:jbake-lang: en
:jbake-article-id: jbake-i18n-thymeleaf
:jbake-tags: jbake, thymeleaf, i18n
:jbake-description: Guide to implement i18n with JBake

ПРИМЕЧАНИЕ: Атрибут`:jbake-article-id:`Это важно: он позволяет связывать различные переводы одной и той же статьи.

Конфигурация URL

В`jbake.properties`, настройте шаблон URL для включения языка :

# Pattern d'URL avec langue
post.permalink.pattern=:lang/blog/:year/:name.html

# Langue par défaut
site.default.lang=fr

Это будет генерировать URL-адреса вида :

  • /fr/blog/2025/internationalisation-jbake.html

  • /en/blog/2025/jbake-internationalization.html

Шаблоны для многоязычного отображения

Шаблон статьи с селектором языка

Создайте шаблон`post.html`который отображает доступные переводы :

<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
    <title th:text="${content.title}">Article</title>
</head>
<body>
    <article>
        <header>
            <h1 th:text="${content.title}">Titre</h1>

            <div class="article-meta">
                <time th:text="${#dates.format(content.date, 'dd MMMM yyyy')}"
                      th:attr="datetime=${#dates.format(content.date, 'yyyy-MM-dd')}">
                    Date
                </time>

                <!-- Sélecteur de traductions -->
                <div class="translations" th:if="${content['article-id']}">
                    <span th:text="#{article.also.available}">Aussi disponible en :</span>
                    <ul class="language-list">
                        <li th:each="post : ${published_posts}"
                            th:if="${post['article-id'] == content['article-id'] and post.lang != content.lang}">
                            <a th:href="${post.uri}"
                               th:text="${post.lang.toUpperCase()}">
                                LANG
                            </a>
                        </li>
                    </ul>
                </div>
            </div>
        </header>

        <div class="content" th:utext="${content.body}">
            Contenu de l'article
        </div>

        <footer class="article-footer">
            <div class="tags" th:if="${content.tags}">
                <span th:text="#{article.tags}">Étiquettes :</span>
                <span th:each="tag : ${content.tags}">
                    <a th:href="@{/tags/{tag}.html(tag=${tag})}"
                       th:text="${tag}">tag</a>
                </span>
            </div>
        </footer>
    </article>
</body>
</html>

Навигация между языками

Глобальный селектор языка

Блок-схема - Пользовательское чтение

@startuml
start

:Utilisateur accède au site;

if (Langue préférée ?) then (FR)
  :Afficher /index.html;
  :Lister articles FR;
else (EN)
  :Afficher /en/index.html;
  :Lister articles EN;
endif

:Utilisateur clique sur article;

:Afficher article\navec métadonnées;

if (Traductions disponibles ?) then (oui)
  :Afficher sélecteur\nde traductions;

  if (Changement de langue ?) then (oui)
    :Rediriger vers\ntraduction;
    :Afficher article\ndans nouvelle langue;
  else (non)
    :Continuer lecture;
  endif
else (non)
  :Continuer lecture;
endif

stop
@enduml

RSS-поток по языку

Для получения отдельных RSS‑потоков по языкам создайте отдельные шаблоны :

feed.xml(французский поток) :

<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0" xmlns:th="http://www.thymeleaf.org">
    <channel>
        <title th:text="#{site.title}">Mon Blog</title>
        <link th:text="${config.site_host}">http://example.com</link>
        <description th:text="#{site.description}">Description</description>
        <language>fr</language>

        <item th:each="post : ${published_posts}"
              th:if="${post.lang == 'fr'}">
            <title th:text="${post.title}">Titre</title>
            <link th:text="${config.site_host + post.uri}">Lien</link>
            <pubDate th:text="${#dates.format(post.date, 'EEE, dd MMM yyyy HH:mm:ss Z')}">
                Date
            </pubDate>
            <description th:text="${post.description}">Description</description>
        </item>
    </channel>
</rss>

Лучшие практики и советы

1. Согласованность идентификаторов статей

Убедитесь, что`:jbake-article-id:`одинаков для всех переводов одной статьи. Используйте согласованный формат :

  • Предпочитайте идентификаторы на английском языке для универсальности

  • Используйте дефисы для разделения слов

  • Избегайте специальных символов

Согласованные даты

Все переводы статьи должны иметь одинаковую дату публикации (:jbake-date:). Это облегчает сортировку и хронологический вывод.

3. Многоязычные теги

Для тегов у вас есть два варианта

4. Управление непереведёнными статьями

Не обязательно переводить все статьи. Если статья существует только на одном языке, она просто не появится в списках другого языка.

5. Многоязычная карта сайта

Создайте sitemap, включающий все языки :

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9"
        xmlns:xhtml="http://www.w3.org/1999/xhtml"
        xmlns:th="http://www.thymeleaf.org">
    <url th:each="post : ${published_posts}">
        <loc th:text="${config.site_host + post.uri}">URL</loc>
        <lastmod th:text="${#dates.format(post.date, 'yyyy-MM-dd')}">Date</lastmod>

        <!-- Liens alternatifs pour les traductions -->
        <xhtml:link th:each="translation : ${published_posts}"
                    th:if="${translation['article-id'] == post['article-id'] and translation.lang != post.lang}"
                    rel="alternate"
                    th:attr="hreflang=${translation.lang},href=${config.site_host + translation.uri}" />
    </url>
</urlset>

Вывод

Международная версия сайта JBake с Thymeleaf — это надёжный и поддерживаемый подход. Разделив i18n шаблонов (через файлы сообщений) и i18n контента (через организацию в каталогах), вы получаете гибкую систему, которую можно легко развивать.

Ключевые моменты, которые следует запомнить :

  • Файлы сообщений Thymeleafдля пользовательского интерфейса

  • Организация по папкам(год/язык) для статей

  • Идентификаторы статьидля связывания переводов

  • Выделенные шаблоныдля каждого языка

  • явные URLвключая код языка
