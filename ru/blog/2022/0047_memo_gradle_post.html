Показать справку

./gradlew --help

Установить системное свойство JVM: `-D, --system-prop

./gradlew -Dmyprop=myvalue
#ou
./gradlew --system-prop myvalue

Установить свойство проекта для скрипта сборки : `-Pmyprop=myvalue

./gradlew -Pmyprop=myvalue
#ou
./gradlew --project-prop myvalue

Укажите каталог запуска Gradle. По умолчанию — текущий каталог.

./gradlew -p ~/src/next_startup
#ou
./gradlew --project-dir ~/src/next_startup

Перезаписать свойство 'param_component' через командную строку :

./gradlew -Pparam_component=CUSTOM_VALUE

Добавить папку в source-set в обычном проекте с Kotlin DSL

sourceSets {
    getByName("test"){
        java.srcDir("src/scripts/groovy")
    }
    getByName("test"){
        java.srcDir("src/scripts/kscript")
    }
    getByName("test"){
        java.srcDir("src/test/javascript")
    }
}

Добавить папку в source-set в проекте Android с Groovy DSL

android {
    sourceSets {
        main.java.srcDirs += "src/main/../../../../ceelo/domain/src/main/java/"
        test.java.srcDirs += "src/test/../../../../ceelo/domain/src/test/java/"
    }
}

Избегать построения и тестирования подмодуля

gradle build -x :excluded-module:check -x :excluded-module:assemble -x :excluded-module:build

Перемещение файлов
tasks.register("moveWebappNode") {
    doLast {
        ant.withGroovyBuilder {
            "move"(
                "webapp/node_modules" to "$rootDir/webapp-src/node_modules",
            )
        }
    }
}

Tar папка

tasks.register<Tar>("tarWebapp") {
    dependsOn("moveWebappNpm")
    group = WEBAPP
    description = "tar webapp"
    doLast {
        setOf(
            "build",
            "target",
            "node_modules"
        ).forEach { dir -> exclude { it.name .dir } }
        archiveFileName.set("webapp.tar")
        destinationDirectory.set(File("${rootDir.absolutePath}$sep$WEBAPP_SRC"))
    }
}

Показать зависимости сборки

tasks.register("printDependencies") {
    description = "print project dependencies"
    group = WEBAPP
    doLast {
        println("${project.name} dependencies")
        mutableMapOf<String, Map<String, String>>(
            "buildDependencies" to buildDependencies,
            "domainDeps" to domainDeps,
            "domainTestDeps" to domainTestDeps,
        ).apply { putAll(appModules) }
            .forEach { module ->
                if (module.value.isNotEmpty()) {
                    println("${module.key}:")
                    module.value.forEach { println(dependency(it)) }
                    println()
                }
            }
    }
}

Пример использования reduce : конкатенация списка в строку

tasks.register("printWebappSrc") {
    description = "print webapp sources"
    group = WEBAPP
    doLast {
        webAppSrc
            .reduce { acc, s -> "$acc\n\t$s" }
            .run { println("$WEBAPP_SRC: $this\n") }
    }
}

Получить описание конкретной задачи

./gradlew -q help --task foo

Чтобы запустить задачу из корня рабочего каталога workingDir, тогда префиксируйте задачу `:)

./gradlew :foo

Для перезапуска задач, которые завершились с ошибкой, используйте опцию `--rerun-tasks

./gradlew check --rerun-tasks

Запустить задачу в конкретном проекте из другого каталога

Опция`-p` (ou --project-dir) позволяет указать путь к проекту Gradle и выполнить задачу в нём, даже если текущий каталог отличается.

Например, чтобы запустить задачу`build`проекта, расположенного в`~/projets/mon-autre-projet`при этом находясь в другом каталоге:

./gradlew -p ~/projets/mon-autre-projet build

Это особенно полезно для написания скриптов действий в нескольких проектах из центрального места.
