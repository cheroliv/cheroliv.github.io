OpenCode ไม่ใช่ผู้ให้บริการโมเดลนี่คือ CLI โอเพนซอร์ส (github.com/anomalyco/opencode) ที่ประสานงานเอเจนต์ AI ไม่ขายการสมัครสมาชิก ไม่ให้บริการอินเฟอเรนซ์ นี่เทียบเท่ากับ`git`สำหรับการทำเวอร์ชัน: เครื่องมือ ไม่ใช่บริการ Ollama Cloud เป็นผู้ให้บริการการอนุมานการติดตั้ง Ollama ในเครื่องของฉันทำหน้าที่เป็น ไคลเอนต์ — โดยรับรองความถูกต้องกับเซิร์ฟเวอร์ของ Ollama ผ่านคีย์ SSH เฉพาะตัว (Device Key) และมอบหมายการรันโมเดลที่ติดแท็กให้เซิร์ฟเวอร์เหล่านั้นดำเนินการ`:cloud`. แพ็กเกจ Pro (20€/เดือน) ปลดล็อกโควตาที่สูงขึ้น และช่วยให้สามารถรวมหลายบัญชีไว้บนเครื่องเดียวกันผ่าน Docker

OpenCode เก็บรักษาประวัติเซสชันทั้งหมดไว้อย่างถาวรในไฟล์ SQLite ที่ตั้งอยู่ที่`~/.local/share/opencode/opencode.db`. La mienne pèse 660 Mo pour 73 jours d’utilisation — une base de données de production tout à fait respectable.

ฐานข้อมูลมีประมาณยี่สิบตาราง แต่สามในนั้นมีความสำคัญอย่างยิ่งสำหรับการตรวจสอบของเรา:

โต๊ะ`session`เหมาะอย่างยิ่งสำหรับการตรวจสอบภาพรวม: แต่ละเซสชันมีจำนวนโทเค็นที่รวมแล้ว โมเดลที่ใช้ และค่าใช้จ่ายของตน ฟิลด์`model`เป็น JSON ดิบ:

{
  "id": "deepseek-v4-pro:cloud",
  "providerID": "ollama-cloud",
  "variant": "default"
}

ทุ่ง`cost`ในฐานข้อมูล OpenCode สะท้อนเฉพาะ*ค่าธรรมเนียม API ภายนอก*ที่ชำระตามการใช้งานผ่าน API key (Google Gemini, OpenAI ฯลฯ) เท่านั้น การเรียกผ่าน Ollama — ไม่ว่าจะเป็นแบบโลคอลหรือผ่าน Ollama Cloud Pro — จะถูกทำเครื่องหมาย`cost=0`เพราะค่าใช้จ่ายเป็นแบบเหมาจ่าย (ค่าสมาชิก) ไม่ใช่แบบต่อโทเคน ต้นทุนที่แท้จริงของการเรียกเหล่านี้คือค่าสมาชิกรายเดือน

รหัสการสกัด

ไม่จำเป็นต้องติดตั้งสิ่งใดเลย Node.js 22+ มีโมดูล SQLite แบบทดลอง (node:sqlite) ซึ่งทำงานได้อย่างสมบูรณ์แบบ นี่คือสคริปต์ที่ให้ทุกสิ่งทุกอย่างแก่ฉัน:

const { DatabaseSync } = require('node:sqlite');
const db = new DatabaseSync(
  `${process.env.HOME}/.local/share/opencode/opencode.db`,
  { readonly: true }
);

// 1. Statistiques globales
const global = db.prepare(`
  SELECT
    COUNT(*) as sessions,
    SUM(tokens_input) as total_input,
    SUM(tokens_output) as total_output,
    SUM(tokens_reasoning) as total_reasoning,
    SUM(tokens_cache_read) as total_cache_read,
    SUM(cost) as total_cost
  FROM session
`).get();

// 2. Ventilation par modèle et fournisseur
const byModel = db.prepare(`
  SELECT
    json_extract(model, '$.id') as model_id,
    json_extract(model, '$.providerID') as provider,
    COUNT(*) as sessions,
    SUM(tokens_input) as total_input,
    SUM(tokens_output) as total_output,
    SUM(cost) as total_cost
  FROM session
  WHERE model IS NOT NULL
  GROUP BY model_id, provider
  ORDER BY SUM(tokens_input) DESC
`).all();

// 3. Par mois
const monthly = db.prepare(`
  SELECT
    strftime('%Y-%m', datetime(time_created/1000, 'unixepoch')) as month,
    COUNT(*) as sessions,
    SUM(tokens_input) as total_input,
    SUM(tokens_output) as total_output,
    SUM(cost) as total_cost
  FROM session
  WHERE time_created IS NOT NULL
  GROUP BY month
  ORDER BY month
`).all();

// 4. Messages par modèle (détection des changements intra-session)
const msgByModel = db.prepare(`
  SELECT
    json_extract(m.data, '$.model.providerID') as provider,
    json_extract(m.data, '$.model.modelID') as model_id,
    COUNT(*) as messages
  FROM message m
  WHERE json_extract(m.data, '$.model') IS NOT NULL
  GROUP BY provider, model_id
  ORDER BY COUNT(*) DESC
`).all();

console.log({ global, byModel, monthly, msgByModel });
db.close();
