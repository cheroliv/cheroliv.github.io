介绍

Google Apps Script (GAS) 是一种与 Google 的多种服务（如 Google Sheets、Google Docs 和 Google Forms）关联的脚本开发平台。它可以自动化任务、添加自定义功能以及集成 Google 服务。

在这份备忘录中，我们将通过具体示例探索 Google Apps Script 的主要概念。我们将讨论诸如变量、循环、函数等概念，并还有许多其他内容，针对 GAS 的特定情境进行调整。

Google Apps Script 的基本结构

首先，让我们检查一下Google Apps脚本的基本结构。

/**
 * Structure de base en Google Apps Script
 */
function exempleStructureGAS() {
    // Votre code ici
    Logger.log("Hello, Google Apps Script!");
}

类型和变量在 Google Apps Script 中

Google Apps Script 使用 JavaScript 作为编程语言。数据类型和变量的工作方式与标准 JavaScript 类似。

/**
 * Types et Variables en Google Apps Script

function exempleTypesVariablesGAS() {
    // Votre code ici

    Logger.log(nombre);
    Logger.log(texte);
}

Google Apps Script 中的操作和运算符与 JavaScript 中的相同。

/**

 */
function exempleOperationsGAS() {
    // Votre code ici

    var resultat = x + y;
    Logger.log(resultat);

变量、let 和 const 在 Google Apps Script 中

在 GAS 中，概念的`var`, let, et `const`用于声明变量。然而，理解它们之间的差异及其影响是至关重要的。

/**
 * Var, Let et Const en Google Apps Script
 */
function exempleVarLetConstGAS() {
    // Votre code ici
    // Utilisation de var
    var x = 10;
    if (true) {
        var x = 20; // La variable x est modifiée globalement
    }
    Logger.log(x);

    // Utilisation de let
    let y = 30;
    if (true) {
        let y = 40; // La variable y est limitée au bloc if
    }
    Logger.log(y);

    // Utilisation de const
    const z = 50;
    // z = 60; // Impossible de réassigner une constante
    Logger.log(z);
}

Google Apps Script中的控制结构

控制结构例如`if`, else, while et `for`用于在 Google Apps Script 中管理执行流程。

/**
 * Structures de Contrôle en Google Apps Script
 */
function exempleStructuresControleGAS() {
    // Votre code ici
    var condition = true;

    if (condition) {
        Logger.log("La condition est vraie.");
    } else {
        Logger.log("La condition est fausse.");
    }

    var compteur = 0;
    while (compteur < 5) {
        Logger.log(compteur);
        compteur++;
    }

    for (var i = 0; i < 3; i++) {
        Logger.log(i);
    }
}

function exempleConstantesVariablesLettresGAS() {

Google Apps Script 中的循环

循环，例如`for` et while, 是遍历元素和执行重复操作所必需的。

/**
 * Boucles en Google Apps Script
 */
function exempleBouclesGAS() {
    // Votre code ici
    for (var i = 0; i < 3; i++) {
        Logger.log(i);
    }

    var condition = true;
    var compteur = 0;

    while (condition) {
        Logger.log("Tour de boucle");
        compteur++;
        if (compteur === 3) {
            condition = false;
        }
    }
}

function exempleObjetsGAS() {

Google Apps Script 中的函数

函数是编程中的基本要素。在 GAS 中，它们可以以多种方式声明和调用。

/**
 * Fonctions en Google Apps Script
 */
function exempleFonctionsGAS() {
    // Votre code ici
    function additionner(a, b) {
        return a + b;
    }

    var resultat = additionner(2, 3);
    Logger.log(resultat);

    // Fonction anonyme
    var multiplier = function (x, y) {
        return x * y;
    };

    Logger.log(multiplier(4, 5));
}

Google Apps Script 中的剩余参数和展开运算符

剩余运算符 (…​) 和传播 (…​) 对于以简洁方式操作数组和对象很有用。

/**
 * Opérateurs de Repos et de Propagation en Google Apps Script
 */
function exempleOperateursReposPropagationGAS() {
    // Votre code ici
    // Opérateur de repos (...) pour les tableaux
    var nombres = [1, 2, 3, 4, 5];
    var [...copieNombres] = nombres;
    Logger.log(copieNombres);

    // Opérateur de propagation (...) pour les objets
    var objOriginal = { x: 1, y: 2 };
    var objClone = { ...objOriginal, z: 3 };
    Logger.log(objClone);
}

在 Google Apps Script 中的解构赋值

解构赋值是一种强大的功能，允许以简洁的方式从对象和数组中提取值。

/**
 * Affectation par Décomposition en Google Apps Script
 */
function exempleAffectationDecompositionGAS() {
    // Votre code ici
    var coordonnees = [3, 4];
    var [x, y] = coordonnees;
    Logger.log(x);
    Logger.log(y);

    var utilisateur = { nom: "John", age: 30 };
    var { nom, age } = utilisateur;
    Logger.log(nom);
    Logger.log(age);
}

Google Apps Script 中的集合和声明式编程

Google Apps Script 支持诸如数组之类的数据结构，以及函数式编程和声明式迭代 (><命令式), 诸如`map`, reduce et forEach。

/**
 * Collections et Programmation Déclarative en Google Apps Script
 */
function exempleCollectionsFonctionnelleGAS() {
    // Votre code ici
    // Exemple de tableau (collection)
    var nombres = [1, 2, 3, 4, 5];

    // Utilisation de forEach
    nombres.forEach(function (nombre) {
        Logger.log(nombre);
    });

    // Utilisation de map
    var carresNombres = nombres.map(function (nombre) {
        return nombre * nombre;
    });
    Logger.log(carresNombres);

    // Utilisation de reduce
    var somme = nombres.reduce(function (acc, nombre) {
        return acc + nombre;
    }, 0);
    Logger.log(somme);
}
