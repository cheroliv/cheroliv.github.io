阅读时间 : 15 minutes

你来到一个10万行代码的项目。二十个模块，一百个类，看不见的依赖，被遗忘的重构历史。README承诺的是“微服务”架构，但代码却在说另一件事。需要多久才能变得高效？三个月— 如果你很幸运的话。而且如果一张自动生成的交互式代码图能够把这件事缩短到三天？

入职墙

每位开发者都经历过这一幕：

  1. 第1天：我们向您展示 README（最后更新：18 个月前）

  2. 第3天：您发现该模块`billing`秘密地调用该模块`notification`

  3. 第7天：一位资深人士对你说“啊哦，这个类实际上做了两件事，我们本来计划把它拆分”

  4. 第14天：您意识到所有业务智能都在`utils/LegacyHelper.java`— 一个在任何地方都未被引用的文件

什么是知识图谱？

一个 Knowledge Graph 是一种结构化的表示知道内容在您的代码库中:

实体 代码中的示例 在图中的角色

节点

类、函数、概念

图的顶点

脊

调用, 继承, 导入

两个节点之间的链接

社区

相关类组

视觉聚类

边类型

提取的，推断的，模糊的

关系中的信任

置信度得分

0.0 à 1.0

推断边的可靠性

超边

关系 3+ 节点

建筑复杂性

 
@startuml
skinparam backgroundColor #FEFEFE
skinparam classAttributeIconSize 0

package "社区 0：服务层" #Ede8f8 {
  class "LLM服务" as n0 {
    type = class
  }
  class "DiagramProcessor" as n1 {
    type = class
  }
}

package "社区1：配置" #D5f5e3 {
  class "配置加载器" as n2 {
    type = class
  }
  class "API 密钥池" as n3 {
    type = class
  }
}

n0 --> n1 : calls\nEXTRACTED
n2 ..> n3 : creates\nINFERRED (0.75)
n0 --> n2 : configures\nEXTRACTED

note right of n0
  **Hyperedge possible :**
  LlmService + DiagramProcessor + ConfigLoader
  partagent un contexte RAG
end note

@enduml

与普通UML图的区别是什么？UML 图显示了开发者 已经决定 展示的内容。知识图谱显示了 实际存在的 内容，包括隐藏的依赖关系和新兴概念。

  **Contexte perdu :**
  QuotaTracker était dans
  un module non-référencé
  dans le README

@enduml

有了知识图谱，Anaïs 就会看到在5分钟:

  • RateLimiter`与…​相关`QuotaTracker(山脊推断的, 置信度 0.82)

  • 一个超边也连接`LlmService`— 入口点

流水线：即取代码，一条命令搞定

Graphify 流水线 + Gradle 插件将您的代码库转换为 PlantUML 图 作为两个命令 :

@startuml
skinparam backgroundColor #FEFEFE
skinparam sequenceArrowThickness 2

actor "开发者" as dev
participant "绘图" as gfy
participant "graphify-out/graph.json" as json
participant "Gradle 插件" as plg
participant "KnowledgeGraphParser" as kgp
participant "知识图谱渲染器" as kgr
participant "图表/知识图谱/" as out

dev -> gfy : graphify update . --no-viz
gfy -> json : extrait nœuds, arêtes,\ncommunautés, confiances

dev -> plg : ./gradlew generateKnowledgeGraphDiagram
plg -> kgp : parse graph.json
kgp -> kgr : nodes + edges + communities
kgr -> out : génère .puml + .png

out --> dev : diagramme interactif

@enduml

零 LLM.一切都是确定性的：相同的代码、相同的图、相同的图表。可重现、可版本化、可离线查看。

边的类型：置信度所说的

@startuml
skinparam backgroundColor #FEFEFE

node "LLM服务" as ls
node "图表处理器" as dp
node "ConfigLoader" as cl
node "API 密钥池" as akp
node "遗留助手" as lh #F1948a

ls --> dp : EXTRACTED\n(calls, direct)
cl ..> akp : INFERRED 0.75\n(creates, probable)
ls -[#FF5722]-> lh : AMBIGUOUS\n(legacy, douteux)

legend right
  |= Type |= Symbole |= Signification |
  | EXTRACTED | <b>--></b> | Relation visible dans le code |
  | INFERRED | <b>..></b> | Relation déduite (score de confiance) |
  | AMBIGUOUS | <b>--x</b> | Relation incertaine, à vérifier |
endlegend

@enduml

边缘类型对入职至关重要：

  • 提取: 你可以安心地导航 — 这在代码中

  • 推断(0.6-0.8) : 可能正确，但在重构前请先验证。

  • 推断(0.8+) : 非常可靠 — 将其用作参考

  • 含糊的注意，敏感点。请向资深人士咨询。

生成您自己的知识图谱仅需 5 分钟

@startuml
skinparam backgroundColor #FEFEFE
skinparam ActivityBackgroundColor #D5f5e3

start

:pip install graphify==0.4.29;

:graphify update . --no-viz;
note right: Génère graphify-out/graph.json

:Ajouter le plugin Gradle;
note right: plugins { id("com.cheroliv.plantuml") }

:./gradlew generateKnowledgeGraphDiagram;
note right: Génère .puml + .png

:Vérifier diagrams/knowledge-graph/;
note right: knowledge-graph-full.puml\nknowledge-graph-full.png

stop

@enduml
具体命令
# 1. Installer graphify
pip install graphify==0.4.29

# 2. Générer le Knowledge Graph
graphify update . --no-viz

# 3. Vérifier le JSON
cat graphify-out/graph.json | jq '.nodes | length'
# → 47 nœuds

# 4. Générer le diagramme
./gradlew generateKnowledgeGraphDiagram

# 5. Filtrer par communauté
./gradlew generateKnowledgeGraphDiagram -Pplantuml.kg.community="service layer"

# 6. Limiter la taille
./gradlew generateKnowledgeGraphDiagram -Pplantuml.kg.maxNodes=20

局限与前景

知识图谱不是魔杖：

限制 解释 绕行

仅静态代码

没有运行时，没有数据流

补充 APM 追踪

INFERRED 可能是错误的

推断得到的边需要验证

置信度分数 + 人工审核

没有业务语义

KG 知道 “LlmService appelle ConfigLoader”, 不是 "`c’est le point d’entrée auth

手动注释或LLM后处理

没有时间性

代码的快照，而非其演变

定期生成 + 比较版本

前景:

  • 差异 KG: 比较两个版本以查看社区的迁移

  • 交互式KG : 点击一个节点 → 在对应行打开 IDE

  • 历史知识图谱可视化社区随时间的演变（迁移的技术债务）

结论

知识图谱转换一个行为孤独而漫长(理解代码库) 作为一个行为共享且快速(查看地图).

这不是文档 — 这是制图. 一张会自动更新的地图，显示真实领土，让每位开发者——无论是新手还是资深——都能自信地导航。

pip install graphify==0.4.29
graphify update . --no-viz
./gradlew generateKnowledgeGraphDiagram

3个命令。5分钟。您的代码库地图。
