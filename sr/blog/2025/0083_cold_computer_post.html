Da li osećate da vaš laptop pregreje anormalno pod Ubuntu ? Ovaj članak vam predlaže jedan pristupsoftverskiпотпуна заohladiti, прати et овлаштити температуромваше машине

Cilj ovog vodiča

  • Smanjiti globalnu temperaturu računara

  • Optimalizovati upravljanje energijom

  • Пратите критичне компоненте (CPU, GPU, итд.)

  • Spriječiti zakasnjenja zbogtermalno ograničenje

@startuml
start
:Installer les outils;
:Analyser les capteurs;
:Appliquer des réglages;
note right: cpufreq, tlp, auto-cpufreq
:Surveiller en temps réel;
stop
@enduml

Preduslov

  • Ubuntu mašina (20.04 ili više preporučena)

  • Internet veza

  • Veština u komandnoj liniji (nivo od početnog do srednjeg)

Instalirati i konfigurisati alate

lm-sensors` за детектовање сензора

sudo apt install lm-sensors
sudo sensors-detect
sensors

Оговорите`YES`svim pitanjima od`sensors-detect`за детекцију модула.

tlp` : inteligentni menadžer energije

sudo apt install tlp tlp-rdw
sudo systemctl enable tlp
sudo systemctl start tlp
@startuml
(*) --> "TLP aktivan?"
if "Да" then
  --> [yes] "Смањење потрошње"
  --> "Ograničenje frekvencije CPU"
else
  --> [no] "Pokret TLP"
  --> "Аутоматска активација"
endif
-->(*)
@enduml

cpufrequtils` : ograničiti frekvencije CPU

sudo apt install cpufrequtils
cpufreq-info
sudo cpufreq-set -g powersave

  • powersave: ograničava pikove frekvencije

  • performance: privileguje snagu na račun temperature

auto-cpufreq` : jednostavno dinamičko upravljanje

git clone https://github.com/AdnanHodzic/auto-cpufreq.git
cd auto-cpufreq
sudo ./auto-cpufreq-installer
sudo auto-cpufreq --install
@startuml
start
:Analyse charge système;
:Réglage fréquence CPU;
:Vérification température;
:Adaptation dynamique;
stop
@enduml

thermald` : automatska termička zaštita

sudo apt install thermald
sudo systemctl enable thermald
sudo systemctl start thermald

Набљуђење у реалном времену

sensors` na komandnoj liniji

watch -n 2 sensors

Opcija GUI : `psensor

sudo apt install psensor

Jednostavan grafički interfejs za CPU, GPU, ventilatore

Додатни савети

  • Zatvorite kartice i teške aplikacije (npr: preglednici)

  • Izbegavati intenzivnu upotrebu na bateriji

  • Мониторовати процесе преку`htop`:

sudo apt install htop
htop

Очистити систем за ограничавање преоптерећа

sudo apt autoremove
sudo apt autoclean
sudo journalctl --vacuum-time=3d

За да се дови

Možete da kreirate uslugu.`systemd`подешен за аутоматско применање неких подешавања при покретању. Da li želite primer u sledećem članku? Dajte mi znati!

📚 Zaključak

Kombiniranjem ovih jednostavnih alata, ćete osvojiti :

  • Управљена температура ЦПУ

  • Manje buke ventilacije

  • Bolja autonomija

Ne zaboravite da redovno kontrolisate temperature da sprečite pregrevanje.
