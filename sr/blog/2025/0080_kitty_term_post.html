Ovaj vodič objašnjava korak po korak kako instalirati terminal kitty na Xubuntu, pravilno ga konfigurisati i zamijeniti bash sa zsh kao podrazumevani shell. Projekt kitty je dostupan ovde: https://github.com/kovidgoyal/kitty.

(Empty) Kitty je modern, brz i podešiv terminal, posebno namijenjen zahtevnim programerima. __

Zašto odabrati Kitty i Zsh?

Kitty se razlikuje po:

  • Bolje performanse zahvaljujući ubrzanje GPU,

  • konfiguracija koja je potpuno bazirana na jednome tekstualnom fajlu,

  • Odlična podrška za fontove i ligature.

Zsh je, s druge strane, moćni interaktivni shell koji nudi:

  • Pametno dovršavanje,

  • Прилагођен prompt,

  • Velika kompatibilnost sa bash.

Kombinovanjem Kitty i Zsh, dobijate produktivno i estetsko okruženje.

@startuml
title Опросчена архитектура Kitty + Zsh
actor User

User --> Kitty : Lance le terminal
Kitty --> Zsh : Initialise le shell interactif
Zsh --> System : Interagit avec le système (fichiers, commandes)
@enduml

Ovaj uputnik je namerno ograničen na instalaciju preko skripte i na Xubuntu.

Preduvjeti sistema

Pre nego što počnete, uverite se da imate:

  • Xubuntu instaliran,

  • pristup internetu,

  • funkcionalna bash ljuska za pokretanje skripte.

Proverite vaše okruženje :

uname -a
lsb_release -a

Preuzimanje i instalacija Kitty

Kitty preporučuje instalaciju putem zvaničnog skripta koji smešta fajlove u`~/.local/kitty.app`.

Ova metoda je nezavisna od menadžera paketa (bez`apt`).

Preuzmite skriptu instalacije

Izvršite sledeću komandu:

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

Ова команда изврши :

  • преузимање бинарних фајлова,

  • ekstrakcija u`~/.local/kitty.app`,

  • Kreiranje simboličkih veza.

@startuml
title Preuzimanje i instalacija Kitty
start
:curl -L installer.sh;
:sh /dev/stdin;
:Décompression dans ~/.local/kitty.app;
:create symlinks;
stop
@enduml

Креирање симболичких веза

Da bi se moglo pozvati`kitty`od terminala, napravite simbolički link :

ln -s ~/.local/kitty.app/bin/kitty ~/.local/bin/kitty

Додајте`~/.local/bin`Додајте у ваш PATH ако није већ урађен :

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

Možete proveriti instalaciju :

kitty --version

Интеграција Kitty у Xubuntu

Aby se Kitty pojavila u meniju aplikacija:

Копирај фајл desktop

Копирајте фајл`.desktop`обеспечен :

cp ~/.local/kitty.app/share/applications/kitty.desktop ~/.local/share/applications/

Izmeni fajl desktop

Uredite fajl :

nano ~/.local/share/applications/kitty.desktop

Проверните или измените следеће линије :

[Desktop Entry]
Version=1.0
Type=Application
Name=Kitty Terminal
Comment=Fast GPU-based terminal emulator
Exec=/home/$USER/.local/kitty.app/bin/kitty
Icon=kitty
Categories=System;TerminalEmulator;

Zamenite`YOURUSER`вашим корисничким именом.

@startuml
title Proces integracije Kitty u meni Xubuntu
start
:Copier .desktop;
:Editer les chemins;
:Sauvegarder;
:Menu Applications;
stop
@enduml

Postavite Kitty kao podrazumevani terminal (opciono)

Da bi Kitty bio podrazumevani terminal koji se pokreće:

sudo update-alternatives --install /usr/bin/x-terminal-emulator x-terminal-emulator ~/.local/kitty.app/bin/kitty 50
sudo update-alternatives --config x-terminal-emulator

Изберите`kitty`у понуђеном мениу.

Instalacija Zsh

Ако Zsh није још инсталиран, покрените:

sudo apt install zsh

Проверите инсталацију :

zsh --version

Поставити Zsh као подразумевани шел

Mozete promeniti vash shell globalno ili samo u Kitty.

Globalna metoda (za sve terminale)

Identifikujte apsolutni put :

which zsh

Opšte`/usr/bin/zsh`.

Promenite podrazumevani shell:

chsh -s /usr/bin/zsh

Odjavite se i ponovo se prijavite.

@startuml
title Globalna promena shell
actor User

User --> Bash : Session actuelle
User --> System : chsh -s /usr/bin/zsh
System --> "/etc/passwd" : Modifie le shell
note right of "/etc/passwd" : Shell par défaut mis à jour
@enduml

Specifična metoda za Kitty

Ako želite da izmenite samo shell u Kitty-u, izmenite fajl konfiguracije :

nano ~/.config/kitty/kitty.conf

Dodajte ovu liniju:

shell zsh

Зачувајте и рестартујте Кити

Конфигурација Zsh (опционно)

Za prilagođavanje vašeg Zsh :

Kreirati datoteku .zshrc

touch ~/.zshrc
nano ~/.zshrc

Пример минималне конфигурације

export ZSH_THEME="robbyrussell"
export PATH="$HOME/.local/bin:$PATH"
alias ll="ls -la"

Shema ispod sažima cijeli proces:

Finalna proverka

Pokrenite Kitty :

kitty

Trebali biste da vidite da`zsh`је активан :

echo $SHELL

Очекиван резултат :

/usr/bin/zsh

Za promenu veličine fonta uKitty, treba podesiti parametar`font_size`у конфигурациском фајлу. Ево детаљног поступка:

📂 Отвори датотеку конфигурације

Главна конфигурацијска датотека се обично налази у :

~/.config/kitty/kitty.conf

Ако тај файл још не постоји, можете га да креирате. Пример :

nano ~/.config/kitty/kitty.conf

🖋️ Додати или изменити `font_size

Dodajte sledeću direктивu, ili je izmenite ako već postoji:

font_size 14.0

ovde`14.0`Odgovara željenoj veličini. Možete uneti bilo kterou decimalnu vrednost, na primer`12.0`, 15.5, i.t.d.

💾 Зачувај и рестартуј Kitty

  • Sačuvajte (Ctrl + O, zatim`Entrée`) i ostavite (Ctrl + X`Ako vi koristite`nano.

  • Zatvorite sve prozore Kitty, a zatim ponovo pokrenite terminal da bi promena stupila na snagu.

✅ Dinamičko podešavanje (privremeni zoom)

Ako želite privremeno da povećate/umanjite približanje bez menjanja konfiguracije, koristite podrazumevanе prečice na tastaturi :

  • Повећај величину фонта:

Ctrl + Shift + =

  • Smanji veličinu fonta:

Ctrl + Shift + -

  • Ponovno postaviti veličinu:

Ctrl + Shift + Backspace

Ove podešavanja ne ostaju posle zatvaranja terminala.

Instalacija i konfiguracija Oh My Zsh

Kada Zsh instalirate i podesite kao podrazumevani shell, možete poboljšati svoje okruženje pomoću Oh My Zsh, okvira za upravljanje Zsh konfiguracijom, koji nudi:

  • kolekcija tema za prompt

  • mnogi pluginovi,

  • jasna organizacija konfiguracije.

Instalacija Oh My Zsh

Uverite se da je Zsh aktivan:

zsh --version

Ako je potrebno, pokrenite:

zsh

Zatim preuzmite i pokrenite službeni skript za instalacija :

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

Ova skripta:

  • Napravi folder`~/.oh-my-zsh`,

  • eventualno sačuvajte svoj fajl`~/.zshrc`,

  • automatski aktivira novi prompt

Промени тему

Отворите ваш конфигурационни фајл:

nano ~/.zshrc

Izmenite promenljivu`ZSH_THEME`za izbor druge teme (na primer`agnoster`) :

ZSH_THEME="agnoster

Зачувајте онда поновите учитавање конфигурације:

source ~/.zshrc

Проверка

Pokrenite Kitty i proverite da li se prompt dobro promenio. Можете потврдити да је Oh My Zsh активан извршавањем :

echo $ZSH

Резултат треба да буде сличан:

/home/tvoj_korisnik/.oh-my-zsh

Omogućite translucentnost u Kitty

Jedna od najomiljenijih funkcija Kitty-ja je mogućnost dodavanja transparencija na pozadini terminala. Ovo omogućava da se lagano vidi podređeno okruženje (prozor, radna površina, itd.), što je poseban korisno pri multitaskingu.

Preduvjeti za prozirnost

Preglednost u Kitty-ju je zasnuta nakompozitor prozorakorišćeno od strane grafičkog okruženja. Na Xubuntu (baziran na XFCE), uverite se da jeKompozicija je aktivirana..

Проверити :

  • desni klik na radnu površinu > Podešavanja >Podešavanja menadžera prozora,

  • tabKompozitor: polje "Omogući kompoziciju" mora biti označeno.

@startuml

  usecase "Uključi kompoziciju" as UC1
}

Конфигурација прозрачности у kitty.conf

Otvorite vašu datoteku konfiguracije`~/.config/kitty/kitty.conf` :

nano ~/.config/kitty/kitty.conf

Додајте или промените следеће линије:

background_opacity 0.85

Ovaj parametar prihvata vrednosti između:

  • 1.0→ непрозоран (без прозирности)

  • 0.0→ potpuno prozirno (neupotrebljivo),

  • srednje vrednosti kao`0.90`, 0.75, itd.

Dobar vizuelni kompromis je obično između`0.85` et 0.95.

Рестартуј Кити

Zatvorite sve primere Kitty, zatim pokrenite novi prozor da bi promene učinile efekat :

kitty

Mogući dodatci

Если користите прилагођен фон терминала, можете ebenfalls подесити боју фуда са прозорношћу (у RGBA) :

background #1e1e2eff

Последна компонента (ff) ukazuje na opačnost (od`00` à ff).

poznata ograničenja

Prozirnost ne radi ako: - kompozitor XFCE je onemogućen, - nekompatibilan menadžer prozora se koristi - Koristite Kitty u tmux modu u pozadini bez podrške za transparentnost.

Onemogući zvuk (zvono za čujno)

Podrazumevano, Kitty izda zvuk bip kada se unese pogrešna komanda ili kada terminal događaj pokrene taj zvuk. Ovaj zvuk može brzo postati nervozirajući, posebno u okruženju intenzivnog razvoja.

Da biste onemogućili ovo ponašanje, dodajte sledeću direktivu u datoteku`~/.config/kitty/kitty.conf`:

audible_bell no

Можете такође да активирате визуелни поврат уместо звучног бипа са :

visual_bell yes

Ажурирање Kitty

Jer je Kitty instaliran putem skripta i ne putem menadžera paketa, ažuriranje se vrši ponovnim pokretanjem zvaničnog skripta instalacije. Ovo omogućuje preuzimanje najnovije verzije i ažuriranje vaše postojeće instalacije u`~/.local/kitty.app`.

Sufiks`.app`на путу`~/.local/kitty.app`Ово је конвенција инсталације Kitty на Linux преко његове официјалне скрипте, и не указује никако на изузетну савмесност са macOS.

Pre pokretanja komande za ažuriranje, uverite se da ste u svojom domaćem direktorijumu (~).

Izvršite sledeću komandu iz vašeg domaćeg direktorijuma :

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

Ova skripta će se zadužiti :

  • Preuzmite binarne datoteke nove verzije.

  • Извлекти датотеке у`~/.local/kitty.app`.

  • Ažurirajte simboličke veze ako je potrebno.

Posle ažuriranja preporučuje se da se zatvore sve instance Kitty-ja i ponovo pokrenu, da bi se osiguralo da je nova verzija pravilno primenjena.
