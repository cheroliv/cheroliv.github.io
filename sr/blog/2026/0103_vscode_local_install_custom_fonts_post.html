Zašto instalirati VS Code u`/opt`ili putem`apt`kada možete da ga postavite kod kuće i pretvorite svoj IDE u teren za igru bez ikakvog kucanja`sudo`? Ovo je priča o lokalnoj instalaciji praćena nevlažnom borbom za povećanje fontova menija i esplorera datoteka.

Преглед путање

Зашто: VS Code у кући

Problem sa instalacijom sistema

VS Code instaliran putem`apt`, dnf`или у/opt`zaključuje fajlove aplikacije iza root privilegija. Svaka promena nativnog CSS-a, od`product.json`ili direktorijum instalacije zahteva`sudo`.

Ali, kada se koristiopencode(tool CLI za upravljanje LLM na svom kodu), agent mora moći da :

  • Уписати у датотеке конфигурације (~/.config/Code/User/settings.json) — ovo je veću home

  • izmenite resurse IDE-a (CSS radne površine,product.json) za napredna prilagođavanja — to je blokirano bez sudo

Решение: локална инсталација

Preuzima se službena tarball arhiva i ona se direktno razkompresuje u`~/apps/`(No visible content)

mkdir -p ~/apps
cd ~/apps
wget "https://code.visualstudio.com/sha/download?build=stable&os=linux-x64" -O vscode.tar.gz
tar -xzf vscode.tar.gz
rm vscode.tar.gz

Бинар се онда налази у`~/apps/VSCode-linux-x64/bin/code`. Nijedan`sudo`Nije potrebno čitanje, izmena ili zamena bilo kojeg fajla ispod.~/apps/VSCode-linux-x64/.

Prilagoditi font glavnog menija

Utvrđenje

Podrazumni font glavnog menija (File, Edit, View…​) i padajućih menija je previše mali. VS Code ne nudi nikako podesavanje za njegovo menjanje.

Техника : директни CSS патч

Додајемо CSS на крај фајла`workbench.desktop.main.css`:

CSS_FILE="$HOME/apps/VSCode-linux-x64/resources/app/out/vs/workbench/workbench.desktop.main.css"

cat >> "$CSS_FILE" << 'EOF'
.menubar-menu-title{font-size:23px!important}
.menubar>.menubar-menu-button{font-size:23px!important}
.monaco-menu-option{font-size:22px!important;line-height:34px!important}
.monaco-menu .action-label:not(.codicon){font-size:22px!important}
.menubar-menu-items-holder .monaco-menu .action-item .action-label{font-size:22px!important}
EOF

Ukloni upozorenje o integritetu

VS Code detektuje izmenе svojih fajlova i prikazuje traku "Your installation is corrupt". Da bi se spriječilo, uklanja se kontrolna suma od`product.json` :

import json
product_json = "$HOME/apps/VSCode-linux-x64/resources/app/product.json"
with open(product_json, 'r') as f:
    data = json.load(f)
data.pop('checksums', None)
with open(product_json, 'w') as f:
    json.dump(data, f, indent=2)

Nakon ponovnog pokretanja više nema upozorenja i meni su konačno čitljivi.

Podesi font okvira Explorer — borba

Pokušaj 1 : parametar koji ne postoji

Прво покушавамо натИвни параметар.workbench.tree.fontSize`у`settings.json(blank)

{
    "workbench.tree.fontSize": 20
}

Резултат :nema efekta. Ovaj parametar ne postoji u VS Code. Dokaz da su neprepoznati parametri tiho zanemareni.

Покушај 2: dodatak Custom CSS and JS Loader

Инсталирамо проширење`be5invis.vscode-custom-css`:

~/apps/VSCode-linux-x64/bin/code --install-extension be5invis.vscode-custom-css

Se pravi CSS fajl u`~/.vscode-custom-css/custom.css`sa selektorima koji ciljaju na elemente eksplorera :

.monaco-tree-rows .monaco-tree-row,
.sidebar .monaco-list-row,
.explorer-viewlet .monaco-list-row,
.monaco-list-row .monaco-icon-label {
    font-size: 22px !important;
    line-height: 36px !important;
}

Наводимо датотеку у подешавањима:

{
    "vscode_custom_css.imports": [
        "file:///home/user/.vscode-custom-css/custom.css"
    ]
}

Rezultat :Izmene se ne primenjuju..

Zalov : morate aktivirati dodatak svaki put

Dokumentacija dodatka je skromna na ovom ključnom pitanju: nakon svake modifikacije prilagođenog CSS-a, trebaobaveznoIzvrši komandu iz palete :

  1. Ctrl+Shift+P→ ukucatiOmogući prilagođeni CSS i JS

  2. VS Code требује рестарт → прихвати

Bez ovog koraka, CSS nikad nije injektovan u IDE.

Pokušaj 3 : linije se preklapaju

Чак и са`font-size: 22px` et line-height: 36px, Slova s nogama (g, p, f, b) izlaze na susedne redove. Pokušavaju da dodaju`height` et min-height :

.monaco-list-row {
    height: 36px !important;
    min-height: 36px !important;
}

Резултат :нема промене. VS Code računa visine redova u JavaScript-u i nadjačava vrednosti CSS.

Решение : zoom на родитељем контејнере

Umesto da se bori protiv JavaScript layota, koristi se svojstvo.`zoom`Na kontejneru linija :

.explorer-viewlet .monaco-list-rows,
.sidebar .monaco-list-rows {
    zoom: 1.25;
}

`zoom`Jednako povećava prikaz kontejnera — tekst i razmak — ne pokvarajući izračunati layout od strane JavaScript motora VS Code. Faktor 1.25 odgovara prijelazu s 13 px na 16 px.

Rezultat :Imena datoteka su konačno čitljiva, linije su pravilno razmaknuta.(empty)

Сажетак селектора и шта ради

Приступ CSS Rezultat

Veći tekst ali preklapaće linije

line-height+height`на.monaco-list-row`

Skript za automatsko ažuriranje

Problem

Kad VS Code se ažurira, on menja folder instalacije iobriši sve CSS zakrpe. Treba ručno ponovo primeniti izmene svaki put.

Скрипт `vscode-update.sh

Pravi se`~/apps/vscode-update.sh`(Empty output)

#!/bin/bash
set -e

VSCODE_DIR="$HOME/apps/VSCode-linux-x64"
BACKUP_DIR="$HOME/apps/vscode-backup"
TEMP_DIR="/tmp/vscode-update"

MENUBAR_FONT_SIZE="23px"
DROPDOWN_FONT_SIZE="22px"

echo "=== VS Code Local Updater ==="

CURRENT_VERSION=$("$VSCODE_DIR/bin/code" --version 2>/dev/null | head -1)
echo "Current version: $CURRENT_VERSION"

echo "Downloading latest VS Code..."
mkdir -p "$TEMP_DIR"
wget -q "https://code.visualstudio.com/sha/download?build=stable&os=linux-x64" \
    -O "$TEMP_DIR/vscode.tar.gz"

echo "Extracting..."
mkdir -p "$TEMP_DIR/extracted"
tar -xzf "$TEMP_DIR/vscode.tar.gz" -C "$TEMP_DIR/extracted"

NEW_VERSION=$("$TEMP_DIR/extracted/VSCode-linux-x64/bin/code" \
    --version 2>/dev/null | head -1)
echo "New version: $NEW_VERSION"

if [ "$CURRENT_VERSION" = "$NEW_VERSION" ]; then
    echo "Already up to date!"
    rm -rf "$TEMP_DIR"
    exit 0
fi

echo "Backing up current installation..."
mkdir -p "$BACKUP_DIR"
cp -r "$VSCODE_DIR" "$BACKUP_DIR/VSCode-linux-x64-$(date +%Y%m%d-%H%M%S)"

echo "Updating..."
rm -rf "$VSCODE_DIR"
mv "$TEMP_DIR/extracted/VSCode-linux-x64" "$VSCODE_DIR"
rm -rf "$TEMP_DIR"

CSS_FILE="$VSCODE_DIR/resources/app/out/vs/workbench/workbench.desktop.main.css"
echo "Re-applying custom CSS patch \
    (menubar=${MENUBAR_FONT_SIZE}, dropdown=${DROPDOWN_FONT_SIZE})..."
cat >> "$CSS_FILE" << CSSEOF
.menubar-menu-title{font-size:${MENUBAR_FONT_SIZE}!important}\
.menubar>.menubar-menu-button{font-size:${MENUBAR_FONT_SIZE}!important}\
.monaco-menu-option{font-size:${DROPDOWN_FONT_SIZE}!important;\
line-height:34px!important}\
.monaco-menu .action-label:not(.codicon)\
{font-size:${DROPDOWN_FONT_SIZE}!important}\
.menubar-menu-items-holder .monaco-menu .action-item .action-label\
{font-size:${DROPDOWN_FONT_SIZE}!important}
CSSEOF

PRODUCT_JSON="$VSCODE_DIR/resources/app/product.json"
if [ -f "$PRODUCT_JSON" ]; then
    echo "Removing checksums to prevent integrity warning..."
    python3 -c "
import json
with open('$PRODUCT_JSON','r') as f: data=json.load(f)
data.pop('checksums', None)
with open('$PRODUCT_JSON','w') as f: json.dump(data,f,indent=2)
print('Done.')
"
fi

echo "=== Update complete: $CURRENT_VERSION -> $NEW_VERSION ==="

Скрипта :

  1. Preuzmi najnoviju stabilnu verziju

  2. Proveri da li verzija razlikuje se od trenutne.

  3. Сачувај тренутну инсталацију (означену временском ознаком) у`~/apps/vscode-backup/`

  4. Zameni instalacioni folder

  5. Поново примениCSS popravak glavnog menija

  6. Сбриши чексуме de `product.json`da se izbegne upozorenje o integritetu

Prilagođavanja okvira Explorer preko Custom CSS ekstenzije i datoteke`~/.vscode-custom-css/custom.css`Они преживају ажурирања јер живе изван фасцикле за инсталацију.

Naučene lekcije

Инсталирати у $HOME ослобађа све

Lokalna instalacija u`~/apps`даје повну контролу над VS Code:

  • Nema`sudo`za izmenu CSS-a ili konfiguracije

  • Agent opencode+LLM može pisati u fajlove konfiguracije i assete IDE‑a.

  • Trivijalno vraćanje: vračanje datirane rezervne kopije

zoom` > font-size za komponente liste

VS Code контролише висину редова користећи JavaScript. Измени`font-size`Mogućnost menjanja visine alokovane od strane motora za layout nedostaje, što rezultuje prečavanjem teksta. Svojstvo`zoom`Na roditeljskom kontejneru sve se proporcionalno povećava i obilazi ovaj problem.

Ekstenzija Custom CSS zahteva eksplicitnu aktivaciju.

Nije postavka "postavi i zaboravi". Svaka promena u fajlu custom CSS zahteva da ponovo pokrenete "Enable Custom CSS and JS" iz paleti komandi.Ctrl+Shift+P).

Skript za ažuriranje je neophodan

Bez skripte, svako ažuriranje VS Code briše CSS zakrpe radne površine. Skripta`vscode-update.sh`Automatizuje preuzimanje, zamenu, re-patch i čišćenje checksumova.
