Vreme čitanja : 15 minutes

Stižete na projekat od 100 000 linija. Dvadeset modula, stotina klasa, nevidljive zavisnosti, istorija zaboravljenih refaktoringa. README obećava arhitekturu „microservices“ ali kod priča nešto drugo. Koliko vremena je potrebno da postanete produktivni?Три месеца— ako срећете. А да ли interaktivna karta koda, generisana automatski, mogla bi da smanji ovo na tri dana ?

Zid onboarding

Svaki programer je proživio ovu scenu:

  1. Dan 1: pokazujemo vam README (poslednje ažuriranje: pre 18 meseci)

  2. Dan 3 : otkrivate da je modul`billing`Tajno pozva modul`notification`

  3. Dan 7: stariji vam kaže: "Ah da, ovaj klas zaista radi dve stvari, planirali smo da je podijelimo.

  4. Dan 14: realizujete da je sva poslovna inteligencija u`utils/LegacyHelper.java`— datoteka koja nije referencirana nigde

skinparam backgroundColor #FEFEFE

Problem nije nedostatak dokumentacije — jestenedostatak karte. Karta koja prikazuje stvarni teritorij, ne izmišljeni teritorij poslednjeg preoblikovanja.

  • QuotaTracker`povezano je sa`ApiKeyPool(rebroизузет)

  • RateLimiter`je vezan za`QuotaTracker(ивица)заключен, poverenje 0.82)

  • Hiperveza povezuje i`LlmService`— ulazna tačka

Pipeline : kod po meri u jednoj komandi

Cevovod Graphify+Gradle plugin transformiše vašu kodnu bazu u dijagram PlantUML uдве наруџбе:

@startuml
skinparam backgroundColor #FEFEFE
skinparam sequenceArrowThickness 2

actor "Razvijar" as dev
participant "graficirati" as gfy
participant "graphify-out/graph.json" as json
participant "Gradle dodatak" as plg
participant "KnowledgeGraphParser" as kgp
participant "KnowledgeGraphRenderer" as kgr
participant "diagrams/knowledge-graph/" as out

dev -> gfy : graphify update . --no-viz
gfy -> json : extrait nœuds, arêtes,\ncommunautés, confiances

dev -> plg : ./gradlew generateKnowledgeGraphDiagram
plg -> kgp : parse graph.json
kgp -> kgr : nodes + edges + communities
kgr -> out : génère .puml + .png

out --> dev : diagramme interactif

@enduml

Nula LLM.Sve je determinističko: isti kod, isti graf, isti dijagram. Reproduktivno, verzionabilno, konsultabilno offline.

Типови ивица: шта кажут poverenje

@startuml
skinparam backgroundColor #FEFEFE

node "LlmService" as ls
node "DiagramProcessor" as dp
node "ConfigLoader" as cl
node "pul API ključeva" as akp
node "LegacyHelper" as lh #F1948a

ls --> dp : EXTRACTED\n(calls, direct)
cl ..> akp : INFERRED 0.75\n(creates, probable)
ls -[#FF5722]-> lh : AMBIGUOUS\n(legacy, douteux)

legend right
  |= Type |= Symbole |= Signification |
  | EXTRACTED | <b>--></b> | Relation visible dans le code |
  | INFERRED | <b>..></b> | Relation déduite (score de confiance) |
  | AMBIGUOUS | <b>--x</b> | Relation incertaine, à vérifier |
endlegend

@enduml

Tipovi grana su ključni za onboarding:

  • EXTRACTED: ti možeš navigirati mirno — to je u kodu

  • izvedeno(0.6-0.8): вероватно тачно, али провери пре рефакторинга

  • ЗАКЛЮЧЕН(0.8+) : veoma pouzdan — koristi ga kao referencu

  • AMBIGUOUS: pažnja, osjetljiva tačka. Zatraži od starijeg.

5 minuta da generiši svoj vlastiti Knowledge Graph

@startuml
skinparam backgroundColor #FEFEFE
skinparam ActivityBackgroundColor #D5f5e3

start

:pip install graphify==0.4.29;

:graphify update . --no-viz;
note right: Génère graphify-out/graph.json

:Ajouter le plugin Gradle;
note right: plugins { id("com.cheroliv.plantuml") }

:./gradlew generateKnowledgeGraphDiagram;
note right: Génère .puml + .png

:Vérifier diagrams/knowledge-graph/;
note right: knowledge-graph-full.puml\nknowledge-graph-full.png

stop

@enduml
Конкретне команде
# 1. Installer graphify
pip install graphify==0.4.29

# 2. Générer le Knowledge Graph
graphify update . --no-viz

# 3. Vérifier le JSON
cat graphify-out/graph.json | jq '.nodes | length'
# → 47 nœuds

# 4. Générer le diagramme
./gradlew generateKnowledgeGraphDiagram

# 5. Filtrer par communauté
./gradlew generateKnowledgeGraphDiagram -Pplantuml.kg.community="service layer"

# 6. Limiter la taille
./gradlew generateKnowledgeGraphDiagram -Pplantuml.kg.maxNodes=20

Granice i perspektive

Knowledge Graph nije čarobni štapić:

ограничење објашњение Obilazak

Само статични код

Nema runtime, nema toka podataka

Dopuniti sa APM trace-ovima

INFERRED može biti lažan

Izvedene rubove zahtevaju validaciju

Ocena poverenja + čovečji pregled

Nema poslovne semantike

KG zna LlmService appelle ConfigLoader, nije `c’est le point d’entrée auth

Ručne anotacije ili LLM post-obrada

Bez temporalnosti

Snimak koda, ne njegov razvoj

Генерисати редовно + поређивати верзије

Перспективе:

  • Razlika KG: пореди две верзије да видиш премештања заједниста

  • interaktivni KG: klik na čvor → otvaranje IDE na odgovornoj liniji

  • istorijski KG: визуализовати еволуцију заједница у времену (технички дуг који мигрира)

Закључак

Knowledge Graph transformiše jedan akt.један и дугак(razumevanje baze koda) u jednom aktapodeljeno i brzo(погледај мапу).

Ово није документација — ово јекартографија. Karte koja se automatski ažurira, koja prikazuje stvarni teren, i koja omogućava svakom programeru, novom ili iskusnom, da navigira s pouzdanjem.

pip install graphify==0.4.29
graphify update . --no-viz
./gradlew generateKnowledgeGraphDiagram

3 komande. 5 minuta. Karta vaše kodne baze.
