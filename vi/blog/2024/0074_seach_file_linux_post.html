Πρακτικός οδηγός: Αναζήτηση αρχείων στο Linux

Εισαγωγή

Το πρόβλημα : Αναζητήστε αρχεία σε ένα σύστημα Linux μέσω του τερματικού.

Στο παρόν άρθρο, θα εξερευνήσουμε πώς να αναζητήσουμε ένα αρχείο στο Ubuntu χρησιμοποιώντας ένα τερματικό Zsh. Το Zsh (Z shell) είναι ένα ισχυρό διερμηνέα εντολών που χρησιμοποιείται ευρέως λόγω της ευελιξίας του και των προχωρημένων λειτουργιών του.

Ubuntu, μια δημοφιλής διανομή Linux, προσφέρει αρκετά εργαλεία γραμμής εντολών για να αναζητήσετε αρχεία. Θα δούμε πώς να χρησιμοποιήσουμε εντολές όπως`find`, locate et `grep`για να εντοπίζετε αρχεία γρήγορα και αποτελεσματικά στο τερματικό.

Χρήση της εντολής `find

Η εντολή`find`Επιτρέπει την αναζήτηση αρχείων σε έναν συγκεκριμένο κατάλογο και τα υποκαταλόγους του. Η βασική σύνταξή του είναι η εξής:

find [chemin] -name [nom_du_fichier]

Εδώ είναι ένα πρακτικό παράδειγμα όπου ψάχνουμε για ένα αρχείο με όνομα`example.txt`στο φάκελο`/home`:

find /home -name "example.txt"

Αυτή η εντολή θα διατρέξει όλους τους υποφακέλους του`/home`και εμφανίστε την πλήρη διαδρομή του αρχείου αν βρεθεί.

Στο διαδικτυακό εγχειρίδιο της εντολής`find`:https://man.archlinux.org/man/find.1.fr/[man find,windows=read-later]*

Επιπλέον επιλογές για `find

Η εντολή`find`είναι πολύ ισχυρή και διαθέτει πολλές επιλογές. Εδώ είναι μερικά χρήσιμα παραδείγματα:

  • Αναζήτηση ανά τύπο αρχείουΓια να αναζητήσετε μόνο αρχεία, χρησιμοποιήστε`-type f`, και για να αναζητήσετε καταλόγους, χρησιμοποιήστε`-type d`. - Αναζήτηση ανά μέγεθοςΜπορείτε επίσης να φιλτράρετε τα αρχεία βάσει του μεγέθους τους χρησιμοποιώντας την επιλογή`-size`. Par exemple, pour rechercher des fichiers de plus de 100 Mo, utilisez :

find /home -size +100M

Χρήση της εντολής `locate

Η εντολή`locate`είναι πιο γρήγορο από`find`διότι χρησιμοποιεί μια προ-διατεταγμένη βάση δεδομένων των αρχείων που είναι παρόντα στο σύστημα. Πρέπει πρώτα να ενημερώσετε αυτή τη βάση δεδομένων με την ακόλουθη εντολή:

sudo updatedb

Επειτα, μπορείτε να αναζητήσετε ένα αρχείο όπως εδώ:

locate example.txt

Χρήση της εντολής grep για αναζήτηση κειμένου σε αρχεία

Εάν θέλετε να αναζητήσετε ένα συγκεκριμένο κείμενο σε ένα αρχείο, μπορείτε να χρησιμοποιήσετε`grep`. Για παράδειγμα, για να βρείτε την εμφάνιση της λέξης "Ubuntu" σε όλα τα αρχεία`.txt`από τον τρέχοντα κατάλογο, χρησιμοποιήστε :

grep "Ubuntu" *.txt

Συμπέρασμα

Η αναζήτηση αρχείων σε Ubuntu μέσω τερματικού Zsh μπορεί να γίνει με τη χρήση διάφορων ισχυρών εργαλείων.`find`είναι ευέλικτο και προσφέρει μια ποικιλία επιλογών, ενώ`locate`επιτρέπει μια γρήγορη αναζήτηση με τη χρήση μιας προκατασκευασμένης βάσης δεδομένων. Τέλος,`grep`επιτρέπει να βρείτε εμφανίσεις κειμένου εντός των αρχείων.

Αυτές οι εντολές σας προσφέρουν μια πλήρη σειρά εργαλείων για να κάνετε τις αναζητήσεις αρχείων σας πιο αποτελεσματικές και προσαρμοσμένες στις ανάγκες σας, και κάθε μία από αυτές τις εντολές έχει ένα εγχειρίδιο που είναι ορατό με την εντολή.man
