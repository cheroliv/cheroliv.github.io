Làm mát và theo dõi nhiệt độ laptop trên Ubuntu

Đăng ngày 15 July 2025

Bạn cảm thấy máy tính xách tay của mình nóng lên bất thường khi chạy Ubuntu? Bài viết này đề xuất cho bạn một quy trìnhphần mềmđầy đủ cholàm lạnh, giám sát et kiểm soát nhiệt độcủa máy bạn.

Mục tiêu của hướng dẫn này

  • Giảm nhiệt độ tổng thể của máy tính

  • Tối ưu hóa quản lý năng lượng

  • Giám sát các thành phần quan trọng (CPU, GPU, v.v.)

  • Tránh tình trạng chậm trễ dotiết giảm nhiệt (thermal throttling)

Điều kiện tiên quyết

  • Một máy Ubuntu (khuyến nghị bản 20.04 hoặc cao hơn)

  • Kết nối Internet

  • Kỹ năng dòng lệnh (trình độ từ cơ bản đến trung cấp)

Cài đặt và cấu hình các công cụ

lm-sensors` để phát hiện các cảm biến

sudo apt install lm-sensors
sudo sensors-detect
sensors

Trả lời`YES`cho tất cả các câu hỏi của`sensors-detect`để phát hiện các module.

tlp` : trình quản lý năng lượng thông minh

sudo apt install tlp tlp-rdw
sudo systemctl enable tlp
sudo systemctl start tlp

cpufrequtils` : giới hạn tần số CPU

sudo apt install cpufrequtils
cpufreq-info
sudo cpufreq-set -g powersave

  • powersave: giới hạn các đỉnh tần số

  • performance: ưu tiên hiệu suất hơn nhiệt độ

auto-cpufreq` : quản lý động đơn giản hóa

git clone https://github.com/AdnanHodzic/auto-cpufreq.git
cd auto-cpufreq
sudo ./auto-cpufreq-installer
sudo auto-cpufreq --install

thermald` : bảo vệ nhiệt tự động

sudo apt install thermald
sudo systemctl enable thermald
sudo systemctl start thermald

Giám sát thời gian thực

sensors` trong dòng lệnh

watch -n 2 sensors

Tùy chọn GUI : `psensor

sudo apt install psensor

Giao diện đồ họa đơn giản cho CPU, GPU, quạt.

Mẹo bổ sung

  • Đóng các thẻ và ứng dụng nặng (ví dụ: trình duyệt)

  • Tránh sử dụng cường độ cao khi dùng pin

  • Theo dõi các tiến trình thông qua`htop`Vui lòng cung cấp văn bản tiếng Pháp cần dịch.

sudo apt install htop
htop

Dọn dẹp hệ thống để hạn chế tình trạng quá tải

sudo apt autoremove
sudo apt autoclean
sudo journalctl --vacuum-time=3d

Để tìm hiểu thêm

Bạn có thể tạo một dịch vụ`systemd`tùy chỉnh để tự động áp dụng một số cài đặt khi khởi động. Bạn có muốn một ví dụ trong bài viết tới không? Hãy cho tôi biết nhé!

📚 Kết luận

Bằng cách kết hợp các công cụ đơn giản này, bạn sẽ đạt được:

  • Nhiệt độ CPU được kiểm soát

  • Ít tiếng ồn quạt thông gió hơn

  • Thời lượng pin tốt hơn

Đừng quên theo dõi nhiệt độ thường xuyên để ngăn ngừa tình trạng quá nhiệt.
