Introducción

Google Apps Script (GAS) es una plataforma de desarrollo de scripts asociada a diversos servicios de Google, como Google Sheets, Google Docs y Google Forms. Permite automatizar tareas, agregar funcionalidades personalizadas e integrar servicios de Google.

En este memorándum, vamos a explorar los conceptos principales de Google Apps Script apoyándonos en ejemplos concretos. Abordaremos nociones como las variables, los bucles, las funciones y mucho más, adaptándolas al contexto específico de GAS.

Estructura básica en Google Apps Script

Para empezar, examinemos la estructura básica de un script de Google Apps.

/**
 * Structure de base en Google Apps Script
 */
function exempleStructureGAS() {
    // Votre code ici
    Logger.log("Hello, Google Apps Script!");
}

Tipos y variables en Google Apps Script

Google Apps Script utiliza JavaScript como lenguaje de programación. Los tipos de datos y las variables funcionan de manera similar a JavaScript estándar.

/**
 * Types et Variables en Google Apps Script
 */
function exempleTypesVariablesGAS() {
    // Votre code ici
    var nombre = 42;
    var texte = "Bonjour, Google Apps Script!";
    Logger.log(nombre);
    Logger.log(texte);
}

Operaciones y Operadores en Google Apps Script

Las operaciones y operadores en Google Apps Script son los mismos que en JavaScript.

/**
 * Opérations et Opérateurs en Google Apps Script
 */
function exempleOperationsGAS() {
    // Votre code ici
    var x = 10;
    var y = 5;
    var resultat = x + y;
    Logger.log(resultat);
}

Var, Let y Const en Google Apps Script

En GAS, los conceptos de`var`, let, et `const`se utilizan para declarar variables. Sin embargo, es esencial comprender sus diferencias e implicaciones.

/**
 * Var, Let et Const en Google Apps Script
 */
function exempleVarLetConstGAS() {
    // Votre code ici
    // Utilisation de var
    var x = 10;
    if (true) {
        var x = 20; // La variable x est modifiée globalement
    }
    Logger.log(x);

    // Utilisation de let
    let y = 30;
    if (true) {
        let y = 40; // La variable y est limitée au bloc if
    }
    Logger.log(y);

    // Utilisation de const
    const z = 50;
    // z = 60; // Impossible de réassigner une constante
    Logger.log(z);
}

Estructuras de Control en Google Apps Script

Las estructuras de control tales como`if`, else, while et `for`son utilizadas para gestionar el flujo de ejecución en Google Apps Script.

/**
 * Structures de Contrôle en Google Apps Script
 */
function exempleStructuresControleGAS() {
    // Votre code ici
    var condition = true;

    if (condition) {
        Logger.log("La condition est vraie.");
    } else {
        Logger.log("La condition est fausse.");
    }

    var compteur = 0;
    while (compteur < 5) {
        Logger.log(compteur);
        compteur++;
    }

    for (var i = 0; i < 3; i++) {
        Logger.log(i);
    }
}

Parámetros y ámbitos en Google Apps Script

Los parámetros y los scopes juegan un papel crucial en el desarrollo de scripts en GAS. Comprende cómo funcionan para evitar comportamientos inesperados.

/**
 * Paramètres et Scopes en Google Apps Script
 */
function exempleParametresScopesGAS(parametre) {
    // Votre code ici
    var variableGlobale = "Je suis global";

    function afficherParametre() {
        Logger.log(parametre);
    }

    afficherParametre();

}

Constantes, Variables y Letras en Google Apps Script

Entender la diferencia entre`const`, var, et `let`es esencial para un uso eficaz de las variables en Google Apps Script.

/**
 * Constantes, Variables, et Lettres en Google Apps Script
 */
function exempleConstantesVariablesLettresGAS() {
    // Votre code ici
    const constante = "Je ne change pas";
    Logger.log(constante);

    var variable = "Je peux changer";
    Logger.log(variable);

    let lettre = "Je peux aussi changer, mais seulement dans mon bloc";
    Logger.log(lettre);
}

Bucles en Google Apps Script

Los bucles, tales como`for` et while, son esenciales para iterar sobre elementos y realizar operaciones repetitivas.

/**
 * Boucles en Google Apps Script
 */
function exempleBouclesGAS() {
    // Votre code ici
    for (var i = 0; i < 3; i++) {
        Logger.log(i);
    }

    var condition = true;
    var compteur = 0;

    while (condition) {
        Logger.log("Tour de boucle");
        compteur++;
        if (compteur === 3) {
            condition = false;
        }
    }
}

Funciones en Google Apps Script

Las funciones son elementos fundamentales en la programación. En GAS, pueden declararse y llamarse de distintas maneras.

/**
 * Fonctions en Google Apps Script
 */
function exempleFonctionsGAS() {
    // Votre code ici
    function additionner(a, b) {
        return a + b;
    }

    var resultat = additionner(2, 3);
    Logger.log(resultat);

    // Fonction anonyme
    var multiplier = function (x, y) {
        return x * y;
    };

    Logger.log(multiplier(4, 5));
}

Operadores de repos y de propagación en Google Apps Script

Los operadores de repos`…​) y de propagación (…​`) son útiles para manipular los arrays y los objetos de manera concisa.

/**
 * Opérateurs de Repos et de Propagation en Google Apps Script
 */
function exempleOperateursReposPropagationGAS() {
    // Votre code ici
    // Opérateur de repos (...) pour les tableaux
    var nombres = [1, 2, 3, 4, 5];
    var [...copieNombres] = nombres;
    Logger.log(copieNombres);

    // Opérateur de propagation (...) pour les objets
    var objOriginal = { x: 1, y: 2 };
    var objClone = { ...objOriginal, z: 3 };
    Logger.log(objClone);
}

Asignación por desestructuración en Google Apps Script

La asignación por desestructuración es una característica poderosa que permite extraer valores de objetos y arrays de forma concisa.

/**
 * Affectation par Décomposition en Google Apps Script
 */
function exempleAffectationDecompositionGAS() {
    // Votre code ici
    var coordonnees = [3, 4];
    var [x, y] = coordonnees;
    Logger.log(x);
    Logger.log(y);

    var utilisateur = { nom: "John", age: 30 };
    var { nom, age } = utilisateur;
    Logger.log(nom);
    Logger.log(age);
}

Colecciones y Programación Declarativa en Google Apps Script

Google Apps Script admite estructuras de datos como los arreglos, y conceptos de programación funcional y de iteración declarativa (><imperativa), como`map`, reduce et forEach.

/**
 * Collections et Programmation Déclarative en Google Apps Script
 */
function exempleCollectionsFonctionnelleGAS() {
    // Votre code ici
    // Exemple de tableau (collection)
    var nombres = [1, 2, 3, 4, 5];

    // Utilisation de forEach
    nombres.forEach(function (nombre) {
        Logger.log(nombre);
    });

    // Utilisation de map
    var carresNombres = nombres.map(function (nombre) {
        return nombre * nombre;
    });
    Logger.log(carresNombres);

    // Utilisation de reduce
    var somme = nombres.reduce(function (acc, nombre) {
        return acc + nombre;
    }, 0);
    Logger.log(somme);
}
