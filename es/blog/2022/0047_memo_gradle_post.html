Mostrar la ayuda

./gradlew --help

Definir la propiedad del sistema de la JVM: `-D, --system-prop

./gradlew -Dmyprop=myvalue
#ou
./gradlew --system-prop myvalue

Definir la propiedad del proyecto para el script de construcción: `-Pmyprop=myvalue

./gradlew -Pmyprop=myvalue
#ou
./gradlew --project-prop myvalue

Especifica el directorio de inicio de Gradle. El valor predeterminado es el directorio actual.

./gradlew -p ~/src/next_startup
#ou
./gradlew --project-dir ~/src/next_startup

Sobreescribir la property 'param_component' mediante la línea de comando :

./gradlew -Pparam_component=CUSTOM_VALUE

Agregar una carpeta a un source-set en un proyecto normal con Kotlin DSL

sourceSets {
    getByName("test"){
        java.srcDir("src/scripts/groovy")
    }
    getByName("test"){
        java.srcDir("src/scripts/kscript")
    }
    getByName("test"){
        java.srcDir("src/test/javascript")
    }
}

Añadir una carpeta a un conjunto de fuentes en un proyecto Android con el DSL de Groovy

android {
    sourceSets {
        main.java.srcDirs += "src/main/../../../../ceelo/domain/src/main/java/"
        test.java.srcDirs += "src/test/../../../../ceelo/domain/src/test/java/"
    }
}

Evitar construir y probar un submódulo

gradle build -x :excluded-module:check -x :excluded-module:assemble -x :excluded-module:build

Mover archivos
tasks.register("moveWebappNode") {
    doLast {
        ant.withGroovyBuilder {
            "move"(
                "webapp/node_modules" to "$rootDir/webapp-src/node_modules",
            )
        }
    }
}

Tar una carpeta

tasks.register<Tar>("tarWebapp") {
    dependsOn("moveWebappNpm")
    group = WEBAPP
    description = "tar webapp"
    doLast {
        setOf(
            "build",
            "target",
            "node_modules"
        ).forEach { dir -> exclude { it.name .dir } }
        archiveFileName.set("webapp.tar")
        destinationDirectory.set(File("${rootDir.absolutePath}$sep$WEBAPP_SRC"))
    }
}

Mostrar las dependencias de una compilación

tasks.register("printDependencies") {
    description = "print project dependencies"
    group = WEBAPP
    doLast {
        println("${project.name} dependencies")
        mutableMapOf<String, Map<String, String>>(
            "buildDependencies" to buildDependencies,
            "domainDeps" to domainDeps,
            "domainTestDeps" to domainTestDeps,
        ).apply { putAll(appModules) }
            .forEach { module ->
                if (module.value.isNotEmpty()) {
                    println("${module.key}:")
                    module.value.forEach { println(dependency(it)) }
                    println()
                }
            }
    }
}

Ejemplo de uso de reduce : concatenación de una lista en una cadena

tasks.register("printWebappSrc") {
    description = "print webapp sources"
    group = WEBAPP
    doLast {
        webAppSrc
            .reduce { acc, s -> "$acc\n\t$s" }
            .run { println("$WEBAPP_SRC: $this\n") }
    }
}

Obtener la descripción de una tarea en particular

./gradlew -q help --task foo

Para lanzar una tarea desde el workingDir root, entonces prefija la tarea con un `:

./gradlew :foo

Para volver a ejecutar las tareas que fallaron, utilice la opción `--rerun-tasks

./gradlew check --rerun-tasks

Lanzar una tarea en un proyecto específico desde otro directorio

La opción`-p` (ou --project-dir) permite especificar la ruta de acceso a un proyecto Gradle y ejecutar una tarea en él, incluso si el directorio actual es diferente.

Por ejemplo, para lanzar la tarea`build`del proyecto situado en`~/projets/mon-autre-projet`mientras se encuentra en otro directorio :

./gradlew -p ~/projets/mon-autre-projet build

Esto es particularmente útil para scriptar acciones en varios proyectos desde una ubicación central.
