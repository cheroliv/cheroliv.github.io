Introduzione

Google Apps Script (GAS) è una piattaforma di sviluppo di script associata a diversi servizi Google quali Google Sheets, Google Docs e Google Forms. Consente di automatizzare le attività, aggiungere funzionalità personalizzate e integrare i servizi Google.

In questo promemoria, esploreremo i principali concetti di Google Apps Script basandoci su esempi concreti. Tratteremo nozioni come le variabili, i cicli, le funzioni e molto altro, adattandole al contesto specifico di GAS.

Struttura di base in Google Apps Script

Per cominciare, esaminiamo la struttura di base di uno script Google Apps.

/**
 * Structure de base en Google Apps Script
 */
function exempleStructureGAS() {
    // Votre code ici
    Logger.log("Hello, Google Apps Script!");
}

Var, Let e Const in Google Apps Script

In GAS, i concetti di`var`, let, et `const`sono utilizzati per dichiarare variabili. Tuttavia, è essenziale comprendere le loro differenze e le loro implicazioni.

/**
 * Var, Let et Const en Google Apps Script
 */
function exempleVarLetConstGAS() {
    // Votre code ici
    // Utilisation de var
    var x = 10;
    if (true) {
        var x = 20; // La variable x est modifiée globalement
    }
    Logger.log(x);

    // Utilisation de let
    let y = 30;
    if (true) {
        let y = 40; // La variable y est limitée au bloc if
    }
    Logger.log(y);

    // Utilisation de const
    const z = 50;
    // z = 60; // Impossible de réassigner une constante
    Logger.log(z);
}

Strutture di Controllo in Google Apps Script

Le strutture di controllo come`if`, else, while et `for`sono utilizzate per gestire il flusso di esecuzione in Google Apps Script.

/**
 * Structures de Contrôle en Google Apps Script
 */
function exempleStructuresControleGAS() {
    // Votre code ici
    var condition = true;

    if (condition) {
        Logger.log("La condition est vraie.");
    } else {
        Logger.log("La condition est fausse.");
    }

    var compteur = 0;
    while (compteur < 5) {
        Logger.log(compteur);
        compteur++;
    }

    for (var i = 0; i < 3; i++) {
        Logger.log(i);
    }
}

Constantes, Variables, et Lettres en Google Apps Script

Comprendere la differenza tra`const`, var, et `let`è essenziale per un utilizzo efficace delle variabili in Google Apps Script.

/**
 * Constantes, Variables, et Lettres en Google Apps Script
 */
function exempleConstantesVariablesLettresGAS() {
    // Votre code ici

    Logger.log(constante);

Cicli in Google Apps Script

I cicli, come`for` et while, sono essenziali per iterare sugli elementi e eseguire operazioni ripetitive.

/**
 * Boucles en Google Apps Script
 */
function exempleBouclesGAS() {
    // Votre code ici
    for (var i = 0; i < 3; i++) {
        Logger.log(i);
    }

    var condition = true;
    var compteur = 0;

    while (condition) {
        Logger.log("Tour de boucle");
        compteur++;
        if (compteur === 3) {
            condition = false;
        }
    }
}

Funzioni in Google Apps Script

Le funzioni sono elementi fondamentali nella programmazione. In GAS, possono essere dichiarate e richiamate in diversi modi.

/**
 * Fonctions en Google Apps Script
 */
function exempleFonctionsGAS() {
    // Votre code ici
    function additionner(a, b) {
        return a + b;
    }

    var resultat = additionner(2, 3);
    Logger.log(resultat);

    // Fonction anonyme
    var multiplier = function (x, y) {
        return x * y;
    };

    Logger.log(multiplier(4, 5));
}

Operatori di Rest e Spread in Google Apps Script

Gli operatori di riposo (…​) e di propagazione (…​) sono utili per manipolare gli array e gli oggetti in modo conciso.

/**
 * Opérateurs de Repos et de Propagation en Google Apps Script
 */
function exempleOperateursReposPropagationGAS() {
    // Votre code ici
    // Opérateur de repos (...) pour les tableaux
    var nombres = [1, 2, 3, 4, 5];
    var [...copieNombres] = nombres;
    Logger.log(copieNombres);

    // Opérateur de propagation (...) pour les objets
    var objOriginal = { x: 1, y: 2 };
    var objClone = { ...objOriginal, z: 3 };
    Logger.log(objClone);
}

Assegnazione per decomposizione in Google Apps Script

L’assegnazione per decomposizione è una funzionalità potente che permette di estrarre valori da oggetti e array in modo conciso.

/**
 * Affectation par Décomposition en Google Apps Script
 */
function exempleAffectationDecompositionGAS() {
    // Votre code ici
    var coordonnees = [3, 4];
    var [x, y] = coordonnees;
    Logger.log(x);
    Logger.log(y);

    var utilisateur = { nom: "John", age: 30 };
    var { nom, age } = utilisateur;
    Logger.log(nom);
    Logger.log(age);
}

Collezioni e Programmazione Dichiarativa in Google Apps Script

Google Apps Script supporta le strutture di dati come gli array, e i concetti di programmazione funzionale e di iterazione dichiarativa (><imperativa), come`map`, reduce et forEach.

/**
 * Collections et Programmation Déclarative en Google Apps Script
 */
function exempleCollectionsFonctionnelleGAS() {
    // Votre code ici
    // Exemple de tableau (collection)
    var nombres = [1, 2, 3, 4, 5];

    // Utilisation de forEach
    nombres.forEach(function (nombre) {
        Logger.log(nombre);
    });

    // Utilisation de map
    var carresNombres = nombres.map(function (nombre) {
        return nombre * nombre;
    });
    Logger.log(carresNombres);

    // Utilisation de reduce
    var somme = nombres.reduce(function (acc, nombre) {
        return acc + nombre;
    }, 0);
    Logger.log(somme);
}
