परिचय

लक्ष्य दर्शक: ऐसे डेवलपर्स जो Gradle प्लगइन बनाने की शुरुआत करना चाहते हैं।

ग्रैडल प्लगइन्स को प्रभावी ढंग से विकसित करने के लिए, एक अच्छी तरह से कॉन्फ़िगर किया गया विकास पर्यावरण आवश्यक है। एक अच्छा सेटअप आपको समय बचाएगा, निराशा कम करेगा और आपके बिल्ड्स की संगति सुनिश्चित करेगा।

यह गाइड चार आवश्यक स्तंभों पर केन्द्रित है :

  1. Le JDK(जावा डेवलपमेंट किट), क्योंकि Gradle और JBake JVM पर चलते हैं।

  2. Un IDEआधुनिक (IntelliJ IDEA) में कोटलिन और ग्रैडल के लिए अच्छा समर्थन है।

  3. Gradleस्वयं, परियोजनाओं को प्रारंभ करने के लिए.

  4. JBake, हमारी स्थिर साइट का इंजन।

Figure 1. विकास पर्यावरण के घटक

JDK : Gradle का इंजन

Gradle एक अनुप्रयोग है जो Java Virtual Machine (JVM) पर चलता है। इसलिए, JDK की स्थापना एक अनिवार्य शर्त है।

कौन सा संस्करण चुनें ?

अनुशंसा की जाती है कि जावा के LTS (Long-Term Support) संस्करण का उपयोग किया जाए। वर्तमान में,JDK 17 ou JDK 21वे उत्कृष्ट विकल्प हैं।

SDKMAN! के माध्यम से स्थापना (अनुशंसित)

SDKMAN! एक शानदार टूल है जो कई SDKs के संस्करणों को प्रबंधित करने के लिए उपयोग किया जाता है, जिसमें Java और Gradle शामिल हैं।

SDKMAN! स्थापित करें

curl -s "https://get.sdkman.io" | bash source "$HOME/.sdkman/bin/sdkman-init.sh"

JDK का एक संस्करण स्थापित करें

# Pour lister les versions de Java disponibles sdk list java

# Pour installer Java 17 (par exemple, la distribution Temurin)
sdk install java 17.0.8-tem

स्थापना की जाँच करें

java -version

आपको स्थापित की गई संस्करण दिखना चाहिए।

2. IDE: IntelliJ IDEA

ग्रैडल प्लगइन विकास के लिए कोटलिन DSL के साथ,IntelliJ IDEAयह पसंद का उपकरण है। इसका Gradle और Kotlin के साथ एकीकरण अद्वितीय है।

  • सामुदायिक संस्करण :नि:शुल्क और शुरू करने के लिए पर्याप्त से अधिक.

  • अल्टीमेट संस्करण :भुगतान आधारित, यह वेब विकास और डेटाबेस के लिए उन्नत सुविधाएँ प्रदान करती है।

JetBrains साइट से अपने लिए उपयुक्त संस्करण डाउनलोड करें : https://www.jetbrains.com/idea/download/

IDE स्वचालित रूप से आपकी फ़ाइलों का पता लगाएगा`build.gradle.kts` et settings.gradle.kts, आपके लिए शक्तिशाली ऑटोकम्पलीशन, कोड नेविगेशन और एकीकृत डिबगिंग टूल प्रदान करता है।

3. Gradle : बिल्ड टूल

हालांकि प्रत्येक परियोजना अपने स्वयं के Gradle संस्करण का उपयोग Gradle Wrapper के माध्यम से करेगी, लेकिन नए परियोजनाओं को आरंभ करने जैसे कार्यों के लिए एक वैश्विक Gradle स्थापना रखना उपयोगी है (gradle init).

SDKMAN! के माध्यम से इंस्टॉलेशन

JDK की तरह ही, SDKMAN! Gradle की स्थापना को सरल बनाता है।

Gradle इंस्टॉल करें

sdk install gradle

स्थापना की जाँच करें

gradle -v

यह कमांड Gradle, Kotlin, Groovy और JDK के उपयोग किए गए संस्करण दिखाएगी।

4. JBake : स्थिर साइट जेनरेटर

JBake वह उपकरण है जिसका हम अपने स्रोत फ़ाइलों (जैसे यह) को स्थिर वेबसाइट में परिवर्तित करने के लिए उपयोग करेंगे। स्थानीय इंस्टॉलेशन होना बदलावों का पूर्वावलोकन करने में उपयोगी होता है।

SDKMAN! के माध्यम से स्थापना

अन्य उपकरणों की तरह, SDKMAN! सबसे सरल विधि है।

JBake इंस्टॉल करें

sdk install jbake

इंस्टॉलेशन की जाँच करें

jbake -v

यह कमांड JBake संस्करण और उपयोग किए जा रहे Java वातावरण की जानकारी प्रदर्शित करेगा।

5. Gradle Wrapper : सर्वोत्तम अभ्यास

एक बार जब आपका प्रोजेक्ट बनाया जाता है (जिसे हम अगले लेख में देखेंगे), आपको वैश्विक कमांड का उपयोग नहीं करना चाहिए।gradle. इसके बजाय, आप इसका उपयोग करेंगेग्रैडल रैपर(./gradlew), un script inclus dans votre projet.

क्यों ?

  • पुनरावृत्ति :Wrapper हर व्यक्ति जो प्रोजेक्ट पर काम कर रहा/रही है (आपके CI/CD सर्वर सहित) सटीक रूप से उपयोग करता है laGradle का समान संस्करण, इस प्रकार विभिन्न पर्यावरणों के कारण होने वाली बिल्ड की त्रुटियों को समाप्त करते हुए।

  • सरलता:परियोजना में योगदान देने के लिए Gradle को मैन्युअली इंस्टॉल करने की आवश्यकता नहीं है।

इसे बस रिपॉजिटरी क्लोन करके चलाएँ`./gradlew`.

एक सामान्य आदेश इस प्रकार दिखेगा :

# Ne pas faire : gradle build
# À faire :
./gradlew build

6. Docker और Portainer : पुन:उत्पादन योग्य बिल्ड के लिए (वैकल्पिक)

यद्यपि प्लगिन लिखने के लिए सख्त रूप से आवश्यक नहीं हैं, Docker और Portainer आधुनिक DevOps उपकरण हैं जो पुनरुत्पादन योग्य बिल्ड्स बनाने और आपके वातावरण को प्रबंधित करने में अत्यधिक सहायक हैं।

Docker इंजन की स्थापना

Docker आपको अपने एप्लिकेशन और उसकी निर्भरताओं को एक कंटेनर में पैकेज करने की अनुमति देता है.

ऑफ़िशियल स्क्रिप्ट के माध्यम से Docker स्थापित करें:

curl -fsSL https://get.docker.com -o get-docker.sh sudo sh get-docker.sh

Docker को sudo के बिना प्रबंधित करें (अनुशंसित) :

अपने उपयोगकर्ता को समूह में जोड़ें`docker`.

sudo usod -aG docker $USER
docker run hello-world

Portainer (GUI) के साथ Docker प्रबंधित करें

Portainer एक हल्का वेब इंटरफ़ेस है जो आपके Docker कंटेनरों को प्रबंधित करने के लिए उपयोग किया जाता है।

पोर्टेनियर के डेटा के लिए एक वॉल्यूम बनाएँ :

docker volume create portainer_data

Portainer कंटेनर लॉन्च करें :

docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:latest

आप अब Portainer इंटरफ़ेस पर पहुँच सकते हैं`https://localhost:9443`.

निष्कर्ष

आपका वातावरण अब तैयार है ! आपके पास JDK है, सबसे उपयुक्त IDE, Gradle और JBake। Docker के जुड़ने से, आप भी कंटेनराइज़्ड और पुन: प्रस्तुत करने योग्य बिल्ड्स बनाने के लिए तैयार हैं। यह मजबूत आधार आपको आवश्यक पर ध्यान केंद्रित करने की अनुमति देगा : शक्तिशाली और उपयोगी प्लगइन्स का विकास।

आगामी लेख में, हम कमांड का उपयोग करेंगे।`gradle init`हमारे पहले प्लगइन परियोजना की संरचना उत्पन्न करने के लिए.
