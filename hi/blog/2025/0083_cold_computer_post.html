अपने लैपटॉप को ठंडा रखें और उबंटू पर तापमान की निगरानी करें

क्या आप महसूस करते हैं कि आपका लैपटॉप Ubuntu पर असामान्य रूप से गर्म हो रहा है ? यह लेख आपको एक विधि प्रस्तुत करता हैसॉफ़्टवेयरपूरा के लिएठंडा करना, निरीक्षण करना et तापमान को नियंत्रित करनाआपकी मशीन का।

इस गाइड का उद्देश्य

  • कंप्यूटर की वैश्विक तापमान को कम करें

  • ऊर्जा प्रबंधन को अनुकूलित करें

  • आलोचनात्मक घटकों (CPU, GPU, आदि) की निगरानी करें

  • धीमी गति से बचेंतापीय थ्रॉटलिंग

पूर्वापेक्षा

  • एक Ubuntu मशीन (20.04 या उससे ऊपर अनुशंसित)

  • इंटरनेट कनेक्शन

  • कमांड लाइन दक्षता (प्रारंभिक से मध्यम स्तर)

इंस्टॉल और कॉन्फ़िगर करें उपकरण

lm-sensors सेंसरों का पता लगाने के लिए

sudo apt install lm-sensors
sudo sensors-detect
sensors

जवाब दें`YES`सभी प्रश्नों के लिए`sensors-detect`मॉड्यूल की पहचान करने के लिए

tlp` : स्मार्ट ऊर्जा प्रबंधक

sudo apt install tlp tlp-rdw
sudo systemctl enable tlp
sudo systemctl start tlp

cpufrequtils` : सीपीयू की आवृत्तियों को सीमित करना

sudo apt install cpufrequtils
cpufreq-info
sudo cpufreq-set -g powersave

  • powersave: आवृत्ति शिखरों को सीमित करता है

  • performance: शक्ति को प्राथमिकता देता है, तापमान के नुकसान पर

auto-cpufreq` : सरलीकृत गतिशील प्रबंधन

git clone https://github.com/AdnanHodzic/auto-cpufreq.git
cd auto-cpufreq
sudo ./auto-cpufreq-installer
sudo auto-cpufreq --install

thermald` : स्वचालित तापीय संरक्षण

sudo apt install thermald
sudo systemctl enable thermald
sudo systemctl start thermald

वास्तविक समय में निगरानी

sensors` कमांड लाइन में

watch -n 2 sensors

विकल्प GUI : `psensor

sudo apt install psensor

सरल ग्राफ़िकल इंटरफ़ेस CPU, GPU, पंखों के लिए।

अतिरिक्त सुझाव

  • भारी टैब्स और अनुप्रयोग बंद करें (उदा: ब्राउज़र)

  • बैटरी पर तीव्र उपयोग से बचें

  • प्रक्रियाओं की निगरानी करना माध्यम से`htop`(No output)

sudo apt install htop
htop

सिस्टम को साफ़ करके अतिभार को सीमित करना

sudo apt autoremove
sudo apt autoclean
sudo journalctl --vacuum-time=3d

ज्यादा आगे जाने के लिए

आप एक सेवा बना सकते हैं`systemd`स्टार्टअप पर स्वचालित रूप से कुछ सेटिंग्स लागू करने के लिए कस्टम. क्या आप अगले लेख में एक उदाहरण चाहते हैं? मुझे बताइए !
