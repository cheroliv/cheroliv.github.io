جمهور هدف: توسعه‌دهندگان که می‌خواهند در ساخت پلاگین‌های Gradle قدم بگذارند.

برای توسعه پلاگین‌های Gradle به‌صورت مؤثر، یک محیط توسعه به‌طور مناسب پیکربندی‌شده ضروری است. یک تنظیم خوب زمان شما را صرفه‌جویی می‌کند، خستگی‌ها را کاهش می‌دهد و یکپارچگی ساخت‌های شما را تضمین می‌کند.

  1. این راهنما بر چهار ستون اساسی متمرکز است :

  2. Le JDK(Java Development Kit)، چون Gradle و JBake روی JVM اجرا می‌شوند.

  3. Un محیط توسعه یکپارچهمدرن (IntelliJ IDEA) با پشتیبانی خوبی از Kotlin و Gradle.

  4. Gradleخودش، برای راه‌اندازی پروژه‌ها.

  5. JBake, موتور سایت ایستای ما.

1. JDK : موتور گرادل

Gradle یک برنامه است که بر روی ماشین مجازی جاوا (JVM) اجرا می‌شود. بنابراین، نصب یک JDK یک پیش‌نیاز مطلق است.

کدام نسخه را انتخاب کنم؟

استفاده از یک نسخه LTS (پشتیبانی بلند مدت) از جاوا پیشنهاد می‌شود. در حال حاضر،JDK 17 ou JDK ۲۱آنها گزینه‌های عالی هستند.

نصب از طریق SDKMAN! (توصیه شده)

SDKMAN! یک ابزار عالی برای مدیریت نسخه‌های بسیاری از SDK‌ها، از جمله Java و Gradle، است.

SDKMAN! را نصب کنید

curl -s "https://get.sdkman.io" | bash source "$HOME/.sdkman/bin/sdkman-init.sh"

نصب یک نسخه از JDK

# Pour lister les versions de Java disponibles sdk list java

# Pour installer Java 17 (par exemple, la distribution Temurin)
sdk install java 17.0.8-tem

نصب را بررسی کنید

java -version

باید نسخه‌ای که تازه نصب کرده‌اید را ببینید.

2. IDE: IntelliJ IDEA

برای توسعه پلاگین‌های Gradle با DSL Kotlin,IntelliJ IDEAابزار مورد انتخاب است. ادغام آن با Gradle و Kotlin بی‌نظیر است.

  • Community Edition:رایگان و به‌양 کافی برای شروع.

  • نسخه نهایی :پرداختنی، ویژگی‌های پیشرفته‌ای برای توسعه وب و پایگاه داده فراهم می‌کند.

نسخه مناسب خود را از وب‌سایت JetBrains دانلود کنید : https://www.jetbrains.com/idea/download/

IDE به‌طور خودکار فایل‌های شما را شناسایی خواهد کرد`build.gradle.kts` et settings.gradle.kts, که autocompletion قدرتمند، ناوبری در کد و ابزارهای اشکال‌زداییintegrated را برای شما فراهم می‌کند.

3. Gradle : ابزار ساخت

اگرچه هر پروژه احتمالاً نسخهٔ خود Gradle را از طریق Gradle Wrapper خواهد استفاده کرد، داشتن نصب جهانی Gradle برای وظایفی مانند راه‌اندازی پروژه‌های جدید مفید است (gradle init).

نصب از طریق SDKMAN!

مثل JDK، SDKMAN! نصب Gradle را آسان می‌سازد.

Gradle را نصب کنید

sdk install gradle

بررسی نصب

gradle -v

این دستور نسخ Gradle، Kotlin، Groovy و JDK مورد استفاده را نمایش خواهد داد.

4. JBake: تولیدکننده سایت استاتیک

JBake ابزاری است که برای تبدیل فایل‌های منبع ما (مثل این) به یک وب‌سایت استاتیک استفاده خواهیم کرد. داشتن یک نصب محلی برای پیش‌نمایش تغییرات مفید است.

نصب از طریق SDKMAN!

مثل سایر ابزارها، SDKMAN! ساده‌ترین روش است.

JBake را نصب کنید

sdk install jbake

بررسی نصب

jbake -v

این دستور نسخه‌ی JBake و اطلاعات محیط Java که از آن استفاده می‌کند را نمایش خواهد داد.

5. Gradle Wrapper : بهترین عمل مطلق

پس از ایجاد پروژه خود (که در مقاله بعد خواهیم دید)، دیگر نباید از دستور عمومی استفاده کنید.gradle. به جای آن، شما آن را استفاده خواهید کردبسته Gradle(./gradlew), یک اسکریپت که در پروژه شما گنجانده شده است.

چرا؟

  • قابلیت بازپذیرش :Wrapper تضمین می‌کند که هر شخصی که بر روی پروژه کار می‌کند (شامل سرور CI/CD شما) به‌طور دقیقنسخه یکسان Gradle, به این ترتیب خطاهای ساخت به دلیل محیط‌های مختلف حذف می‌شود.

  • ساده‌گی :نیاز نیست Gradle را به صورت دستی نصب کنید تا در پروژه‌ای مشارکت کنید.

فقط کافی است مخزن را کلون کنید و اجرا کنید`./gradlew`.

یک دستور معمولی به این شکل خواهد بود:

# Ne pas faire : gradle build
# À faire :
./gradlew build

6. Docker و Portainer: برای ساخت‌های قابل بازتولید (اختیاری)

اگرچه برای نوشتن یک پلاگین به‌طور دقیق لازم نیستند، Docker و Portainer ابزارهای DevOps مدرن هستند که به‌سختی ساخت-build‌های قابل‌تکرار را آسان می‌سازند و مدیریت محیط شما را ساده می‌کنند.

نصب Docker Engine

Docker به شما امکان می‌دهد برنامه و وابستگی‌های آن را در یک کانتینر بسته‌بندی کنید.

نصب Docker از طریق اسکریپت رسمی :

curl -fsSL https://get.docker.com -o get-docker.sh sudo sh get-docker.sh

مدیریت Docker بدون sudo (پیشنهاد شده):

کاربر خود را به گروه اضافه کنید`docker`.

sudo usod -aG docker $USER
docker run hello-world

داکر را با Portainer (GUI) مدیریت کنید

Portainer یک رابط وب سبک برای مدیریت کانتینرهای Docker شما است.

یک حجم برای داده‌های Portainer ایجاد کنید :

docker volume create portainer_data

راه‌اندازی کانتینر Portainer :

docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:latest

شما می‌توانید اکنون به رابط کاربری Portainer روی دسترسی پیدا کنید`https://localhost:9443`.

نتیجه

محیط شما اکنون آماده است! شما یک JDK، IDE مناسب‌ترین، Gradle و JBake دارید. با افزودن Docker، شما نیز برای ساخت ساخت‌های conteneurized و reproducible آماده می‌شوید. این پایه قوی شما را قادر می‌سازد تا بر روی جوهر متمرکز شوید: توسعه پلاگین‌های قوی و مفید.

در مقاله بعدی، ما از این دستور استفاده خواهیم کرد`gradle init`برای تولید ساختار اولین پروژه پلاگین ما.
