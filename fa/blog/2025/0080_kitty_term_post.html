این راهنما گام به گام توضیح می‌دهد که چگونه ترمینال kitty را روی Xubuntu نصب کنیم، آن را به‌درستی پیکربندی کنیم و bash را به zsh به‌عنوان شل پیش‌فرض جایگزین کنیم. پروژه kitty در اینجا در دسترس است: https://github.com/kovidgoyal/kitty.

_ Kitty یک ترمینال مدرن، سریع و قابل تنظیم است، به‌ویژه برای توسعه‌دهندگان دقیق‌طلب مناسب است. _

چرا Kitty و Zsh را انتخاب کنیم؟

کیتی به این دلیل متمایز است :

  • عملکرد بهتر به دلیل تسریع GPU,

  • یک پیکربندی به‌طور کامل مبتنی بر یک فایل متنی یکتا,

  • پشتیبانی عالی از فونت‌ها و لیگچرها.

Zsh به‌طور مشابه یک پوسته تعاملی قدرتمند است که :

  • یک تکمیل هوشمند،

  • یک prompt قابل سفارشی,

  • سازگاری بسیار بالا با bash.

با ترکیب Kitty و Zsh، از یک محیط کارآمد و زیبا بهره‌مند شوید.

@startuml
title معماری ساده Kitty + Zsh
actor User

User --> Kitty : Lance le terminal
Kitty --> Zsh : Initialise le shell interactif
Zsh --> System : Interagit avec le système (fichiers, commandes)
@enduml

این راهنما به‌طور عمدی فقط به نصب از طریق اسکریپت و Xubuntu محدود شده است.

پیش‌نیازهای سیستم

قبل از شروع، مطمئن شوید که دارید :

  • Xubuntu نصب شده,

  • دسترسی به اینترنت،

  • یک شل bash کارآمد برای اجرای اسکریپت.

محیط خود را بررسی کنید:

uname -a
lsb_release -a

دانلود و نصب کیتی

Kitty پیشنهاد می‌دهد آن را از طریق یک اسکریپت رسمی نصب کند که فایل‌ها را در`~/.local/kitty.app`.

این روش مستقل از مدیران بسته است (بدون`apt`).

اسکریپت نصب را دانلود کنید

دستور زیر را اجرا کنید:

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

این دستور : انجام می‌دهد

  • دانلود باینری‌ها,

  • استخراج در`~/.local/kitty.app`,

  • ایجاد لینک‌های سمبولیک.

@startuml
title دانلود و نصب Kitty
start
:curl -L installer.sh;
:sh /dev/stdin;
:Décompression dans ~/.local/kitty.app;
:create symlinks;
stop
@enduml

ایجاد پیوندهای نمادین

برای اینکه بتواند invoquer`kitty`از ترمینال، یک لینک نمادین بسازید:

ln -s ~/.local/kitty.app/bin/kitty ~/.local/bin/kitty

افزایید`~/.local/bin`به PATH خود اضافه کنید اگر قبلاً انجام نشده باشد :

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

می‌توانید نصب را بررسی کنید:

kitty --version

ادغام Kitty در Xubuntu

تا Kitty در منوی برنامه‌ها ظاهر شود :

کپی کردن فایل desktop

فایل را کپی کنید`.desktop`ارائه شده :

cp ~/.local/kitty.app/share/applications/kitty.desktop ~/.local/share/applications/

فایل دسکتاپ را ویرایش کنید

فایل را ویرایش کنید:

nano ~/.local/share/applications/kitty.desktop

خطوط زیر را بررسی یا ویرایش کنید:

[Desktop Entry]
Version=1.0
Type=Application
Name=Kitty Terminal
Comment=Fast GPU-based terminal emulator
Exec=/home/$USER/.local/kitty.app/bin/kitty
Icon=kitty
Categories=System;TerminalEmulator;

جایگزین کنید`YOURUSER`با نام کاربری شما.

@startuml
title فرآیند ادغام Kitty در منوی Xubuntu
start
:Copier .desktop;
:Editer les chemins;
:Sauvegarder;
:Menu Applications;
stop
@enduml

مطابق کردن Kitty به‌عنوان ترمینال پیش‌فرض (اختیاری)

به منظور Kitty به‌عنوان ترمینال پیش‌فرض اجرا شود :

sudo update-alternatives --install /usr/bin/x-terminal-emulator x-terminal-emulator ~/.local/kitty.app/bin/kitty 50
sudo update-alternatives --config x-terminal-emulator

انتخاب کنید`kitty`در منوی پیشنهادی.

نصب Zsh

اگر Zsh هنوز نصب نشده باشد، اجرا کنید :

sudo apt install zsh

نصب را بررسی کنید:

zsh --version

Zsh را به عنوان شل پیش‌فرض تنظیم کنید

شما می‌توانید پوسته خود را به‌طور کلی یا فقط در Kitty تغییر دهید.

روش کلی (برای تمام ترمینال‌ها)

مسیر مطلق را شناسایی کنید :

which zsh

به طور کلی`/usr/bin/zsh`.

پیش‌فرض شل را تغییر دهید :

chsh -s /usr/bin/zsh

از خارج شوید و دوباره وارد شوید

@startuml
title تغییر جهانی شل
actor User

User --> Bash : Session actuelle
User --> System : chsh -s /usr/bin/zsh
System --> "/etc/passwd" : Modifie le shell
note right of "/etc/passwd" : Shell par défaut mis à jour
@enduml

روش مخصوص Kitty

اگر ترجیح می‌دهید فقط شِل را در Kitty تغییر دهید، فایل پیکربندی را ویرایش کنید:

nano ~/.config/kitty/kitty.conf

این خط را اضافه کنید :

shell zsh

ذخیره کنید و Kitty را دوباره راه‌اندازی کنید.

تنظیم Zsh (اختیاری)

برای شخصی‌سازی Zsh شما :

یک فایل .zshrc ایجاد کنید

touch ~/.zshrc
nano ~/.zshrc

نمونه پیکربندی حداقل

export ZSH_THEME="robbyrussell"
export PATH="$HOME/.local/bin:$PATH"
alias ll="ls -la"

خلاصه کامل گردش کار

نمودار زیر تمام فرآیند را خلاصه می‌کند:

@startuml
title Workflow نصب و پیکربندی
start
:Téléchargement script Kitty;
:Installation dans ~/.local;
:Création symlink;
:Ajout ~/.local/bin au PATH;
if (Zsh installé ?) then (non)
  :sudo apt install zsh;
endif
:Configurer Kitty.desktop;
:Optionnel - changer terminal par défaut;
:Optionnel - chsh -s /usr/bin/zsh;
stop
@enduml

بررسی نهایی

Kitty را اجرا کنید :

kitty

باید ببینید که`zsh`فعال است :

echo $SHELL

نتیجه مورد انتظار :

/usr/bin/zsh

برای تغییر اندازه قلم درکیتی, باید پارامتر را تنظیم کرد`font_size`در فایل پیکربندی. این دقیق است :

📂 باز کردن فایل تنظیمات

فایل تنظیمات اصلی معمولاً در :

~/.config/kitty/kitty.conf

اگر این فایل هنوز وجود ندارد، می‌توانید آن را ایجاد کنید. مثال :

nano ~/.config/kitty/kitty.conf

🖋️ افزودن یا تغییر `font_size

دستورالعمل زیر را اضافه کنید یا اگر قبلاً وجود دارد، آن را تغییر دهید :

font_size 14.0

اینجا`14.0`با اندازهٔ مورد نظر همخوانی دارد. شما می‌توانید هر عدد اعشاری دلخواه را وارد کنید، به عنوان مثال`12.0`, 15.5، و غیره

💾 ذخیره و راه‌اندازی مجدد Kitty

  • ذخیره کنید (Ctrl + O, سپس`Entrée`) و بگذارید (Ctrl + X) إذا شما استفاده می‌کنید`nano`.

  • تمامی پنجره‌های Kitty را ببندید، سپس ترمینال را دوباره راه‌اندازی کنید تا تغییر اعمال شود.

✅ تنظیم دینامیکی (Zoom موقت)

اگر می‌خواهید به صورت موقت زوم In/Out (بزرگ/کوچک) کنید بدون تغییر تنظیمات، از میان‌برهای پیش‌فرض کلیدبورد استفاده کنید:

  • اندازه قلم را افزایش دهید:

Ctrl + Shift + =

  • اندازه فونت را کاهش دهید:

Ctrl + Shift + -

  • بازانداز کردن اندازه:

Ctrl + Shift + Backspace

این تنظیمات پس از بستن ترمینال پایدار نمی‌مانند.

نصب و تنظیم Oh My Zsh

پس از نصب و تنظیم Zsh به‌عنوان شل پیش‌فرض، می‌توانید با Oh My Zsh، یک چارچوب مدیریت پیکربندی Zsh، محیط خود را غنی‌سازی کنید:

  • مجموعه‌ای از موضوعات برای پرامپت,

  • افزونه‌های بسیاری,

  • یک سازمان واضح از پیکربندی.

نصب Oh My Zsh

مطمئن شوید که Zsh فعال است:

zsh --version

در صورت لزوم، اجرا کنید :

zsh

سپس اسکریپت نصب رسمی را دانلود و اجرا کنید :

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

این اسکریپت:

  • پوشه را بساز`~/.oh-my-zsh`,

  • ممکن است فایل شما را ذخیره کنید`~/.zshrc`,

  • به‌طور خودکار prompt جدید را فعال می‌کند.

تم را تغییر دهید

فایل تنظیمات خود را باز کنید:

nano ~/.zshrc

متغیر را تغییر دهید`ZSH_THEME`برای انتخاب تم دیگر (به عنوان مثال`agnoster`) :

ZSH_THEME="agnoster

تنظیمات را ذخیره کنید و سپس بارگذاری مجدد کنید :

source ~/.zshrc

تایید

Kitty را اجرا کنید و مطمئن شوید که پرامپت به‌طور کامل تغییر کرده است. می‌توانید تأیید کنید که Oh My Zsh فعال است با اجرای :

echo $ZSH

نتیجهٔ باید مشابه باشد :

/home/کاربر_شما/.oh-my-zsh

نمودار مورد استفاده

@startuml
title مثال نصب و استفاده از Oh My Zsh
actor Utilisateur as User

package "کیتی ترمینال" {
  component "لایه Zsh" as Zsh
}

component "چارچوب Oh My Zsh" as OhMyZsh

User --> Kitty : Lance Kitty
Kitty --> Zsh : Initialise Zsh
Zsh --> OhMyZsh : Charge configuration (~/.zshrc, thèmes, plugins)
User --> OhMyZsh : Personnalise le thème et les plugins

@enduml

شفافیت را در Kitty فعال کنید

یک از ویژگی‌های محبوب Kitty این است که می‌توانید transparence را به پس‌زمینه ترمینال اضافه کنید. این اجازه می‌دهد تا به‌صورت ملایم محیط زیرین (پنجره، دسکتاپ و …​) را ببینید که در multitasking به‌طور خاص مفید است.

پیش‌نیاز برای شفافیت

شفافیت در Kitty بر پایه‌یآهنگ‌ساز پنجره‌هااستفاده شده توسط محیط گرافیکی. در Xubuntu (مبنی بر XFCE)، مطمئن شوید کهترکیب فعال شده است.

بررسی شود :

  • کلیک راست روی دسکتاپ > تنظیمات >تنظیمات مدیر پنجره,

  • تبسازنده: کادر "Activer la composition" باید علامت بزند.

@startuml
title مورد استفاده - فعال‌سازی شفافیت در Kitty
actor Utilisateur

rectangle "محیط گرافیکی (XFCE/Xubuntu)" {
  usecase "فعال‌ساز ترکیب" as UC1
}

rectangle "Kitty Terminal" {
  usecase "شفافیت را در kitty.conf تنظیم کنید" as UC2
}

Utilisateur --> UC1
Utilisateur --> UC2

@enduml

پیکربندی شفافیت در kitty.conf

فایل تنظیمات خود را باز کنید`~/.config/kitty/kitty.conf`:

nano ~/.config/kitty/kitty.conf

خطوط زیر را اضافه یا ویرایش کنید :

background_opacity 0.85

این پارامتر مقادیری بین پذیرفته می‌شود:

  • 1.0→ ناشراف (بدون شفافیت),

  • 0.0→ کاملاً شفاف (ناآپذیر),

  • مقادیر میانی مانند`0.90`, 0.75, و غیره

یک توافق بصری خوب معمولاً بین`0.85` et 0.95.

راه‌اندازی دوباره کیتی

تمام نمونه‌های Kitty را ببندید، سپس یک پنجره جدید باز کنید تا تغییرات اعمال شوند :

kitty

مکمل‌های ممکن

اگر از پس‌زمینه-terminal سفارشی استفاده می‌کنید، می‌توانید رنگ پس‌زمینه با شفافیت (به صورت RGBA) نیز تعیین کنید :

background #1e1e2eff

آخرین کامپوننت (ff) نماید عتتمت (az`00` à ff).

نمودار دنباله - مقداردهی اولیه کیتی با شفافیت

@startuml
title سلسله راه‌اندازی کیتی با شفافیت
actor User
participant "کیتی" as Kitty
participant "XFCE سازنده" as XFCE
participant "GPU/مدیر پنجره" as WM

User -> Kitty : Lance Kitty
Kitty -> kitty.conf : Lit configuration
Kitty -> XFCE : Vérifie composition activée
XFCE --> Kitty : Composition = active
Kitty -> WM : Demande allocation fenêtrée transparente
WM --> Kitty : OK (rendu avec alpha < 1)
Kitty -> User : Affiche terminal translucide

@enduml

محدودیت‌های شناخته شده

شفافیت کار نمی‌کند اگر : - کومپوزیتور XFCE غیرفعال شده است, - یک مدیر پنجره‌ی ناسازگار استفاده می‌شود, - شما Kitty را در حالت tmux در پس‌زمینه استفاده می‌کنید بدون پشتیبانی از شفافیت.

غیرفعال کردن صدای بíp (صدای هشدار)

به‌طور پیش‌فرض، Kitty وقتی که یک دستور اشتباه وارد شود یا یک رویداد terminal آن را راه‌اندازی کند، یک صدای bip پخش می‌کند. این صدا می‌تواند به سرعت آزاردهنده شود، به‌ویژه در محیطی که توسعه‌ی پرشده انجام می‌شود.

برای غیرفعال کردن این رفتار، دستورالعمل زیر را به فایل اضافه کنید`~/.config/kitty/kitty.conf`:

audible_bell no

شما همچنین می‌توانید بازخورد بصری را به جای صدای بيف فعال کنید :

visual_bell yes

به‌روزرسانی کیتی

چون Kitty از طریق یک اسکریپت نصب می‌شود و نه از طریق یک مدیر بسته، به‌روزرسانی با اجرای دوباره اسکریپت نصب رسمی انجام می‌شود. این امکان دانلود آخرین نسخه و به‌روزرسانی نصب موجود شما را در`~/.local/kitty.app`.

پسوند`.app`در مسیر`~/.local/kitty.app`این روش نصب Kitty روی لینوکس از طریق اسکریپت رسمی آن است و به هیچ‌وجه نشان‌دهندهٔ سازگاری منحصر با macOS نیست.

قبل از اجرای دستور به‌روزرسانی، مطمئن شوید که در دایرکتوری خانگی خود قرار دارید (~).

دستور زیر را از دایرکتوری خانگی خود اجرا کنید:

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

این اسکریپت مسئول خواهد بود:

  • باینری‌های نسخه‌ی جدید را دانلود کنید.

  • فایل‌ها را استخراج کن در`~/.local/kitty.app`.

  • در صورت نیاز، لینک‌های نمادین را به‌روزرسانی کنید.

پس از به‌روزرسانی، توصیه می‌شود تمام نمونه‌های Kitty را بسته و سپس آن‌ها را مجدداً راه‌اندازی کنید تا مطمئن شوید نسخه جدید به‌درستی در نظر گرفته می‌شود.

منابع
