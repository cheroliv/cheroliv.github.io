احساس می‌کنید که لپ تاپ شما در اوبونتو به طور غیر عادی گرم می‌شود؟ این مقاله یک رویکرد را برای شما پیشنهاد می‌دهد.نرم‌افزارکامل برایخنک کردن, نگرانی کردن et دمای را کنترل کنیدماشین شما.

هدف این راهنما

  • دمای کلی کامپیوتر را کاهش دهید

  • بهینه‌سازی مدیریت انرژی

  • نظارت بر اجزای حائز اهمیت (CPU، GPU و غیره)

  • اجرا نشدید به دلیلسفتگی حرارتی

@startuml
start
:Installer les outils;
:Analyser les capteurs;
:Appliquer des réglages;
note right: cpufreq, tlp, auto-cpufreq
:Surveiller en temps réel;
stop
@enduml

پیش‌نیاز

  • یک ماشین اوبونتو (۲۰٫۰۴ یا بالاتر توصیه شده)

  • اتصال اینترنت

  • مهارت در خط فرمان (سطح مبتدی تا متوسط)

نصب و پیکربندی ابزارها

lm-sensors` برای تشخیص سنسورها

sudo apt install lm-sensors
sudo sensors-detect
sensors

پاسخ دهید`YES`به تمام سوال‌های`sensors-detect`pour détecter les modules.

tlp` : مدیر هوشمند انرژی

sudo apt install tlp tlp-rdw
sudo systemctl enable tlp
sudo systemctl start tlp
@startuml
(*) --> "TLP فعال است؟"
if "بله" then
  --> [yes] "کاهش مصرف"
  --> "محدودیت فرکانس CPU"
else
  --> [no] "شروع TLP"
  --> "فعال‌سازی خودکار"
endif
-->(*)
@enduml

cpufrequtils` : محدود کردن فرکانس‌های CPU

sudo apt install cpufrequtils
cpufreq-info
sudo cpufreq-set -g powersave

  • powersave: قیمه‌های فرکانس را محدود می‌کند

  • performance: قدرت را به جای دما ترجیح می‌دهد

auto-cpufreq` : مدیریت پویا ساده‌سازی‌شده

git clone https://github.com/AdnanHodzic/auto-cpufreq.git
cd auto-cpufreq
sudo ./auto-cpufreq-installer
sudo auto-cpufreq --install
@startuml
start
:Analyse charge système;
:Réglage fréquence CPU;
:Vérification température;
:Adaptation dynamique;
stop
@enduml

thermald` : حفاظت حرارتی خودکار

sudo apt install thermald
sudo systemctl enable thermald
sudo systemctl start thermald

نظارت در زمان واقعی

sensors` در خط فرمان

watch -n 2 sensors

گزینهٔ GUI : `psensor

sudo apt install psensor

رابط گرافیکی ساده برای CPU، GPU و فن‌ها.

نکات تکمیلی

  • بستن برگ‌ها و برنامه‌های سنگین (مثل: مرورگرها)

  • از استفاده‌های شدید بر باتری اجتناب کنید

  • نظارت بر فرآیندها از طریق`htop`:

sudo apt install htop
htop

سیستم را برای محدود کردن بارهای بیش از حد پاک کنید

sudo apt autoremove
sudo apt autoclean
sudo journalctl --vacuum-time=3d

برای پیش رفتن

شما می‌توانید یک سرویس ایجاد کنید`systemd`شخصی‌سازی‌شده برای اعمال خودکار برخی تنظیمات در زمان راه‌اندازی. آیا مایل به یک مثال در یک مقاله آینده هستید؟ این را به من بگویید!

📚 نتیجه

با ترکیب این ابزارهای ساده، شما به دست خواهید آورد:

  • دما CPU کنترلSOE

  • کمتر صدای تهویه

  • خودکفایی بهتر

نفراموش کنید که به‌صورت منظم دماهای خود را برای جلوگیری از هرگونه گرمای مفرط نظارت کنید.

_ بهتر است پیشگیری کنیم تا CPU خود را ذوب ندهیم. _
