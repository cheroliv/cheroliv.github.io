이 가이드는 Xubuntu에서 kitty 터미널을 단계별로 설치하고 올바르게 구성하며, bash를 기본 셸로 *zsh*로 바꾸는 방법을 설명합니다. kitty 프로젝트는 여기에서 이용할 수 있습니다: https://github.com/kovidgoyal/kitty.

__ Kitty는 요구가 높은 개발자에게 특히 적합한 현대적이고 빠르며 구성 가능한 터미널입니다. (empty)

왜 Kitty와 Zsh를 선택해야 할까요?

Kitty은(는) 다음과 같이 특징이 있습니다:

  • GPU 가속 덕분에 향상된 성능,

  • 단일 텍스트 파일을 기반으로 완전히 구성된,

  • 폰트와 리가처에 대한 훌륭한 지원

Zsh는 그에 반해 강력한 인터랙티브 셸을 제공합니다:

  • 지능형 완성,

  • 맞춤형 프롬프트,

  • bash와 높은 호환성.

Kitty와 Zsh를 함께 사용하면 생산적이고 미적인 환경을 누릴 수 있습니다.

@startuml
title 간소화된 아키텍처 Kitty + Zsh
actor User

User --> Kitty : Lance le terminal
Kitty --> Zsh : Initialise le shell interactif
Zsh --> System : Interagit avec le système (fichiers, commandes)
@enduml

이 가이드는 스크립트를 통한 설치와 Xubuntu에만 의도적으로 제한됩니다.

시스템 사전 요구사항

시작하기 전에, 가지고 있어야 할 것 :

  • Xubuntu 설치됨,

  • 인터넷 접속,

  • 스크립트를 실행하기 위한 기능적인 bash 셸

환경을 확인하세요:

uname -a
lsb_release -a

Kitty 다운로드 및 설치

Kitty는 공식 스크립트를 통해 파일을 설치하는 것을 권장합니다. 파일을 넣는`~/.local/kitty.app`.

이 방법은 패키지 관리자에 독립적인(없는`apt`).

설치 스크립트를 다운로드하세요

다음 명령어를 실행하세요:

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

이 명령은 수행합니다 :

  • 바이너리 다운로드,

  • 추출에서`~/.local/kitty.app`,

  • 심볼릭 링크 생성.

@startuml
title Kitty 다운로드 및 설치
start
:curl -L installer.sh;
:sh /dev/stdin;
:Décompression dans ~/.local/kitty.app;
:create symlinks;
stop
@enduml

심볼릭 링크 생성

소환하기 위해`kitty`터미널에서 심볼릭 링크를 생성하세요 :

ln -s ~/.local/kitty.app/bin/kitty ~/.local/bin/kitty

추가하세요`~/.local/bin`votre PATH에 추가하지 않았다면 :

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

설치를 확인할 수 있습니다:

kitty --version

Xubuntu에 Kitty 통합

Kitty가 응용 프로그램 메뉴에 나타나도록:

데스크톱 파일을 복사

파일을 복사하세요`.desktop`제공 :

cp ~/.local/kitty.app/share/applications/kitty.desktop ~/.local/share/applications/

데스크톱 파일 수정

파일을 편집하세요 :

nano ~/.local/share/applications/kitty.desktop

다음 줄을 확인하거나 수정하세요:

[Desktop Entry]
Version=1.0
Type=Application
Name=Kitty Terminal
Comment=Fast GPU-based terminal emulator
Exec=/home/$USER/.local/kitty.app/bin/kitty
Icon=kitty
Categories=System;TerminalEmulator;

바꿔`YOURUSER`사용자 이름으로

@startuml
title Xubuntu 메뉴에 Kitty 통합 프로세스
start
:Copier .desktop;
:Editer les chemins;
:Sauvegarder;
:Menu Applications;
stop
@enduml

Kitty를 기본 터미널로 설정 (선택 사항)

Kitty가 기본 터미널로 실행되도록 하려면:

sudo update-alternatives --install /usr/bin/x-terminal-emulator x-terminal-emulator ~/.local/kitty.app/bin/kitty 50
sudo update-alternatives --config x-terminal-emulator

선택하세요`kitty`제안된 메뉴에서.

Zsh 설치

Zsh가 아직 설치되지 않았다면, 실행하세요 :

sudo apt install zsh

설을 확인하세요:

zsh --version

Zsh를 기본 셸로 설정

셸을 전역적으로 변경하거나 Kitty 내에서만 변경할 수 있습니다.

전역 방법 (모든 터미널에 대해)

절대 경로를 식별하세요 :

which zsh

일반적으로`/usr/bin/zsh`.

기본 셸을 변경하세요 :

chsh -s /usr/bin/zsh

로그아웃하고 다시 로그인하세요.

@startuml
title 전역 셸 변경
actor User

User --> Bash : Session actuelle
User --> System : chsh -s /usr/bin/zsh
System --> "/etc/passwd" : Modifie le shell
note right of "/etc/passwd" : Shell par défaut mis à jour
@enduml

Kitty 전용 방법

Kitty에서 셸만 바꾸기를 원한다면, 구성 파일을 편집하세요:

nano ~/.config/kitty/kitty.conf

이 줄을 추가하세요:

shell zsh

저장하고 Kitty를 다시 시작하세요.

Zsh 구성 (선택 사항)

Zsh를 사용자 지정하려면 :

파일 .zshrc 생성

touch ~/.zshrc
nano ~/.zshrc

최소 구성 예시

export ZSH_THEME="robbyrussell"
export PATH="$HOME/.local/bin:$PATH"
alias ll="ls -la"

최종 검증

키티 실행 :

kitty

당신은 그것을 보아야 합니다.`zsh`활성 상태입니다 :

echo $SHELL

예상 결과 :

/usr/bin/zsh

글꼴 크기를 변경하려면키티, 매개변수를 조정해야 합니다`font_size`구성 파일에서. 자세한 절차는 다음과 같습니다:

📂 구성 파일 열기

주요 구성 파일은 보통 다음 위치에 있습니다:

~/.config/kitty/kitty.conf

이 파일이 아직 존재하지 않는 경우, 그것을 생성할 수 있습니다. 예시 :

nano ~/.config/kitty/kitty.conf

🖋️ 추가하거나 수정 `font_size

다음 지시문을 추가하거나, 이미 존재한다면 수정하세요:

font_size 14.0

여기`14.0`원하는 크기에 맞습니다. 원하는 소수 값을 입력할 수 있습니다, 예를 들어`12.0`, 15.5, 등등

💾 저장하고 Kitty 다시 시작

  • 저장 (Ctrl + O, 그 다음에`Entrée`) 그리고 떠나세요 (Ctrl + X) 사용하신다면`nano`.

  • Kitty의 모든 창을 닫은 다음, 변경 사항이 적용되도록 터미널을 다시 시작하세요.

✅ 동적 조정 (임시 줌)

임시로 확대/축소하고 싶지만 설정을 변경하지 않으려면 기본 키보드 단축키를 사용하세요:

  • 글꼴 크기를 늘리다:

Ctrl + Shift + =

  • 글꼴 크기 줄이기:

Ctrl + Shift + -

  • 크기 재설정:

Ctrl + Shift + Backspace

이 설정은 터미널을 닫은 후에도 유지되지 않습니다.

Oh My Zsh 설치 및 구성

Zsh가 설치되고 기본 셸로 설정된 후, *Oh My Zsh*를 사용하여 환경을 풍부하게 할 수 있습니다. Zsh 구성을 관리하는 프레임워크인 *Oh My Zsh*는 다음과 같은 기능을 제공합니다:

  • 프롬프트용 테마 컬렉션,

  • 많은 플러그인,

  • 구성의 명확한 조직.

Oh My Zsh 설치

Zsh가 활성화되어 있는지 확인하세요 :

zsh --version

필요하면 실행하세요:

zsh

그런 다음 공식 설치 스크립트를 다운로드하고 실행하세요.

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

이 스크립트 :

  • 폴더를 만들어`~/.oh-my-zsh`,

  • 가능하면 파일을 백업해 주세요`~/.zshrc`,

  • 새 프롬프트를 자동으로 활성화합니다.

테마 변경

구성 파일을 엽니다 :

nano ~/.zshrc

변수를 수정하세요`ZSH_THEME`다른 테마를 선택하기 위해 (예를 들어`agnoster`) :

ZSH_THEME="agnoster

저장하고 구성을 다시 로드하세요:

source ~/.zshrc

검증

Kitty를 실행하고 프롬프트가 제대로 변경되었는지 확인하세요. 다음과 같이 실행하여 Oh My Zsh가 활성화되어 있는지 확인할 수 있습니다:

echo $ZSH

결과가 비슷해야 합니다 :

/home/당신의_사용자/.oh-my-zsh

Kitty에서 투명도 활성화

Kitty의 가장 좋아하는 기능 중 하나는 터미널 배경에 *투명도*를 추가할 수 있는 기능입니다. 이를 통해 창, 바탕화면 등 아래 환경을 약간 볼 수 있어 멀티태스킹 시 특히 유용합니다.

투명성을 위한 사전 조건

키티의 투명성은 그것에 기반을 둔다윈도우 컴포지터그래픽 환경에서 사용됩니다. Xubuntu (XFCE 기반에서), …​인지 확인하세요구성이 활성화되었습니다..

확인해야 할 :

  • 바탕화면에서 오른쪽 클릭 > 설정 >창 관리자 설정,

  • 탭작곡가상자 : "컴포지션 활성화" 가 체크되어 있어야 합니다.

@enduml

kitty.conf에서 투명도 구성

설정 파일을 열어 주세요`~/.config/kitty/kitty.conf`(Empty output)

nano ~/.config/kitty/kitty.conf

다음 줄을 추가하거나 수정하세요 :

background_opacity 0.85

이 매개변수는 다음 사이의 값을 허용합니다:

  • 1.0→ 불투명 (투명도 없음),

  • 0.0→ 완전히 투명한 (사용할 수 없는),

  • 중간 값과 같은`0.90`, 0.75, 등등

좋은 시각적 타협은 보통 사이에`0.85` et 0.95.

Kitty 재시작

Kitty의 모든 인스턴스를 닫은 다음, 변경 사항이 적용되도록 새 창을 다시 시작하세요 :

kitty

가능한 보완

사용자 지정 터미널 배경을 사용하고 있는 경우, RGBA를 사용한 투명 배경색도 설정할 수 있습니다:

background #1e1e2eff

마지막 구성 요소 (ff) indique l’opacité (de`00` à ff).

알려진 제한

투명도가 작동하지 않을 경우: - XFCE 컴포지터가 비활성화됨, - 호환되지 않는 윈도우 관리자가 사용되고 있습니다, - 당신은 Kitty를 tmux 모드에서 배경에서 사용하고 있으며 투명도 지원이 없습니다.

벨 소리 비활성화 (청각적 벨)

기본적으로 Kitty는 bip 소리를 내며, 잘못된 명령이 입력되거나 터미널 이벤트가 이를 트리거할 때 발생합니다. 이 소음은 특히 강도 높은 개발 환경에서는 빠르게 성가신 것이 될 수 있습니다.

이 동작을 비활성화하려면 파일에 다음 지시문을 추가`~/.config/kitty/kitty.conf`:

audible_bell no

또한 *시각 피드백*을 소리 대신 활성화할 수 있습니다:

visual_bell yes

Kitty 업데이트

Kitty가 스크립트를 통해 설치되었고 패키지 관리자가 아니기 때문에, 업데이트는 공식 설치 스크립트를 다시 실행하여 수행됩니다. 이를 통해 최신 버전을 다운로드하고 기존 설치를 업데이트할 수 있습니다 안에`~/.local/kitty.app`.

접미사`.app`길에서`~/.local/kitty.app`Kitty의 Linux 설치 방식은 공식 스크립트를 통해 이루어지며, 이는 macOS와의 독점적 호환성을 나타내는 것이 아닙니다.

업데이트 명령을 실행하기 전에, 개인 디렉터리에 있는지 확인하세요 (~).

다음 명령을 홈 디렉터리에서 실행하세요:

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

이 스크립트는 다음을 담당할 것입니다 :

  • 새 버전의 바이너리를 다운로드하다

  • 파일을 추출하여`~/.local/kitty.app`.

  • 필요한 경우 심볼릭 링크를 업데이트하세요.

업데이트 후, Kitty의 모든 인스턴스를 종료하고 다시 시작하여 새로운 버전이 제대로 적용되도록 하는 것이 권장됩니다.
