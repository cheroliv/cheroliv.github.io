ভূমিকা

".লক্ষ্য দর্শক : Gradle প্লাগিন তৈরি করা শুরু করতে ইচ্ছুক ডেভেলপাররা।

Gradle প্লাগাইন দক্ষতার সাথে উন্নয়ন করতে, একটি ভালভাবে কনফিগার করা উন্নয়ন পরিবেশ অপরিহার্য। একটি ভাল সেটআপ আপনার সময় বাঁচাবে, বিরক্তি কমবে এবং আপনার বিল্ডদের সততা নিশ্চিত করবে।

এই গাইড চারটি মৌলিক স্তম্ভের ও在乎

  1. Le JDK(Java Development Kit), কারণ Gradle এবং JBake JVM-এ চালু হয়।

  2. Un IDEআধুনিক (IntelliJ IDEA) কোটলিন ও Gradle-কে ভালো সমর্থন দেয়।

  3. Gradleত নিজেই, প্রকল্পগুলো শুরু করার জন্য।

  4. JBake, আমাদের স্ট্যাটিক সাইটের ইঞ্জিন.

Figure 1. ".বিকাশ পরিবেশের উপকরণ

1. JDK: Gradle-ইর ইঞ্জিন

Gradle একটি অ্যাপ্লিকেশন যা Java ভায়ারচুয়াল মেশিন (JVM)-এ চলায়। সুতরাং, একটি JDK ইনস্টল করা একটি অপরিহার্য পূর্বশর্ত।

কোন সংস্করণ বেছে নিবেন?

Java-এ একটি LTS (Long-Term Support) সংস্করণ ব্যবহার করা পরামর্শ দেওয়া হয়। এখন,JDK ১৭ ou JDK ২১চমৎকার পছন্দ।

SDKMAN! এর মাধ্যমে ইনস্টলেশন (প্রস্তাবিত)

SDKMAN! একটি অসাধারণ টুল যাতে অনেক SDK-এর সংস্করণ ব্যবস্থাপনা করা যায়, যার মধ্যে Java এবং Gradle অন্তর্ভুক্ত।

ইনস্টল SDKMAN!

curl -s "https://get.sdkman.io" | bash source "$HOME/.sdkman/bin/sdkman-init.sh"

JDK-এর একটি সংস্করণ ইনস্টল করুন

# Pour lister les versions de Java disponibles sdk list java

# Pour installer Java 17 (par exemple, la distribution Temurin)
sdk install java 17.0.8-tem

ইনস্টলেশন যাচাই করুন

java -version

আপনি যে সংস্করণটি আপনি এখন ইনস্টল করেছেন তা দেখতে পাবেন।

2. আইডিই : IntelliJ IDEA

Gradle প্লাগইন ডেভেলপমেন্টের জন্য Kotlin DSL এর সাথে,IntelliJ IDEAএটি পছন্দের সরঞ্জাম। এর Gradle এবং Kotlin সঙ্গে একীকরণ অপারম্পর।

  • সম্প্রদায় সংস্করণ :বিনামূল্যে এবং শুরু করার জন্য খুব পর্যাপ্ত.

  • অ্যালটিমেট এডিশন :প্রিমিয়াম, এটি ওয়েব ডেভেলপমেন্ট এবং ডেটাবেসের জন্য উন্নত ফিচার প্রদান করে।

আপনার জন্য উপযুক্ত সংস্করণটি JetBrains ওয়েবসাইট থেকে ডাউনলোড করুন: https://www.jetbrains.com/idea/download/

IDE স্বয়ংক্রিয়ভাবে আপনার ফাইলগুলো সনাক্ত করবে`build.gradle.kts` et settings.gradle.kts, আপনাকে শক্তিশালী অটো-কম্প্লিটেশন, কোড নেভিগেশন এবং ইন্টিগ্রেটেড ডিবাগিং টুলস প্রদান করে।

3. Gradle : বিল্ড টুল

�যদিও প্রতিটি প্রকল্প Gradle Wrapper‑এর মাধ্যমে Gradle‑এর নিজস্ব সংস্করণ ব্যবহার করবে, গ্লোবাল Gradle ইনস্টল করা নতুন প্রকল্পের আরম্ভের মতো কাজের জন্য উপকারী (gradle init).

SDKMAN-er মাধ্যমে ingresos!

জেডিকেজের মতোই, SDKMAN! গ্রেডলের ইনস্টলেশনকে সহজ করে।

Gradle ইনস্টল করুন

sdk install gradle

ইনস্টলেশন যাচাই করুন

gradle -v

এই কমান্ডটি Gradle, Kotlin, Groovy এবং JDK-এর ব্যবহৃত সংস্করণগুলো দেখাবে।

4. JBake : স্ট্যাটিক সাইট জেনারেটর

JBake হল আমরা যে টুলটি ব্যবহার করবো আমাদের সোর্স ফাইলগুলোকে (যেমন এইটি) স্ট্যাটিক ওয়েবসাইটে রূপান্তর করতে। একটি স্থানীয় ইনস্টলেশন থাকা পরিবর্তerin সুবিধাজনক.

SDKMAN!এর মধ্যে ইনস্টলেশন

SDKMAN! সবচেয়ে সহজ পদ্ধতি।

JBake ইনস্টল করুন

sdk install jbake

ইনস্টলেশন যাচাই

jbake -v

এটি কমান্ডটি JBake এর সংস্করণ এবং তা যে Java পরিবেশ ব্যবহার করে তা সম্পর্কিত তথ্য প্রদর্শন করবে।

5. গ্রেডল র‍্যাপার: পরিপূর্ণ ভালো প্র্যাকটিস

একবার আপনার প্রকল্পটি তৈরি হয়ে গেলে (যা আমরা পরবর্তী নিবন্ধে দেখব), আপনি আর globals কমান্ডটি ব্যবহার করা উচিত না।gradle. দিকে, আপনি এটি ব্যবহার করবেনগ্র্যেডল ওয়ার্যাপার(./gradlew), আপনার প্রকল্পে অন্তর্ভুক্ত একটি স্ক্রিপ্ট.

কেন?

  • পুনরুৎপাদনযোগ্যতা :এই র‍্যাপার নিশ্চিত করে যে প্রকল্পে কাজ করছে প্রত্যেকো ব্যক্তি (আপনার CI/CD সার্ভার সহ) ঠিকভাবে ব্যবহার করেএকই সংস্করণের গ্র্যাডল, এভাবে বিভিন্ন পরিবেশের কারণে বিল্ড ত্রুটি দূর করে।

  • সরলতা :একটি প্রকল্পে অবদান রাখতে ম্যানুয়ালি Gradle ইনস্টল করার দরকার নেই।

শুধু সংগ্রহস্থলটি ক্লোন করুন এবং চালু করুন`./gradlew`।

একটি স্বাভাবিক কমান্ড এইভাবে দেখাবে :

# Ne pas faire : gradle build
# À faire :
./gradlew build

6. ডকার ও পোর্টাইনার : পুনরুৎপাদনযোগ্য বিল্ড (ঐচ্ছিক)

একটি প্লাগইন লিখতে সঠিকভাবে প্রয়োজন হলেও না, Docker এবং Portainer আধুনিক DevOps সরঞ্জাম, যা reproducible বিল্ড তৈরি এবং আপনার পরিবেশের ব্যবস্থাপনাকে খুব সহজ করে তোলে।

ডকার ইঞ্জিনের ইনস্টলেশন

Docker আপনাকে আপনার অ্যাপ্লিকেশন এবং এর নির্ভরশীলতাগুলি একটি কন্টেইনারে প্যাক করতে দেয়.

অফিশিয়াল স্ক্রিপ্টের মাধ্যমে Docker ইনস্টল করুন :

curl -fsSL https://get.docker.com -o get-docker.sh sudo sh get-docker.sh

**Dockerকে sudo ছাড়া ব্যবহার করুন (সুপারিশ করা হয়েছে) :

আপনার ব্যবহারকারীকে গোষ্ঠiere যোগ করুন`docker`.

sudo usod -aG docker $USER
docker run hello-world

পোর্টেইনার (GUI) ব্যবহার করে Docker পরিচালনা করুন

Portainer হল একটি হালকা ওয়েব ইন্টারফেস যা আপনার ডকার কনটেইনার পরিচালনা করতে ব্যবহৃত হয়।

একটি ভলিউম তৈরি করুন পোর্টেইনারের ডেটা জোন诺 :

docker volume create portainer_data

Portainer কনটেইনার চালু করุ่น:

docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:latest

আপনি এখন পোর্টায়েনার ইন্টারফেসটি উপরে অ্যাক্সেস করতে পারেন`https://localhost:9443`.

উপসংহার

আপনার পরিবেশ এখন প্রস্তুত! আপনার কাছে একটি JDK, সবচেয়ে উপযুক্ত IDE, Gradle এবং JBake আছে। ডকার যোগড়া করলে, আপনিও কনটেইনারাইজড এবং পুনরুৎপাদনযোগ্য বিল্ডগুলো তৈরি করতে প্রস্তুত। এই দৃঢ় ভিত্তি আপনাকে মৌলিক দিকগুলিতে—শক্তিশালী ও উপযোগী প্লাগইন উন্নয়নে— ফোকাস করতে সাহায্য করবে।

আসন্ন নিবন্ধে, আমরা কমান্ডটি ব্যবহার করব।`gradle init`আমাদের প্রথম প্লাগইন প্রকল্পের গঠন তৈরি করার জন্য
