Deze handleiding legt stap voor stap uit hoe je de terminal kitty installeert op Xubuntu, deze correct configureert en bash vervangt door zsh als standaardshell. Het project kitty is beschikbaar hier: https://github.com/kovidgoyal/kitty.

_ Kitty is een moderne, snelle en configureerbare terminal, vooral geschikt voor veeleisende ontwikkelaars. _

Waarom kiezen voor Kitty en Zsh?

Kitty onderscheidt zich door :

  • Betere prestaties dankzij GPU-versnelling,

  • Een configuratie volledig gebaseerd op één enkel tekstbestand,

  • Een uitstekende ondersteuning voor lettertypen en ligaturen.

Zsh is daarentegen een krachtige interactieve shell die biedt:

  • Een intelligente aanvulling,

  • Een aanpasbaar prompt,

  • Een grote compatibiliteit met bash.

Door Kitty en Zsh te combineren, geniet je van een productieve en esthetische omgeving.

@startuml
title Vereenvoudigde architectuur Kitty + Zsh
actor User

User --> Kitty : Lance le terminal
Kitty --> Zsh : Initialise le shell interactif
Zsh --> System : Interagit avec le système (fichiers, commandes)
@enduml

Deze handleiding is bewust beperkt tot de installatie via een script en tot Xubuntu.

Systeemvereisten

Voordat je begint, zorg ervoor dat je:

  • Xubuntu geïnstalleerd,

  • een toegang tot internet,

  • een werkende bash-shell om het script te starten

Controleer uw omgeving :

uname -a
lsb_release -a

Download en installatie van Kitty

Kitty raadt aan om het te installeren via een officieel script dat de bestanden in`~/.local/kitty.app`.

Deze methode is onafhankelijk van pakketbeheerders (geen`apt`).

Download het installatiescript

Voer de volgende opdracht uit:

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

Deze opdracht voert:

  • download van de binaire bestanden,

  • extraction in`~/.local/kitty.app`,

  • aanmaken van symbolische koppelingen

@startuml
title Download en installatie van Kitty
start
:curl -L installer.sh;
:sh /dev/stdin;
:Décompression dans ~/.local/kitty.app;
:create symlinks;
stop
@enduml

Aanmaak van de symbolische links

Om te kunnen aanroepen`kitty`vanaf de terminal, maak een symbolische koppeling:

ln -s ~/.local/kitty.app/bin/kitty ~/.local/bin/kitty

Voeg`~/.local/bin`aan je PATH als het nog niet is gedaan:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

Je kunt de installatie controleren:

kitty --version

Integratie van Kitty in Xubuntu

Zodat Kitty in het menu van de applicaties verschijnt:

Kopieer het bestand desktop

Kopieer het bestand`.desktop`verstrekt:

cp ~/.local/kitty.app/share/applications/kitty.desktop ~/.local/share/applications/

Wijzig het desktop-bestand

Bewerk het bestand :

nano ~/.local/share/applications/kitty.desktop

Controleer of bewerk de volgende regels:

[Desktop Entry]
Version=1.0
Type=Application
Name=Kitty Terminal
Comment=Fast GPU-based terminal emulator
Exec=/home/$USER/.local/kitty.app/bin/kitty
Icon=kitty
Categories=System;TerminalEmulator;

Vervang`YOURUSER`door uw gebruikersnaam.

:Editer les chemins;
:Sauvegarder;
:Menu Applications;
stop
@enduml

Kitty koppelen als standaardterminal (optioneel)

Zodat Kitty wordt gelanceerd als de standaardterminal:

sudo update-alternatives --install /usr/bin/x-terminal-emulator x-terminal-emulator ~/.local/kitty.app/bin/kitty 50
sudo update-alternatives --config x-terminal-emulator

Selecteer`kitty`in het voorgestelde menu

Installatie van Zsh

Als Zsh nog niet geïnstalleerd is, voer uit:

sudo apt install zsh

Controleer de installatie:

zsh --version

Stel Zsh in als standaardshell

U kunt uw shell wereldwijd wijzigen of alleen in Kitty.

Globale methode (voor alle terminals)

Identificeer het absolute pad:

which zsh

In het algemeen`/usr/bin/zsh`.

Wijzig de standaard-shell :

chsh -s /usr/bin/zsh

Log uit en log weer in.

@startuml

@enduml

Specifieke methode voor Kitty

Als je alleen de shell in Kitty wilt wijzigen, bewerk dan het configuratiebestand:

nano ~/.config/kitty/kitty.conf

Voeg deze regel toe:

shell zsh

Sla op en herstart Kitty.

Configuratie van Zsh (optioneel)

Om je Zsh aan te passen :

Maak een .zshrc-bestand aan

touch ~/.zshrc
nano ~/.zshrc

Voorbeeld van minimale configuratie

export ZSH_THEME="robbyrussell"
export PATH="$HOME/.local/bin:$PATH"
alias ll="ls -la"

Eindcontrole

Start Kitty :

kitty

Je zou moeten zien dat`zsh`is actief :

echo $SHELL

Verwacht resultaat :

/usr/bin/zsh

Om de lettergrootte aan te passen inKitty, het parameter moet worden aangepast`font_size`in het configuratiebestand. Hier volgt de gedetailleerde procedure:

📂 Open het configuratiebestand

Het hoofdconfiguratiebestand bevindt zich gewoonlijk in :

~/.config/kitty/kitty.conf

Als dit bestand nog niet bestaat, kun je het maken. (Empty)

nano ~/.config/kitty/kitty.conf

�🖋️ Toevoegen of wijzigen `font_size

Voeg de volgende richtlijn toe, of wijzig deze als deze al bestaat:

font_size 14.0

Hier`14.0`Komt overeen met de gewenste grootte. U kunt elke decimale waarde invoeren, bijvoorbeeld`12.0`, 15.5, etc.

💾 Opslaan en Kitty opnieuw starten

  • Opslaan (Ctrl + O, dan`Entrée`) en verlaten (Ctrl + X) als je gebruikt`nano`.

  • Sluit alle vensters van Kitty en herstart de terminal zodat de wijziging effect krijgt.

Dynamische aanpassing (tijdelijke zoom)

Als je tijdelijk wilt in-/uitzoomen zonder de configuratie te wijzigen, gebruik je de standaardsneltoetsen:

  • Vergroot de lettergrootte:

Ctrl + Shift + =

  • Verklein de lettergrootte:

Ctrl + Shift + -

  • Formaat opnieuw instellen:

Ctrl + Shift + Backspace

Deze instellingen blijven niet behouden na het sluiten van de terminal.

Installatie en configuratie van Oh My Zsh

Nadat Zsh is geïnstalleerd en ingesteld als standaardshell, kun je je omgeving verrijken met Oh My Zsh, een framework voor het beheren van de Zsh-configuratie, biedt:

  • een collectie van thema’s voor de prompt,

  • veel plugins,

  • een duidelijke organisatie van de configuratie.

Installatie van Oh My Zsh

Zorg ervoor dat Zsh actief is:

zsh --version

Indien nodig, start:

zsh

Download dan en voer het officiële installatiescript uit:

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

Dit script :

  • Maak de map`~/.oh-my-zsh`,

  • Sla eventueel uw bestand op`~/.zshrc`,

  • activeert automatisch de nieuwe prompt.

Wijzig het thema

Open uw configuratiebestand:

nano ~/.zshrc

Wijzig de variabele`ZSH_THEME`om een ander thema te kiezen (bijvoorbeeld`agnoster`) :

ZSH_THEME="agnoster

Opslaan en vervolgens de configuratie opnieuw laden :

source ~/.zshrc

Verificatie

Start Kitty en controleer of de prompt goed is veranderd. Je kunt bevestigen dat Oh My Zsh actief is door het volgende uit te voeren:

echo $ZSH

Het resultaat zou vergelijkbaar moeten zijn met :

/home/jouw_gebruiker/.oh-my-zsh

Activeer de transparantie in Kitty

Een van de meest gewaardeerde functies van Kitty is de mogelijkheid om transparantie toe te voegen aan de achtergrond van de terminal. Dit maakt het mogelijk om de onderliggende omgeving (venster, bureaublad, enz.) lichtjes te zien, wat vooral handig is bij multitasking.

Vereisten voor transparantie

De transparantie in Kitty is gebaseerd op hetvenstercomponistgebruikt door de grafische omgeving. Onder Xubuntu (gebaseerd op XFCE), zorg ervoor dat decompositie is geactiveerd.

Te controleren:

  • rechtsklikken op het bureaublad > Instellingen >Instellingen van de vensterbeheerder,

  • tabbladComponisthet vakje "Activer la composition" moet worden aangevinkt.

}

@enduml

Configuratie van de transparantie in kitty.conf

Open uw configuratiebestand`~/.config/kitty/kitty.conf`:

nano ~/.config/kitty/kitty.conf

Voeg of wijzig de volgende regels:

background_opacity 0.85

Deze parameter accepteert waarden tussen :

  • 1.0→ opaa k (geen transparantie),

  • 0.0→ volledig transparant (onbruikbaar),

  • tussenwaarden als`0.90`, 0.75, enz.

Een goed visueel compromis ligt meestal tussen`0.85` et 0.95.

Redémarrer Kitty

Fermez toutes les instances de Kitty, puis relancez une nouvelle fenêtre pour que les modifications prennent effet :

kitty

Compléments possibles

Si vous utilisez un fond de terminal personnalisé, vous pouvez également définir une couleur de fond avec transparence (en RGBA) :

background #1e1e2eff

La dernière composante (ff) indique l’opacité (de 00 à ff).

Limitations connues

La translucidité ne fonctionne pas si : - le compositeur XFCE est désactivé, - een niet-compatibele vensterbeheerder wordt gebruikt, - u gebruikt Kitty in een tmux-modus op de achtergrond zonder transparantie-ondersteuning.

Désactiver le bip sonore (audible bell)

Par défaut, Kitty émet un son de bip lorsqu’une commande erronée est saisie ou qu’un événement terminal le déclenche. Ce bruit peut rapidement devenir gênant, surtout dans un environnement de développement intensif.

Pour désactiver ce comportement, ajoutez la directive suivante au fichier ~/.config/kitty/kitty.conf :

audible_bell no

Vous pouvez également activer un retour visuel en remplacement du bip sonore avec :

visual_bell yes

Mise à jour de Kitty

Puisque Kitty est installé via un script et non un gestionnaire de paquets, la mise à jour se fait en relançant le script d’installation officiel. Cela permet de télécharger la dernière version et de mettre à jour votre installation existante dans ~/.local/kitty.app.

Le suffixe .app dans le chemin ~/.local/kitty.app est la convention d’installation de Kitty sur Linux via son script officiel, et n’indique en aucun cas une compatibilité exclusive avec macOS.

Avant de lancer la commande de mise à jour, assurez-vous d’être dans votre répertoire personnel (~).

Exécutez la commande suivante depuis votre répertoire personnel :

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

Ce script se chargera de :

  • Télécharger les binaires de la nouvelle version.

  • Extraire les fichiers dans ~/.local/kitty.app.

  • Mettre à jour les liens symboliques si nécessaire.

Après la mise à jour, il est recommandé de fermer toutes les instances de Kitty et de les relancer pour s’assurer que la nouvelle version est bien prise en compte.
