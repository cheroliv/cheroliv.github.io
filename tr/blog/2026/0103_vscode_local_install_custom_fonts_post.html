VS Code’yu neden kurmalısınız`/opt`veya aracılığıyla`apt`Evinizde yerleştirebildiğiniz ve IDE’nizi hiçbir şey yazmadan oyun alanı haline getirdiğinizde`sudo`? Bu, yerel bir kurulumun ardından menü ve dosya gezgini yazı tiplerini büyütmek için geçmiş bir mücadele öyküsü.

Neden: VS Code evde

Sistem kurulumuyla ilgili sorun

VS Code üzerinden kurulu`apt`, dnf`veya içinde/opt`Uygulama dosyalarını root izinlerinin arkasında kilitler. Native CSS’in herhangi bir değişikliği, de`product.json`veya kurulum klasörü gerektirir`sudo`.

Ama, biri kullanırkenopencodeAjan, yapabilmesi gereken şeyler:

  • Yapılandırma dosyalarına yazmak`~/.config/Code/User/settings.json`) — bu zaten home’de

  • IDE’nin varlıklarını değiştir (workbench CSS’ini,product.json) için gelişmiş özelleştirmeler — bu, sudo olmadan kilitli

Çözüm : yerel bir kurulum

Resmi tarball arşivini indirir ve doğrudan içinde`~/apps/`:

mkdir -p ~/apps
cd ~/apps
wget "https://code.visualstudio.com/sha/download?build=stable&os=linux-x64" -O vscode.tar.gz
tar -xzf vscode.tar.gz
rm vscode.tar.gz

İkili daha sonra içinde`~/apps/VSCode-linux-x64/bin/code`. Yok`sudo`okumak, düzenlemek veya değiştirmek için gerekli değil herhangi bir dosya altında`~/apps/VSCode-linux-x64/`.

Ana menü fontunu özelleştir

Tespit

Ana menünün (Dosya, Düzenle, Görüntüle…​) ve açılır menülerinin varsayılan yazı tipi çok küçük. VS Code bunu değiştirmek için herhangi bir ayar sunmaz.

Teknik: doğrudan CSS yaması

Dosyanın sonuna CSS ekliyoruz.workbench.desktop.main.css</think>

@startuml
skinparam backgroundColor #FEFEFE
autonumber

actor Développeur as dev
participant "workbench.desktop\n.main.css" as css
participant "product.json" as product
participant "VS Code" as vscode

== Patch CSS ==
dev -> css : Ajouter règles font-size\n(.menubar-menu-title, etc.)
dev -> vscode : Redémarrer VS Code
vscode -> vscode : Charge le CSS patché
vscode --> dev : Menus et dropdowns en 23px/22px ✓

== Suppression warning ==
vscode --> dev : ⚠️ "Kurulumunuz bozuk."
dev -> product : Supprimer clé "sağlama toplamları"\n(python3 -c ...)
dev -> vscode : Redémarrer VS Code
vscode --> dev : Plus de warning ✓

note over css, product
  Deux fichiers dans ~/apps/
  = modifiables sans sudo
end note
@enduml
CSS_FILE="$HOME/apps/VSCode-linux-x64/resources/app/out/vs/workbench/workbench.desktop.main.css"

cat >> "$CSS_FILE" << 'EOF'
.menubar-menu-title{font-size:23px!important}
.menubar>.menubar-menu-button{font-size:23px!important}
.monaco-menu-option{font-size:22px!important;line-height:34px!important}
.monaco-menu .action-label:not(.codicon){font-size:22px!important}
.menubar-menu-items-holder .monaco-menu .action-item .action-label{font-size:22px!important}
EOF

İntegrite uyarısını sil

VS Code, dosyalarındaki değişiklikleri algılar ve 'Yüklemeniz bozuk' ibaresini gösteren bir şerit gösterir. Bunu önlemek için, sağlama toplamlarını sileriz`product.json`:

import json
product_json = "$HOME/apps/VSCode-linux-x64/resources/app/product.json"
with open(product_json, 'r') as f:
    data = json.load(f)
data.pop('checksums', None)
with open(product_json, 'w') as f:
    json.dump(data, f, indent=2)

Yeniden başlatıldıktan sonra uyarı kalmadı ve menüler artık okunabilir.

Geziyici bölmesinin yazı tipini özelleştirmek — mücadele

Deneme 1: mevcut olmayan bir parametre

İlk önce yerel parametreyi deneriz`workbench.tree.fontSize`içinde`settings.json`:

{
    "workbench.tree.fontSize": 20
}

Sonuç:hiçbir etki. Bu ayar VS Code’da mevcut değil. Tanınmayan ayarların sessizce yoksayıldığını kanıtlar.

Deneme 2: Custom CSS and JS Loader uzantısı

Eklentiyi kuruyoruz`be5invis.vscode-custom-css` :

~/apps/VSCode-linux-x64/bin/code --install-extension be5invis.vscode-custom-css

Bir CSS dosyası oluşturuyoruz içinde`~/.vscode-custom-css/custom.css`gezgin öğelerini hedefleyen seçiciler :

.monaco-tree-rows .monaco-tree-row,
.sidebar .monaco-list-row,
.explorer-viewlet .monaco-list-row,
.monaco-list-row .monaco-icon-label {
    font-size: 22px !important;
    line-height: 36px !important;
}

Ve bu dosya ayarlar içinde referans gösterilir:

{
    "vscode_custom_css.imports": [
        "file:///home/user/.vscode-custom-css/custom.css"
    ]
}

Sonuç :değişiklikler geçerli değil.

Tuzak: her defasında uzantıyı etkinleştirmek gerekir.

Eklentinin belgeleri bu kritik konuda özen göstermez : Her CSS özelleştirmesi değiştirildikten sonra yapılması gerekirzorunlu olarakpaletten komutu çalıştır :

  1. `Ctrl+Shift+P`yazmakÖzel CSS ve JS’yi Etkinleştir

  2. VS Code yeniden başlatma istiyor → kabul et

Bu adım olmadan, CSS asla IDE’ye enjekte edilmez.

Deneme 3: çizgiler üst üste geliyor

Bile`font-size: 22px` et line-height: 36px, çubuklu harfler (g, p, f, b) komşu satırlara taşar. Eklemeye çalışıyoruz`height` et min-height :

.monaco-list-row {
    height: 36px !important;
    min-height: 36px !important;
}

Sonuç :Hiç değişiklik yok. VS Code, JavaScript’te satır yüksekliğini hesaplar ve CSS değerlerini geçersiz kılar.

`zoom`Kapsayıcı görüntüsünü — metin VE boşluk — eşit şekilde büyütür, VS Code’in JavaScript motorunun hesapladığı düzeni bozmadan. 1.25 katsayısı yaklaşık olarak 13px’ten 16px’e geçişe denk gelir.

autonumber

dev -> script : ./vscode-update.sh
script -> local : Lire version courante
script -> remote : wget dernière version
script -> script : Comparer versions

alt Version identique
    script --> dev : "Zaten güncel!"
else Nouvelle version
    script -> backup : Sauvegarder installation courante\n(horodatée)
    script -> local : rm -rf ancienne installation
    script -> local : mv nouvelle installation
    script -> css : Ajouter patch CSS\n(menubar 23px, dropdown 22px)
    script -> product : Supprimer checksums\n(python3)
    script --> dev : "Güncelleme tamamlandı\n1.xx.yy → 1.zz.ww"
end note
@enduml

Sorun

VS Code güncellerken, kurulum klasörünü değiştirir veTüm CSS yamalarını siler. Değişiklikleri her seferinde manuel olarak yeniden uygulamamız gerekiyor.

Bu betik `vscode-update.sh

Biz oluşturuyoruz`~/apps/vscode-update.sh`:

#!/bin/bash
set -e

VSCODE_DIR="$HOME/apps/VSCode-linux-x64"
BACKUP_DIR="$HOME/apps/vscode-backup"
TEMP_DIR="/tmp/vscode-update"

MENUBAR_FONT_SIZE="23px"
DROPDOWN_FONT_SIZE="22px"

echo "=== VS Code Local Updater ==="

CURRENT_VERSION=$("$VSCODE_DIR/bin/code" --version 2>/dev/null | head -1)
echo "Current version: $CURRENT_VERSION"

echo "Downloading latest VS Code..."
mkdir -p "$TEMP_DIR"
wget -q "https://code.visualstudio.com/sha/download?build=stable&os=linux-x64" \
    -O "$TEMP_DIR/vscode.tar.gz"

echo "Extracting..."
mkdir -p "$TEMP_DIR/extracted"
tar -xzf "$TEMP_DIR/vscode.tar.gz" -C "$TEMP_DIR/extracted"

NEW_VERSION=$("$TEMP_DIR/extracted/VSCode-linux-x64/bin/code" \
    --version 2>/dev/null | head -1)
echo "New version: $NEW_VERSION"

if [ "$CURRENT_VERSION" = "$NEW_VERSION" ]; then
    echo "Already up to date!"
    rm -rf "$TEMP_DIR"
    exit 0
fi

echo "Backing up current installation..."
mkdir -p "$BACKUP_DIR"
cp -r "$VSCODE_DIR" "$BACKUP_DIR/VSCode-linux-x64-$(date +%Y%m%d-%H%M%S)"

echo "Updating..."
rm -rf "$VSCODE_DIR"
mv "$TEMP_DIR/extracted/VSCode-linux-x64" "$VSCODE_DIR"
rm -rf "$TEMP_DIR"

CSS_FILE="$VSCODE_DIR/resources/app/out/vs/workbench/workbench.desktop.main.css"
echo "Re-applying custom CSS patch \
    (menubar=${MENUBAR_FONT_SIZE}, dropdown=${DROPDOWN_FONT_SIZE})..."
cat >> "$CSS_FILE" << CSSEOF
.menubar-menu-title{font-size:${MENUBAR_FONT_SIZE}!important}\
.menubar>.menubar-menu-button{font-size:${MENUBAR_FONT_SIZE}!important}\
.monaco-menu-option{font-size:${DROPDOWN_FONT_SIZE}!important;\
line-height:34px!important}\
.monaco-menu .action-label:not(.codicon)\
{font-size:${DROPDOWN_FONT_SIZE}!important}\
.menubar-menu-items-holder .monaco-menu .action-item .action-label\
{font-size:${DROPDOWN_FONT_SIZE}!important}
CSSEOF

PRODUCT_JSON="$VSCODE_DIR/resources/app/product.json"
if [ -f "$PRODUCT_JSON" ]; then
    echo "Removing checksums to prevent integrity warning..."
    python3 -c "
import json
with open('$PRODUCT_JSON','r') as f: data=json.load(f)
data.pop('checksums', None)
with open('$PRODUCT_JSON','w') as f: json.dump(data,f,indent=2)
print('Done.')
"
fi

echo "=== Update complete: $CURRENT_VERSION -> $NEW_VERSION ==="

Betik :

  1. İndir en son stabil sürümü

  2. Sürümün mevcut sürümden farklı olup olmadığını kontrol et.

  3. Geçerli kurulumu (zaman damgalı) kaydet`~/apps/vscode-backup/`

  4. Kurulum klasörünü değiştir

  5. Yeniden uygulaana menünün CSS yaması

  6. Checksum’leri sil de `product.json`bütünlük uyarısından kaçınmak için

NOT: Gezgin bölmesinin özelleştirmeleri, Custom CSS uzantısı ve dosya üzerinden yapılır.`~/.vscode-custom-css/custom.css`Güncellemelerde de hayatta kalırlar, çünkü kurulum klasörü dışında yaşarlar.

Evde kurmak her şeyi serbest bırakır

Yerel bir kurulumda`~/apps`VS Code üzerinde tam kontrol sağlar :

  • Yok`sudo`CSS’yi veya yapılandırmayı değiştirmek için

  • Opencode+LLM ajanı, IDE’nin yapılandırma dosyalarına ve varlıklarına yazabilir.

  • basit Rollback : zaman damgalı yedeği geri yükle

zoom` > font-size bileşenler listesi için

VS Code, JavaScript üzerinden satır yüksekliğini kontrol eder. Değiştir`font-size`Layout motoru tarafından ayrılan yüksekliğe dokunamadığı için metinler taşar. Özellik`zoom`Ana konteyner üzerindeki büyütme, orantılı olarak her şeyi büyütür ve bu sorunu aşar.

Custom CSS uzantısı açıkça etkinleştirilmesi gerekiyor

Bu bir 'set and forget' ayarı değil. Custom CSS dosyasındaki her değişiklik, 'Enable Custom CSS and JS' komutunu komut paletesinden yeniden çalıştırmayı gerektirir (Ctrl+Shift+P).

Bir güncelleme scripti zorunludur

Betik olmadan, VS Code’un her güncellemesi workbench’in CSS yamalarını siler. Betik`vscode-update.sh`indirmeyi, değiştirmeyi, yeniden yamalama ve checksum temizlemeyi otomatikleştirir
