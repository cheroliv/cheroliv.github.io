Mimari Vizyon

Yönlendiren ilke

Mimarisi ilgilin ayrımı prensibe:

  • İçerik : Yapılandırılmış AsciiDoc dosyaları zengin meta verilerle

  • Sunum : yeniden kullanılabilir Thymeleaf şablonları

  • Veriler : JBake tarafından AsciiDoc özniteliklerinden otomatik olarak çıkarılan model

  • Style : Bootstrap 5 görsel tutarlılık için

Stratejik seçim: Portföy için AsciiDoc

Table 1. AsciiDoc neden ?
Kritér avantaj

Tutarlılık

Blog makaleleriyle aynı format

Metaveriler

Yapılandırılmış ve genişletilebilir özellikler (project-*)

Bakım kolaylığı

Basit metin düzenleme, Git ile sürüm kontrolü yapılabilir

Esneklik

Zengin içerik (tablolar, kod, resimler) içerebilir

şablonlama

JBake Thymeleaf için öznitelikleri otomatik olarak çıkarır

Veri modeli

Her portföy projesi bir AsciiDoc belgesidir:

  • Üstbilgi meta verileri : yapılandırılmış bilgiler (müşteri, süre, teknolojiler, vb.)

  • Belge gövdesi : anarşif betimleme, zorluklar, çözümler, sonuçlar

  • Özel özellikler : önekli`project-*`otomatik çıkarma için

@startuml
skinparam backgroundColor #FEFEFE
skinparam handwritten false

class ProjetAsciiDoc {
  +titre: String
  +jbake-type: "proje"
  +jbake-status: published|draft
  +jbake-date: Date
  +jbake-tags: List<String>
  --
  +project-category: String
  +project-client: String
  +project-duration: String
  +project-role: String
  +project-thumbnail: String
  +project-gallery: List<String>
  +project-tech-stack: String
  +project-highlights: List<String>
  +project-demo-url: String
  +project-github-url: String
  --
  +body: HTML (converti)
}

class JBakeEngine {
  +parse(asciidoc)
  +extractMetadata()
  +convertToHTML()
}

class ThymeleafTemplate {
  +portfolio.html
  +project.html
  +partials/project-card.html
}

class PortfolioPage {
  +published_projects: List
  +filtres: categories
}

ProjetAsciiDoc --> JBakeEngine : parse
JBakeEngine --> ThymeleafTemplate : fournit données
ThymeleafTemplate --> PortfolioPage : génère
@enduml

Detaylı Kullanım Senaryoları

UC1 : Portföye bir öğe eklemek

Nominal akış

@startuml
skinparam backgroundColor #FEFEFE
actor Développeur as dev
participant "Düzenleyici
Metin" as editor
participant "Dosya\nAsciiDoc" as file
participant "JBake\nMotor" as jbake
participant "statik
site" as site

dev -> editor : Créer nouveau fichier
activate editor
editor -> file : portfolio/nouveau-projet.adoc
activate file

dev -> editor : Rédiger en-tête avec métadonnées\n(titre, type=project, status=published,\nattributs project-*)
dev -> editor : Rédiger contenu narratif\n(contexte, défis, solutions)
dev -> editor : Ajouter images dans assets/img/portfolio/

editor -> file : Sauvegarder
deactivate editor

dev -> jbake : Lancer build (jbake -b)
activate jbake
jbake -> file : Lire et parser
jbake -> jbake : Extraire métadonnées
jbake -> jbake : Convertir AsciiDoc → HTML
jbake -> jbake : Appliquer template project.html
jbake -> jbake : Ajouter à la liste portfolio.html
jbake -> site : Générer pages statiques
deactivate jbake

dev -> site : Vérifier résultat
activate site
site --> dev : Afficher projet
deactivate site
@enduml

Oluşturulacak dosya şablonu

Geliştirici oluşturur`content/portfolio/nom-projet.adoc`standartlaştırılmış bir yapıyla :

  • Tüm gerekli özniteliklere sahip başlık

  • Normalleştirilmiş bölümler (Bağlam, Zorluklar, Çözümler, Sonuçlar)

  • Görüntüler için tutarlı adlandırma

Doğrulama puanları

  • Zorunlu öznitelikler mevcut (jbake-type, jbake-status, project-thumbnail)

  • Bağlantı verilen görüntüler içinde bulunur`assets/img/portfolio/`

  • JBake derlemesi hatasız olarak başarılı olur

  • Proje, portföy sayfasında görünür.

  • Bireysel proje sayfası doğru şekilde görüntüleniyor.

participant "Sistem

deactivate site
@enduml

Alternatif strateji: arşivleme

Kalıcı olarak silmek yerine, bir klasör oluşturma olanağı`content/portfolio/archive/`:

  • Dosyayı silmek yerine taşı

  • Kolayca geri yüklemeye izin verir

  • Git geçmişini daha açık tut

Kaynak temizliği

  • Yetim görüntülerde kontrol et`assets/img/portfolio/`

  • Başka projeler tarafından referans alınmayan görüntüleri sil

  • JBake önbelleğini temizleyerek hayalet referanslardan kaçının

UC3: Yayınlanmamış (taslak) yap

nominal akış

@startuml
skinparam backgroundColor #FEFEFE
actor Développeur as dev
participant "Dosya\nAsciiDoc" as file
participant "JBake
Engine" as jbake
participant "Site
Statik" as site

dev -> file : Ouvrir portfolio/projet.adoc
activate file

dev -> file : Modifier attribut\n:jbake-status: published\n↓\n:jbake-status: draft

file --> dev : Sauvegardé
deactivate file

dev -> jbake : Rebuild (jbake -b)
activate jbake
jbake -> file : Parser le fichier
jbake -> jbake : Détecter status=draft
jbake -> jbake : Exclure de published_projects
jbake -> jbake : Ne pas créer page publique
note right
  Le projet existe toujours
  mais n'est pas publié
end note
jbake -> site : Générer site (sans ce projet)
deactivate jbake

dev -> site : Vérifier portfolio
activate site
site --> dev : Projet absent de la liste publique
deactivate site
@enduml

Olası durumlar

@startuml
skinparam backgroundColor #FEFEFE

[*] --> Draft : Création initiale
Draft --> Published : Validation et publication
Published --> Draft : Retrait temporaire
Draft --> Archived : Projet abandonné
Published --> Archived : Projet obsolète
Archived --> [*] : Suppression définitive
Published --> Published : Mises à jour

note right of Draft
  :jbake-status: draft
  Non visible publiquement
  Utile pour projets en cours
end note

note right of Published
  :jbake-status: published
  Visible sur le portfolio
  Indexé par JBake
end note

note right of Archived
  Déplacé dans archive/
  ou jbake-status: archived
  Non publié mais conservé
end note
@enduml

Tipik kullanım durumları

  • Taslak aşamasında proje : taslak olarak oluştur, hazır olduğunda yayınla

  • Geçici gizli proje : Müşteri onay süresi boyunca drafta geçmek

  • Ana güncelleme : taslağa geçmek, düzenlemek, yeniden yayınlamak

  • A/B testing : taslakta kopyala, test et, en iyi versiyonu yayınla

Veri çıkarma deseni

JBake, AsciiDoc özelliklerini Thymeleaf içinde erişilebilir özelliklere otomatik olarak dönüştürür:

@startuml
skinparam backgroundColor #FEFEFE

rectangle "AsciiDoc Belgesi" {
  (":project-client: Acme Corp") as attr1
  (":project-duration: 6 ay") as attr2
  (":project-tags: java, react") as attr3
}

rectangle "JBake modeli" {
  (content['project-client']) as prop1
  (content['project-duration']) as prop2
  (content.tags) as prop3
}

rectangle "Şablon Thymeleaf" {
  (th:text="${project['project-client']}") as tmpl1
  (th:text="${project['project-duration']}") as tmpl2
  (th:each="etiket : ${project.tags}") as tmpl3
}

attr1 --> prop1 : parsing
attr2 --> prop2 : parsing
attr3 --> prop3 : parsing

prop1 --> tmpl1 : binding
prop2 --> tmpl2 : binding
prop3 --> tmpl3 : binding
@enduml

Adlandırma kuralları

  • Proje Özellikleri : önek`project-*` (ex: project-client, project-tech-stack)

  • Dosyalar : kebab-case (ex:`ecommerce-platform.adoc`)

  • Resimler: proje adı öneki (örnek:`ecommerce-platform-thumb.jpg`)

  • Templates : fonksiyonel isim (örnek:`project-card.html`, tech-badge.html)

Extensibilité

Ajout de nouveaux attributs

Pour enrichir le modèle de données, simplement ajouter de nouveaux attributs préfixés project-* :

  • project-awards: Prix et reconnaissances

  • project-testimonial: Citation client

  • project-team-size: Taille équipe

  • project-budget-range: Fourchette budgétaire

Ces attributs deviennent automatiquement disponibles dans les templates sans modification du moteur JBake.

Bonnes Pratiques

Organisation des fichiers

  • Un fichier = un projet : éviter de mélanger plusieurs projets

  • Images dans dossier dédié : assets/img/portfolio/nom-projet/

  • Nomenclature cohérente : facilite recherche et maintenance

  • Versioning Git : tracking complet des modifications

İçerik yönetimi

  • Statut draft par défaut : publier seulement quand prêt

  • Review avant publication : validation qualité et confidentialité

  • Métadonnées complètes : remplir tous les champs pertinents

  • Contenu narratif riche : ne pas se limiter aux métadonnées

Performance

  • Optimiser images : compression avant commit

  • Pagination si nécessaire : si >20 projets

  • Lazy loading : images des galeries chargées à la demande

  • Cache navigateur : headers appropriés pour assets

Sonuç

Cette architecture permet :

  • Simplicité d’usage : ajouter un projet = créer un fichier texte

  • Flexibilité : extensible via nouveaux attributs

  • Maintenabilité : séparation contenu/présentation

  • Traçabilité : versioning Git complet

  • Automatisation : build et déploiement continus possibles

Le choix d’AsciiDoc assure la cohérence avec le reste du site tout en offrant la richesse des métadonnées nécessaires à un portfolio professionnel.
