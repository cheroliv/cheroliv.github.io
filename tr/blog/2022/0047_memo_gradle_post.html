Εμφάνιση βοήθειας

./gradlew --help

Ορισμός της ιδιότητας συστήματος της JVM: `-D, --system-prop

./gradlew -Dmyprop=myvalue
#ou
./gradlew --system-prop myvalue

Ορισμός της ιδιότητας του έργου για το build script: `-Pmyprop=myvalue

./gradlew -Pmyprop=myvalue
#ou
./gradlew --project-prop myvalue

Καθορίζει τον κατάλογο εκκίνησης του Gradle. Η προεπιλεγμένη τιμή είναι ο τρέχων κατάλογος.

./gradlew -p ~/src/next_startup
#ou
./gradlew --project-dir ~/src/next_startup

Υπερφορτύστε την ιδιότητα 'param_component' από τη γραμμή εντολών:

./gradlew -Pparam_component=CUSTOM_VALUE

Προσθέστε έναν φάκελο σε ένα source-set σε ένα κανονικό έργο με το Kotlin DSL

sourceSets {
    getByName("test"){
        java.srcDir("src/scripts/groovy")
    }
    getByName("test"){
        java.srcDir("src/scripts/kscript")
    }
    getByName("test"){
        java.srcDir("src/test/javascript")
    }
}

Προσθέστε έναν φάκελο σε ένα source‑set σε ένα έργο Android με το Groovy DSL

android {
    sourceSets {
        main.java.srcDirs += "src/main/../../../../ceelo/domain/src/main/java/"
        test.java.srcDirs += "src/test/../../../../ceelo/domain/src/test/java/"
    }
}

Αποφύγετε τη δημιουργία και τον έλεγχο ενός υπομέρου.

gradle build -x :excluded-module:check -x :excluded-module:assemble -x :excluded-module:build

Μετακίνηση αρχείων
tasks.register("moveWebappNode") {
    doLast {
        ant.withGroovyBuilder {
            "move"(
                "webapp/node_modules" to "$rootDir/webapp-src/node_modules",
            )
        }
    }
}

σύρτε ένα φάκελο

tasks.register<Tar>("tarWebapp") {
    dependsOn("moveWebappNpm")
    group = WEBAPP
    description = "tar webapp"
    doLast {
        setOf(
            "build",
            "target",
            "node_modules"
        ).forEach { dir -> exclude { it.name .dir } }
        archiveFileName.set("webapp.tar")
        destinationDirectory.set(File("${rootDir.absolutePath}$sep$WEBAPP_SRC"))
    }
}

Εμφάνιση εξαρτήσεων κατασκευής

tasks.register("printDependencies") {
    description = "print project dependencies"
    group = WEBAPP
    doLast {
        println("${project.name} dependencies")
        mutableMapOf<String, Map<String, String>>(
            "buildDependencies" to buildDependencies,
            "domainDeps" to domainDeps,
            "domainTestDeps" to domainTestDeps,
        ).apply { putAll(appModules) }
            .forEach { module ->
                if (module.value.isNotEmpty()) {
                    println("${module.key}:")
                    module.value.forEach { println(dependency(it)) }
                    println()
                }
            }
    }
}

Παράδειγμα χρήσης της reduce : ενώνουσα μιας λίστας σε μια συμβολοσειρά

tasks.register("printWebappSrc") {
    description = "print webapp sources"
    group = WEBAPP
    doLast {
        webAppSrc
            .reduce { acc, s -> "$acc\n\t$s" }
            .run { println("$WEBAPP_SRC: $this\n") }
    }
}

Λήψη της περιγραφίας μιας συγκεκριμένης εργασίας

./gradlew -q help --task foo

Για να εκκινήσετε μια εργασία από το workingDir ρίζα, προθέστε την εργασία με ένα `:

./gradlew :foo

Για να επανεκκινήσετε τις εργασίες που απέτυχαν, χρησιμοποιήστε την επιλογή `--rerun-tasks

./gradlew check --rerun-tasks

Εκκίνηση μιας εργασίας σε ένα συγκεκριμένο έργο από άλλο κατάλογο

Η επιλογή`-p` (ou --project-dir) επιτρέπει να καθορίσετε τη διαδρομή πρόσβασης σε ένα έργο Gradle και να εκτελέσετε μια εργασία σε αυτό, ακόμα κι αν ο τρέχων κατάλογος είναι διαφορετικός.

Για παράδειγμα, για να ξεκινήσετε την εργασία`build`du progetto`~/projets/mon-autre-projet`Enquanto είναι σε άλλο φάκελο :

./gradlew -p ~/projets/mon-autre-projet build

Αυτό είναι ιδιαίτερα χρήσιμο για τη γραφή σεναρίων ενεργειών σε πολλά έργα από ένα κεντρικό σημείο.
