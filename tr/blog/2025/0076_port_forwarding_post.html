Sorun : NAT ve özel adresler

Sorun : Ubuntu makinenizde bir web uygulaması geliştiriyorsunuz ve ev ağınız dışından erişilebilir hâle getirmek istiyorsunuz? Doğru yerdesiniz! Bu makalede, internet kutunuzda port yönlendirme yaparak bir yerel hizmet (örneğin 8080 numaralı porta) nasıl İnternet’e açılacağını göreceğiz.

Varsayılan olarak, internet kutunuz NAT (Network Address Translation) kullanarak tek bir genel IP adresini ev ağındaki tüm cihazlar arasında paylaşır. Yerel makineleriniz, internet üzerinden yönlendirilemeyen özel IP adresleri (192.168.x.x, 10.x.x.x, vb.) kullanır.

Ubuntu makinenizde bir hizmeti başlattığınızda (örnek: 8080 numaralı portta bir web sunucusu), bu hizmet yalnızca yerel ağınızdan erişilebilir. İnternet’ten de erişilebilir hale getirmek için bir port yönlendirme yapılandırması yapmamız gerekir.

Adım 1 : Kamu IP adresinizi belirleyin

Öncelikle, internet bağlantınızın genel IP adresini alın :

# Plusieurs méthodes au choix
curl ifconfig.me
curl ipecho.net/plain
wget -qO- http://ipecho.net/plain

# Ou encore
curl -s checkip.amazonaws.com

Bu IP adresi, kullanıcıların hizmetinize erişmek için kullanacakları adrestir.

Adım 2: Ubuntu makinenizin yerel IP adresini öğrenin

Ubuntu makineniz yerel ağınızda özel bir IP adresine sahiptir. Öğrenmek için:

# Afficher toutes les interfaces réseau
ip addr show

# Ou plus spécifiquement pour l'interface principale
ip route get 1.1.1.1 | awk '{print $7; exit}'

# Alternative avec hostname
hostname -I | awk '{print $1}'

Bu adresi not alın (örnek olarak`192.168.1.100`), yapılandırma için buna ihtiyacımız olacak

  • Livebox Portakal : 192.168.1.1

  • SFR Kutu:`192.168.1.1`

  • Bbox Bouygues:`192.168.1.254`

Adım 4 : Ubuntu’da hizmetin yapılandırılması

Hizmetinizin yalnızca localhost değil, tüm arayüzlerde dinlediğinden emin olun:

# ✅ Correct : écoute sur toutes les interfaces
python3 -m http.server 8080 --bind 0.0.0.0

# ❌ Incorrect : écoute seulement en local
python3 -m http.server 8080 --bind 127.0.0.1

Servisinizin doğru dinlediğinden emin olmak için :

# Vérifier les ports en écoute
sudo netstat -tlnp | grep :8080
# ou avec ss (plus moderne)
sudo ss -tlnp | grep :8080

Bir şey görmeniz gerekiyor gibi`0.0.0.0:8080`ve değil`127.0.0.1:8080`.

Adım 5 : Ubuntu güvenlik duvarı yapılandırması

Ubuntu varsayılan olarak UFW (Uncomplicated Firewall) kullanır. Gerekirse durumunu kontrol edin ve portu izni verin :

# Vérifier le statut du pare-feu
sudo ufw status

# Si le pare-feu est actif, autoriser le port 8080
sudo ufw allow 8080/tcp

# Ou plus spécifiquement pour un service web
sudo ufw allow 'Apache'  # si vous utilisez Apache
sudo ufw allow 'Nginx Full'  # si vous utilisez Nginx

Adım 6: Test ve doğrulama

Yerel ağdan test

Öncelikle, yerel ağınızdaki başka bir makineden erişimi test edin :

# Remplacez par l'IP locale de votre machine Ubuntu
curl http://192.168.1.100:8080

Test dışarıdan

Şimdi, genel IP adresinizi kullanarak Internet üzerinden test edin :

# Remplacez par votre IP publique
curl http://VOTRE_IP_PUBLIQUE:8080

Ayrıca çevrimiçi araçlar gibi kullanabilirsiniz:

  • https://www.yougetsignal.com/tools/open-ports/

  • https://canyouseeme.org/

İyi uygulamalar ve güvenlik

Temel güvenlik

# Configurer fail2ban pour protéger contre les attaques par force brute
sudo apt update && sudo apt install fail2ban

# Limiter l'accès avec UFW (exemple : autoriser seulement certaines IP)
sudo ufw allow from 203.0.113.0/24 to any port 8080

Bağlantı izleme

# Surveiller les connexions en temps réel
sudo netstat -an | grep :8080

# Logs des connexions (selon votre application)
sudo tail -f /var/log/nginx/access.log  # pour Nginx
sudo journalctl -f -u your-service      # pour un service systemd

Bir reverse proxy kullanımı

Daha iyi güvenlik ve esneklik için bir ters proxy gibi Nginx kullanmayı düşünün :

server {
    listen 80;
    server_name votre-domaine.com;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}

Port forwarding alternatifleri

Bulut çözümleri

  • ngrokgeçici güvenli tünel

  • Cloudflare Tunnel: ücretsiz ve güvenli çözüm

  • serveo.net: basit SSH tüneli

# Exemple avec ngrok
ngrok http 8080

# Exemple avec serveo
ssh -R 80:localhost:8080 serveo.net

VPS ve ters proxy

Profesyonel kullanım için, VPN üzerinden yerel altyapınıza yönlendiren bir reverse proxy ile bir VPS kullanımını düşünün.

Sorun giderme

Yaygın sorunlar

sorun Çözüm

Dışarıdan erişilemeyen hizmet

Port forwarding yapılandırmasını kontrol edin ve hizmetin 0.0.0.0 üzerinde dinlediğinden emin olun.

Bağlantı reddedildi

Servis başlatılmadı veya yalnızca 127.0.0.1 üzerinden dinleniyor

Bağlantı zaman aşımı

Güvenlik duvarı sorunu (kutu veya Ubuntu) veya yanlış yapılandırılmış port yönlendirmesi

Kamu IP adresi düzenli olarak değişir.

Dinamik bir DNS (DynDNS, No-IP, vb.) yapılandırın

Ağ hata ayıklama

# Tester la connectivité locale
telnet localhost 8080

# Tester depuis une autre machine du réseau
telnet 192.168.1.100 8080

# Vérifier les routes réseau
ip route show

# Analyser le trafic réseau
sudo tcpdump -i any port 8080

Sonuç

Yerel bir hizmeti İnternet üzerinden açmak, port yönlendirme, güvenlik ve izleme için dikkatli bir yapılandırma gerektirir. Bu yaklaşım, geliştirme veya kişisel projeler için mükemmeldir, ancak üretimde kullanım için daha sağlam seçenekler (VPS, CDN, bulut hizmetleri) hakkında düşünmelisiniz.

Önemli olan, her zaman güvenliği akla tutmaktır: güçlü şifreler kullanın, sisteminizi düzenli olarak güncelleyin ve açığa çıkan hizmetlerinizin erişimlerini izleyin.
