Hedef kitle: Gradle eklenti geliştirmeye başlamak isteyen geliştiriciler

Giriş

Gradle eklentileri etkili bir şekilde geliştirmek için iyi yapılandırılmış bir geliştirme ortamı gereklidir. Bir iyi kurulum, zamanınızı kazandırır, öfkenizi azaltır ve derlemelerinizin tutarlılığını sağlar.

Bu kılavuz, dört temel sütunu odaklar :

  1. Le JDK(Java Development Kit), çünkü Gradle ve JBake JVM’de çalışırlar.

  2. Un IDEmodern Kotlin ve Gradle için iyi destekli (IntelliJ IDEA).

  3. GradleKendi, projeleri başlatmak için.

  4. JBake, statik sitemizin motoru.

Geliştirme ortamı bileşenleri
@startuml
!theme plain
node "Geliştirici makinesi" {
  component "JDK (JVM)" as JDK
  component "IntelliJ IDEA" as IDE
  component "Gradle (küresel)" as Gradle
  component "JBake (küresel)" as JBake

  IDE --> JDK : utilise
  Gradle --> JDK : utilise
  JBake --> JDK : utilise
}
@enduml

1. JDK: Gradle’in motoru

Gradle, Java sanal makinesi (JVM) üzerinde çalışan bir uygulamadır. Bu nedenle, bir JDK kurulumu mutlak bir gerekliliktir.

Hangi sürümü seçmeliyim?

Java’nın LTS (Uzun Vadeli Destek) sürümünü kullanmanız önerilir. Şu anda,JDK 17 ou JDK 21Harika seçeneklerdir.

Installation via SDKMAN! (Önerilen)

SDKMAN!, Java ve Gradle dahil birçok SDK’nın sürümlerini yönetmek için harika bir araçtır.

SDKMAN! kurun

curl -s "https://get.sdkman.io" | bash source "$HOME/.sdkman/bin/sdkman-init.sh"

JDK’nın bir sürümünü kurmak

# Pour lister les versions de Java disponibles sdk list java

# Pour installer Java 17 (par exemple, la distribution Temurin)
sdk install java 17.0.8-tem

Kurulumu kontrol et

java -version

Yüklediğiniz sürümü görmeniz gerekiyor

2. IDE: IntelliJ IDEA

Kotlin DSL ile Gradle eklenti geliştirme için,IntelliJ IDEAseçilen araçtır Gradle ve Kotlin ile entegrasyonu eşsizdir.

  • Topluluk Sürümü :Ücretsiz ve başlangıç için yeterince fazla

  • Nihai Sürüm :Ücretli, web ve veritabanı geliştirme için gelişmiş işlevler sunar.

Sizin için uygun sürümü JetBrains sitesinden indirin: https://www.jetbrains.com/idea/download/

IDE dosyalarınızı otomatik olarak algılayacaktır`build.gradle.kts` et settings.gradle.kts, sizin için güçlü bir otomatik tamamlama, kod içinde gezinme ve entegre hata ayıklama araçları sunuyor.

3. Gradle: Derleme aracı

Ancak her proje Gradle Wrapper üzerinden kendi Gradle sürümünü kullanacaksa da, yeni projeleri başlatmak gibi görevler için Global Gradle kurulumuna sahip olmak faydalı (gradle init).

SDKMAN! üzerinden kurulum

JDK gibi, SDKMAN! Gradle’ın kurulumunu basitleştirir.

Gradle’ı kur

sdk install gradle

Kurulumu kontrol et

gradle -v

Bu komut Gradle, Kotlin, Groovy ve JDK sürümlerini görüntüleyecektir.

4. JBake : Statik site oluşturucu

JBake, kaynak dosyalarımızı (bu gibi) statik bir web sitesine dönüştürmek için kullanacağımız aractır. Yerel bir kurulum, değişiklikleri önizlemek için pratiktir.

SDKMAN! üzerinden kurulum

Diğer araçlar gibi, SDKMAN! en basit yöntemdir.

JBake’i kur

sdk install jbake

Kurulumu kontrol et

jbake -v

Bu komut, JBake sürümünü ve kullandığı Java ortamı bilgilerini görüntüleyecektir.

5. Gradle Wrapper: Mutlak iyi uygulama

Projenizi oluşturduktan sonra (bunu sonraki makalede göreceğiz), global komutu artık kullanmamalısınız.gradle. Onun yerine onu kullanacaksınızGradle Wrapper(./gradlew), projenize dahil edilmiş bir komut dosyası.

Neden?

  • yeniden üretilebilirlik:Wrapper, proje üzerinde çalışan herkesin (CI/CD sunucunuz dahil) tam olarak kullanmasını garantiler.Gradle’in aynı sürümü, böylece farklı ortamlardan kaynaklanan derleme hatalarını ortadan kaldırıyor.

  • Basitlik :Projeye katkıda bulunmak için Gradle’i manuel olarak kurmanıza gerek yok.

Depoyu klonlamak ve çalıştırmak yeterlidir../gradlew.

Tipik bir komut buna benzeyecek:

# Ne pas faire : gradle build
# À faire :
./gradlew build

6. Docker ve Portainer : Tekrarlanabilir Oluşumlar İçin (İsteğe Bağlı)

Bir eklenti yazmak için kesin olarak gerekli olmasa da, Docker ve Portainer modern DevOps araçlardır ve yeniden üretilebilir derlemelerin oluşturulmasını ve ortamınızın yönetimini büyük ölçüde kolaylaştırırlar.

Docker Engine kurulumu

Docker, uygulamanızı ve bağımlılıklarını bir konteyner içinde paketlemenizi sağlar.

Docker’ı resmi komut dosyasıyla kurun :

curl -fsSL https://get.docker.com -o get-docker.sh sudo sh get-docker.sh

Docker’ı sudo kullanmadan yönetin (önerilen) :

Kullanıcınızı gruba ekleyin`docker`.

sudo usod -aG docker $USER
docker run hello-world

Portainer (GUI) ile Docker’ı yönet

Portainer, Docker konteynerlerinizi yönetmek için hafif bir web arayüzüdür.

Portainer verileri için bir birim oluşturun:

docker volume create portainer_data

Portainer konteynerini başlat :

docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:latest

Portainer arayüzünde şimdi erişebilirsiniz`https://localhost:9443`.

Sonuç

Ortamınız şimdi hazır! Bir JDK, en uygun IDE, Gradle ve JBake’ye sahipsiniz. Docker eklendiğinde, konteynerleştirilmiş ve tekrarlanabilir derlemeler oluşturmak için de hazırsınız. Bu sağlam temel, önemli olan şeye odaklanmanızı sağlayacak: güçlü ve kullanışlı eklentilerin geliştirilmesi.

Bir sonraki makalede, komutu kullanacağız.`gradle init`İlk eklenti projemizin yapısını oluşturmak için.
