Εγκατάσταση του Pandoc

Publié le 30 January 2024

Χρόνος ανάγνωσης : 3 min Το Pandoc, ένας παγκόσμιος μετατροπέας εγγράφων

Το Pandoc είναι ένα λογισμικό επεξεργασίας κειμένου ανοικτού κώδικα που μπορεί να χρησιμοποιηθεί για τη μετατροπή εγγράφων μεταξύ διαφορετικών μορφών. Υπάρχουν διάφοροι τρόποι για την εγκατάσταση του Pandoc.

Εγκατάσταση από τη σελίδα λήψης

Για να εγκαταστήσετε το Pandoc από τη σελίδα λήψης, ακολουθήστε τα παρακάτω βήματα:

  1. Μεταβείτε στη σελίδα λήψης του Pandoc :https://pandoc.org/installing.html/[https://pandoc.org/installing.html]

  2. Κατεβάστε το πρόγραμμα εγκατάστασης του πακέτου για το σύστημα λειτουργικού σας.

  3. Εκτελέστε το πρόγραμμα εγκατάστασης για να εγκαταστήσετε το Pandoc.

Εγκατάσταση από ένα αρχείο zip

Για να εγκαταστήσετε το Pandoc από ένα αρχείο zip, ακολουθήστε τα ακόλουθα βήματα:

  1. Κατεβάστε το αρχείο zip που περιέχει τα δυαδικά του Pandoc και την τεκμηρίωση.

  2. Αποσυμπιέστε το αρχείο zip.

  3. Μετακινήστε τα δυαδικά σε έναν κατάλογο που επιλέγετε.

Εγκατάσταση με τη χρήση Chocolatey

Για να εγκαταστήσετε το Pandoc με τη χρήση του Chocolatey, ακολουθήστε τα παρακάτω βήματα :

  1. �Άνοιξτε μια εντολή εντολών.

  2. Εκτελέστε την ακόλουθη εντολή:

choco install pandoc

Εγκατάσταση με το winget

Για να εγκαταστήσετε το Pandoc με τη χρήση του winget, ακολουθήστε τα παρακάτω βήματα :

  1. Άνοιξτε ένα προMPT εντολών.

  2. Εκτελέστε την ακόλουθη εντολή :

winget install --source winget --exact --id JohnMacFarlane.Pandoc

Συστάσεις

Προεπιλεγμένα, το Pandoc δημιουργεί PDFs με τη βοήθεια του LaTeX. Συστήνεται να εγκαταστήσετε το LaTeX μέσω MiKTeX. Με την επιλογή`--pdf-engine`, Μπορείτε να καθορίσετε επίσης άλλα προγράμματα για αυτή την εργασία.

Προειδοποίηση

Η χρήση πολλών μέθοδων εγκατάστασης μπορεί να προκαλέσει δύο ξεχωριστές εγκαταστάσεις του Pandoc. Προτείνεται να αφαιρέσετε σωστά το Pandoc πριν μεταβείτε σε εναλλακτική μέθοδο εγκατάστασης.

Εγκατάσταση σε Linux μέσω WSL

Ελέγξτε αν η έκδοση του pandoc στο διαχειριστή πακέτων σας δεν είναι παλιά. Το Pandoc βρίσκεται στους αποθετήρια των Debian, Ubuntu, Slackware, Arch, Fedora, NixOS, openSUSE, gentoo και Void.

Για να αποκτήσετε την τελευταία έκδοση, προτείνουμε ένα δυαδικό πακέτο για την αρχιτεκτονική amd64 στη σελίδα λήψης.

Το εκτελέσιμο είναι συνδεδεμένο στατικά και δεν έχει δυναμικές εξαρτήσεις, μηδε εξαρτήσεις σε εξωτερικά αρχεία δεδομένων. Σημείωση: λόγω του στατικού συνδέσμου, το δυαδικό pandoc αυτού του πακέτου δεν μπορεί να χρησιμοποιήσει τα φίλτρα lua που απαιτούν εξωτερικά modules lua γραμμένα σε C.

Παρέχεται ένα tarball και ένα πακέτο .deb. Για να εγκαταστήσετε το deb :

sudo dpkg -i $DEB

Παράδειγμα κατά την εγγραφή :

wget https://github.com/jgm/pandoc/releases/download/3.1.11.1/pandoc-3.1.11.1-1-amd64.deb
sudo dpkg -i pandoc-3.1.11.1-1-amd64.deb

où `$DEB`είναι η διαδρομή προς το deb που έχει κατεβαστεί Αυτό θα εγκαταστήσει το εκτελέσιμο`pandoc`και η σελίδα του εγχειριδίου

Αν χρησιμοποιείτε μια διανομή βασισμένη σε RPM, μπορεί να μπορέσετε να εγκαταστήσετε το deb από τη σελίδα λήψης μας με τη βοήθεια του alien.

Σε οποιαδήποτε διανομή, μπορείτε να εγκαταστήσετε από το tarball στο`$DEST`(π.χ.,/usr/local/ ou $HOME/.local) ενώ κάνετε :

tar xvzf $TGZ --strip-components 1 -C $DEST

où `$TGZ`είναι η διαδρομή προς το συμπιεσμένο tarball που έγινε λήψη. Για τις εκδόσεις του Pandoc παλαιότερες από την έκδοση 2.0, που δεν παρέχουν tarball, δοκιμάστε αντίθετα:

ar p $DEB data.tar.gz | tar xvz --strip-components 2 -C $DEST

Μπορείτε επίσης να εγκαταστήσετε από τον πηγαίο κώδικα, χρησιμοποιώντας τις οδηγίες που παρακάτω υπό`Compilation à partir de la source`. Οι περισσότερες διανομές έχουν την πλατφόρμα Haskell στα αποθετήρια πακέτων τους. Για παράδειγμα, στο Debian/Ubuntu, μπορείτε να το εγκαταστήσετε με

apt-get install haskell-platform

Προεπιλογικά, το Pandoc δημιουργεί PDFs χρησιμοποιώντας το LaTeX. Σας συνιστάμε να εγκαταστήσετε το TeX Live μέσω του διαχειριστή πακέτων σας. (Στον Debian/Ubuntu,apt-get install texlive). Με την επιλογή`--pdf-engine`, Μπορείτε όμως να καθορίσετε άλλα προγράμματα για αυτή την εργασία.
