Εισαγωγή

Google Apps Script (GAS) είναι μια πλατφόρμα ανάπτυξης σεναρίων που σχετίζεται με διάφορα υπηρεσίες Google όπως τα Google Sheets, τα Google Docs και τα Google Forms. Επιτρέπει την αυτοματοποίηση εργασιών, την προσθήκη προσαρμοσμένων λειτουργιών και την ενσωμάτωση υπηρεσιών Google.

Σε αυτή τη σημείωση, θα εξετάσουμε τις κύριες έννοιες του Google Apps Script βασισμένοι σε πρακτικά παραδείγματα. Θα ασχοληθούμε με έννοιες όπως οι μεταβλητές, οι βρόχοι, οι λειτουργίες και πολλά άλλα, προσαρμόζοντας τα στο συγκεκριμένο πλαίσιο του GAS.

Βασική δομή στην Google Apps Script

Για να ξεκινήσουμε, ας εξετάσουμε τη βασική δομή μιας δέσμης ενεργειών Google Apps.

/**
 * Structure de base en Google Apps Script
 */
function exempleStructureGAS() {
    // Votre code ici
    Logger.log("Hello, Google Apps Script!");
}

Τύποι και Μεταβλητές στο Google Apps Script

Η Google Apps Script χρησιμοποιεί τη JavaScript ως γλώσσα προγραμματισμού. Οι τύποι δεδομένων και οι μεταβλητές λειτουργούν παρόμοια με την τυπική JavaScript.

/**
 * Types et Variables en Google Apps Script
 */
function exempleTypesVariablesGAS() {
    // Votre code ici
    var nombre = 42;
    var texte = "Bonjour, Google Apps Script!";
    Logger.log(nombre);
    Logger.log(texte);
}

Λειτουργίες και τελεστές στο Google Apps Script

Οι λειτουργίες και οι τελεστές στο Google Apps Script είναι οι ίδιοι με την JavaScript.

/**
 * Opérations et Opérateurs en Google Apps Script
 */
function exempleOperationsGAS() {
    // Votre code ici
    var x = 10;
    var y = 5;
    var resultat = x + y;
    Logger.log(resultat);
}

Var, Let και Const στο Google Apps Script

Στον GAS, οι έννοιες του`var`, let, et `const`χρησιμοποιούνται για τη δήλωση μεταβλητών. Ω</tool_call>, είναι ζωτικό να κατανοήσουμε τις διαφορές τους και τις επιπτώσεις τους.

/**
 * Var, Let et Const en Google Apps Script
 */
function exempleVarLetConstGAS() {
    // Votre code ici
    // Utilisation de var
    var x = 10;
    if (true) {
        var x = 20; // La variable x est modifiée globalement
    }
    Logger.log(x);

    // Utilisation de let
    let y = 30;
    if (true) {
        let y = 40; // La variable y est limitée au bloc if
    }
    Logger.log(y);

    // Utilisation de const
    const z = 50;
    // z = 60; // Impossible de réassigner une constante
    Logger.log(z);
}

Δομές ελέγχου στο Google Apps Script

Οι δομές έλεγχου όπως`if`, else, while et `for`utilizarόνται για τη διαχείριση της ροής εκτέλεσης στο Google Apps Script.

/**
 * Structures de Contrôle en Google Apps Script
 */
function exempleStructuresControleGAS() {
    // Votre code ici
    var condition = true;

    if (condition) {
        Logger.log("La condition est vraie.");
    } else {
        Logger.log("La condition est fausse.");
    }

    var compteur = 0;
    while (compteur < 5) {
        Logger.log(compteur);
        compteur++;
    }

    for (var i = 0; i < 3; i++) {
        Logger.log(i);
    }
}

Παραμέτροι και Έμβατα στο Google Apps Script

Οι παραμέτροι και οι εμβέλειες παίζουν κρίσιμο ρόλο στην ανάπτυξη σεναρίων σε GAS. Κατανόηση πώς λειτουργούν για να αποφύγετε απρόσμενα συμπεριφορές.

/**
 * Paramètres et Scopes en Google Apps Script
 */
function exempleParametresScopesGAS(parametre) {
    // Votre code ici
    var variableGlobale = "Je suis global";

    function afficherParametre() {
        Logger.log(parametre);
    }

    afficherParametre();
    Logger.log(variableGlobale);
}

Σταθερές, μεταβλητές και γράμματα σε Google Apps Script

Κατανόηση της διαφοράς μεταξύ`const`, var, et `let`Είναι ζωτικό για την αποτελεσματική χρήση των μεταβλητών στο Google Apps Script.

/**
 * Constantes, Variables, et Lettres en Google Apps Script
 */
function exempleConstantesVariablesLettresGAS() {
    // Votre code ici
    const constante = "Je ne change pas";
    Logger.log(constante);

    var variable = "Je peux changer";
    Logger.log(variable);

    let lettre = "Je peux aussi changer, mais seulement dans mon bloc";
    Logger.log(lettre);
}

Βρόχοι στο Google Apps Script

Οι βρόχοι, όπως`for` et while, είναι απαραίτητα για να επαναλάβουμε τα στοιχεία και να εκτελούμε επαναλαμβανόμενες λειτουργίες.

/**
 * Boucles en Google Apps Script
 */
function exempleBouclesGAS() {
    // Votre code ici
    for (var i = 0; i < 3; i++) {
        Logger.log(i);
    }

    var condition = true;
    var compteur = 0;

    while (condition) {
        Logger.log("Tour de boucle");
        compteur++;
        if (compteur === 3) {
            condition = false;
        }
    }
}

Αντικείμενα στο Google Apps Script

Τα αντικείμενα χρησιμοποιούνται για την οργάνωση των δεδομένων. Στην GAS, πολλά ενσωματωμένα αντικείμενα διευκολύνουν την αλληλεπίδραση με τις υπηρεσίες του Google.

/**
 * Objets en Google Apps Script
 */
function exempleObjetsGAS() {
    // Votre code ici
    var feuille = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var cellule = feuille.getRange("A1");
    cellule.setValue("Nouvelle valeur");
}

Σταθερές, Μεταβλητές, και Γράμματα στο Google Apps Script

Κατανόηση της διαφοράς μεταξύ`const`, var, et `let`Είναι απαραίτητο για μια αποτελεσματική χρήση των μεταβλητών στον Google Apps Script.

/**
 * Constantes, Variables, et Lettres en Google Apps Script
 */
function exempleConstantesVariablesLettresGAS() {
    // Votre code ici
    const constante = "Je ne change pas";
    Logger.log(constante);

    var variable = "Je peux changer";
    Logger.log(variable);

    let lettre = "Je peux aussi changer, mais seulement dans mon bloc";
    Logger.log(lettre);
}

Συναρτήσεις στο Google Apps Script

Οι συναρτήσεις είναι βασικά στοιχεία στον προγραμματισμό. Στο GAS, μπορούν να δηλώνουν και να καλούνται με διάφορους τρόπους.

/**
 * Fonctions en Google Apps Script
 */
function exempleFonctionsGAS() {
    // Votre code ici
    function additionner(a, b) {
        return a + b;
    }

    var resultat = additionner(2, 3);
    Logger.log(resultat);

    // Fonction anonyme
    var multiplier = function (x, y) {
        return x * y;
    };

    Logger.log(multiplier(4, 5));
}

Τελεστές αναπαύσεως και διαδοχής σε Google Apps Script

Οι τελεστές αναμονής (…​) και διαδοχής (…​) είναι χρήσιμα για να χειρίζονται τους πίνακες και τα αντικείμενα συνοπτικά.

/**
 * Opérateurs de Repos et de Propagation en Google Apps Script
 */
function exempleOperateursReposPropagationGAS() {
    // Votre code ici
    // Opérateur de repos (...) pour les tableaux
    var nombres = [1, 2, 3, 4, 5];
    var [...copieNombres] = nombres;
    Logger.log(copieNombres);

    // Opérateur de propagation (...) pour les objets
    var objOriginal = { x: 1, y: 2 };
    var objClone = { ...objOriginal, z: 3 };
    Logger.log(objClone);
}

Ανάθεση με Ανάλυση σε Google Apps Script

Η ανάθεση διασποράς είναι μια ισχυρή λειτουργία που επιτρέπει την εξαγωγή τιμών από αντικείμενα και πίνακες με συνοπτικό τρόπο.

/**
 * Affectation par Décomposition en Google Apps Script
 */
function exempleAffectationDecompositionGAS() {
    // Votre code ici
    var coordonnees = [3, 4];
    var [x, y] = coordonnees;
    Logger.log(x);
    Logger.log(y);

    var utilisateur = { nom: "John", age: 30 };
    var { nom, age } = utilisateur;
    Logger.log(nom);
    Logger.log(age);
}

Συλλογές και Δηλωτικός προγραμματισμός στην Google Apps Script

Η Google Apps Script υποστηρίζει δομές δεδομένων όπως οι πίνακες, και τις έννοιες του λειτουργικού προγραμματισμού και της δηλωτικής επανάληψης (><ιμπερατική), όπως`map`, reduce et forEach.

/**
 * Collections et Programmation Déclarative en Google Apps Script
 */
function exempleCollectionsFonctionnelleGAS() {
    // Votre code ici
    // Exemple de tableau (collection)
    var nombres = [1, 2, 3, 4, 5];

    // Utilisation de forEach
    nombres.forEach(function (nombre) {
        Logger.log(nombre);
    });

    // Utilisation de map
    var carresNombres = nombres.map(function (nombre) {
        return nombre * nombre;
    });
    Logger.log(carresNombres);

    // Utilisation de reduce
    var somme = nombres.reduce(function (acc, nombre) {
        return acc + nombre;
    }, 0);
    Logger.log(somme);
}
