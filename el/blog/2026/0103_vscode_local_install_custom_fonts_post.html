Το Γιατί: VS Code στο Home

Το πρόβλημα με την εγκατάσταση του συστήματος

VS Code εγκατεστημένο μέσω`apt`, dnf`ή σε/opt`Κλείδώνει τα αρχεία της εφαρμογής πίσω από τα δικαιώματα root. Οποιαδήποτε αλλαγή του εγγενούς CSS, του`product.json`ή του φακέλου εγκατάστασης απαιτεί`sudo`.

Αλλά, όταν κάποιος χρησιμοποιείopencode(tool CLI για να χειριστούμε ένα LLM στον κώδικά του), ο agent χρειάζεται να μπορεί να:

  • Γράψτε στα αρχεία ρύθμισης`~/.config/Code/User/settings.json`) — Το, είναι ήδη στο σπίτι

  • Τροποποιήστε τα assets του IDE (CSS του workbench,product.json) για τις προχωρημένες παραμετροποίησης — αυτό είναι μπλοκαρισμένο χωρίς sudo

Η λύση: μια τοπική εγκατάσταση

Κατεβάζουμε την επίσημη tarball αρχειοθήκη και την αποσυμπιέζουμε άμεσα στο`~/apps/`:

mkdir -p ~/apps
cd ~/apps
wget "https://code.visualstudio.com/sha/download?build=stable&os=linux-x64" -O vscode.tar.gz
tar -xzf vscode.tar.gz
rm vscode.tar.gz

Το δυαδικό είναι τότε σε`~/apps/VSCode-linux-x64/bin/code`. Κανένας`sudo`Δεν είναι απαραίτητο για να διαβάσετε, να τροποποιήσετε ή να αντικαταστήσετε οποιοδήποτε αρχείο υπό`~/apps/VSCode-linux-x64/`.

Η παρατήρηση

Η προεπιλεγμένη γραμματοσειρά του κύριου μενού (File, Edit, View…​) και των dropdowns είναι πολύ μικρή. VS Code δεν προσφέρει καμία ρύθμιση για να την τροποποιήσει.

Διαγραφή της προειδοποίησης ακεραιότητας

VS Code αντιχνεύει τις αλλαγές των αρχείων του και εμφανίζει μια μπάρα ειδοποίησης "Your installation is corrupt". Για να το αποφύγουμε, αφαιρούμε τα checksums του`product.json`:

import json
product_json = "$HOME/apps/VSCode-linux-x64/resources/app/product.json"
with open(product_json, 'r') as f:
    data = json.load(f)
data.pop('checksums', None)
with open(product_json, 'w') as f:
    json.dump(data, f, indent=2)

Μετά την επανεκκίνηση, δεν υπάρχει πια προειδοποίηση και τα μενού είναι τελικά αναγνωστικά.

Προσαρμογή της γραμματοσειράς του παραθύρου Explorer — η μάχη

Προσπάθεια 1 : μια παράμετρος που δεν υπάρχει

Προσπαθούμε πρώτα το φυσικό παράμετρο`workbench.tree.fontSize`σε`settings.json` :

{
    "workbench.tree.fontSize": 20
}

Αποτέλεσμα :κανένα εφέ. Αυτή η ρύθμιση δεν υπάρχει στο VS Code. Η απόδειξη ότι τα μη αναγνωρισμένα ρυθμίσεις αγνοούνται σιωπηλά.

Προσπάθεια 2: η επέκταση Custom CSS and JS Loader

Εγκαθιστούμε την επέκταση`be5invis.vscode-custom-css` :

~/apps/VSCode-linux-x64/bin/code --install-extension be5invis.vscode-custom-css

Δημιουργούμε ένα αρχείο CSS στο`~/.vscode-custom-css/custom.css`με επιλογείς που στοχεύουν τα στοιχεία του εξερευνητή :

.monaco-tree-rows .monaco-tree-row,
.sidebar .monaco-list-row,
.explorer-viewlet .monaco-list-row,
.monaco-list-row .monaco-icon-label {
    font-size: 22px !important;
    line-height: 36px !important;
}

Και αναферόμαστε αυτό το αρχείο στις ρυθμίσεις :

{
    "vscode_custom_css.imports": [
        "file:///home/user/.vscode-custom-css/custom.css"
    ]
}

Αποτέλεσμα :Οι αλλαγές δεν εφαρμόζονται.

Ο παγίδα : πρέπει να ενεργοποιήσετε την επέκταση κάθε φορά

Η τεκμηρίωση της επέκτασης είναι διαקרítě σε αυτό το κρίσιμο σημείο: μετά από κάθε τροποποίηση του προσαρμοσμένου CSS, πρέπειυποχρεωτικάΕκτέλεση της εντολής από τη παλέτα :

  1. Ctrl+Shift+P→ πληκτρολογώΕνεργοποίηση Προσαρμοσμένου CSS και JS

  2. Το VS Code ζητά επανεκκίνηση → Αποδοχή

Χωρίς αυτό το βήμα, το CSS δεν ενσωματώνεται ποτέ στο IDE.

Προσπάθεια 3: οι γραμμές επικαλύπτονται

Ακόμη και με`font-size: 22px` et line-height: 36px, τα γράμματα με κάτω γραμμή (g, p, f, b) υπερβαίνουν στις γειτονικές γραμμές. Προσπαθεί να προσθέσει`height` et min-height:

.monaco-list-row {
    height: 36px !important;
    min-height: 36px !important;
}

Αποτέλεσμα :καμία αλλαγή. VS Code υπολογίζει τα ύψη των γραμμών σε JavaScript και αντικαθιστά τις τιμές CSS.

Αντί να αγωνιζόμαστε εναντίον του layout JavaScript, χρησιμοποιούμε την ιδιότητα`zoom`στο κονтеινέρ των γραμμών :

Το πρόβλημα

Όταν ο VS Code ενημερώνεται, αντικαθιστά τον φάκελο εγκατάστασης καιδιαγράψε όλα τα patches CSS. Πρέπει να εφαρμόσετε ξανά τις αλλαγές χειροκίνητα κάθε φορά.

Το script `vscode-update.sh

Δημιουργούμε`~/apps/vscode-update.sh` :

#!/bin/bash
set -e

VSCODE_DIR="$HOME/apps/VSCode-linux-x64"
BACKUP_DIR="$HOME/apps/vscode-backup"
TEMP_DIR="/tmp/vscode-update"

MENUBAR_FONT_SIZE="23px"
DROPDOWN_FONT_SIZE="22px"

echo "=== VS Code Local Updater ==="

CURRENT_VERSION=$("$VSCODE_DIR/bin/code" --version 2>/dev/null | head -1)
echo "Current version: $CURRENT_VERSION"

echo "Downloading latest VS Code..."
mkdir -p "$TEMP_DIR"
wget -q "https://code.visualstudio.com/sha/download?build=stable&os=linux-x64" \
    -O "$TEMP_DIR/vscode.tar.gz"

echo "Extracting..."
mkdir -p "$TEMP_DIR/extracted"
tar -xzf "$TEMP_DIR/vscode.tar.gz" -C "$TEMP_DIR/extracted"

NEW_VERSION=$("$TEMP_DIR/extracted/VSCode-linux-x64/bin/code" \
    --version 2>/dev/null | head -1)
echo "New version: $NEW_VERSION"

if [ "$CURRENT_VERSION" = "$NEW_VERSION" ]; then
    echo "Already up to date!"
    rm -rf "$TEMP_DIR"
    exit 0
fi

echo "Backing up current installation..."
mkdir -p "$BACKUP_DIR"
cp -r "$VSCODE_DIR" "$BACKUP_DIR/VSCode-linux-x64-$(date +%Y%m%d-%H%M%S)"

echo "Updating..."
rm -rf "$VSCODE_DIR"
mv "$TEMP_DIR/extracted/VSCode-linux-x64" "$VSCODE_DIR"
rm -rf "$TEMP_DIR"

CSS_FILE="$VSCODE_DIR/resources/app/out/vs/workbench/workbench.desktop.main.css"
echo "Re-applying custom CSS patch \
    (menubar=${MENUBAR_FONT_SIZE}, dropdown=${DROPDOWN_FONT_SIZE})..."
cat >> "$CSS_FILE" << CSSEOF
.menubar-menu-title{font-size:${MENUBAR_FONT_SIZE}!important}\
.menubar>.menubar-menu-button{font-size:${MENUBAR_FONT_SIZE}!important}\
.monaco-menu-option{font-size:${DROPDOWN_FONT_SIZE}!important;\
line-height:34px!important}\
.monaco-menu .action-label:not(.codicon)\
{font-size:${DROPDOWN_FONT_SIZE}!important}\
.menubar-menu-items-holder .monaco-menu .action-item .action-label\
{font-size:${DROPDOWN_FONT_SIZE}!important}
CSSEOF

PRODUCT_JSON="$VSCODE_DIR/resources/app/product.json"
if [ -f "$PRODUCT_JSON" ]; then
    echo "Removing checksums to prevent integrity warning..."
    python3 -c "
import json
with open('$PRODUCT_JSON','r') as f: data=json.load(f)
data.pop('checksums', None)
with open('$PRODUCT_JSON','w') as f: json.dump(data,f,indent=2)
print('Done.')
"
fi

echo "=== Update complete: $CURRENT_VERSION -> $NEW_VERSION ==="

Η εγκατάσταση στο home ελευθερώνει όλα

Μια τοπική εγκατάσταση σε`~/apps`δίνει πλήρη έλεγχο στον VS Code :

  • δεν`sudo`για να τροποποιήσετε το CSS ή τη διαμόρφωση

  • Ο πράκτορας opencode+LLM μπορεί να γράψει στα αρχεία ρυθμίσεων και τα assets του IDE

  • Απλό rollback: επαναφορά του backup horodaté

zoom` > font-size για τα στοιχεία list

Ο VS Code ελέγχει το ύψος των γραμμών μέσω JavaScript. Τροποποιήστε`font-size`Δεν μπορεί να αλλάξει το ύψος που έχει εκχωρηθεί από το μηχανισμό διάταξης, οδηγεί σε κείμενα που εκπέφτουν. Η ιδιότητα`zoom`στον γονικό κοντέινερ, μεγεθύνει όλο ανάλογα και αποφεύγει αυτό το πρόβλημα.

Η επέκταση Custom CSS απαιτεί ρητή ενεργοποίηση

Δεν είναι μια ρύθμιση "set and forget". Κάθε αλλαγή στο αρχείο CSS προσαρμοσμένο απαιτεί την επανεκτέλεση της "Enable Custom CSS and JS" από τη παλέτα εντολών (Ctrl+Shift+P).

Ενα script ενημέρωσης είναι απαραίτητο

Χωρίς το script, κάθε ενημέρωση του VS Code διαγράφει τα patches CSS του workbench. Το script`vscode-update.sh`αυτοματοποιεί τη λήψη, την αντικατάσταση, το re-patch και το καθαρισμό των checksums.
