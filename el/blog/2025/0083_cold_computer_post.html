Αισθανθείτε ότι το laptop σας ζεσταίνεται ακανόνιστως στο Ubuntu; Αυτό το άρθρο σας προτείνει μια διαδικασίαλογισμικόολοκληρωμένη γιαψύχω, παρακολουθώ et να ελέγξετε τη θερμοκρασίατου υπολογιστή σας.

Σκοπός αυτού του οδηγού

  • Μειώστε την συνολική θερμοκρασία του υπολογιστή

  • Βελτιστοποίηση της διαχείρισης ενέργειας

  • Παρακολουθήστε τα critica συστατικά (CPU, GPU, κ.λπ.)

  • Να αποφεύγετε τις καθυστερήσεις λόγω τουθερμικό περιορισμός

προϋποθέσεις

  • Μια μηχανή Ubuntu (20.04 ή νεότερη προτεινόμενη)

  • Σύνδεση Διαδικτύου

  • Δεξιότητα εντολών γραμμής εντολών (επίπεδο αρχάριος έως μέτριος)

Εγκατάσταση και ρύθμιση των εργαλείων

lm-sensors` για να ανιχνεύσει τους αισθητήρες

sudo apt install lm-sensors
sudo sensors-detect
sensors

Απαντήστε`YES`σε όλες τις ερωτήσεις του`sensors-detect`για να ανιχνεύσει τα modules.

tlp` : έξυπνος διαχειριστής ενέργειας

sudo apt install tlp tlp-rdw
sudo systemctl enable tlp
sudo systemctl start tlp

cpufrequtils` : περιορίζει τις συχνότητες CPU

sudo apt install cpufrequtils
cpufreq-info
sudo cpufreq-set -g powersave

  • powersave: περιορίζει τα πικ της συχνότητας

  • `performance`προτιμάει την ισχύ σε βάρος της θερμοκρασίας

auto-cpufreq` : απλοποιημένη δυναμική διαχείριση

git clone https://github.com/AdnanHodzic/auto-cpufreq.git
cd auto-cpufreq
sudo ./auto-cpufreq-installer
sudo auto-cpufreq --install

thermald` : αυτόματη θερμική προστασία

sudo apt install thermald
sudo systemctl enable thermald
sudo systemctl start thermald

Παρακολούθηση σε πραγματικό χρόνο

sensors` σε τη γραμμή εντολών

watch -n 2 sensors

Επιλογή GUI : `psensor

sudo apt install psensor

Απλή γραφική διεπαφή για CPU, GPU, ανεμιστήρες.

  • Αποφύγετε τις έντονες χρήσεις σε μπαταρία

Καθαρίστε το σύστημα για να περιορίσετε τις υπερφορτώσεις

sudo apt autoremove

Για να πάτε περαιτέρω

Μπορείτε να δημιουργήσετε μια υπηρεσία`systemd`προσαρμοσμένο για την αυτόματη εφαρμογή ορισμένων ρυθμίσεων κατά την εκκίνηση �Θέλετε ένα παράδειγμα σε ένα μελλοντικό άρθρο; Να μου το πείτε!

Συμπέρασμα

Συνδυάζοντας αυτά τα απλά εργαλεία, θα κερδίσετε :

  • Έλεγχος θερμοκρασίας CPU

  • Λίγος θόρυβος από την αναπνευστική

  • Μια καλύτερη autonomía

Μην ξεχάσετε να παρακολουθείτε τις θερμοκρασίες σας τακτικά για να αποτρέψετε κάθε υπερθέρμανση.

_ Καλύτερα είναι να πρόληψεις παρά να τupanείς την CPU σου. _
