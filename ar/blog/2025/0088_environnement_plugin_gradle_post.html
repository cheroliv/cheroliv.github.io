مقدمة

الجمهور المستهدف : مطورين يرغبون في البدء في إنشاء مكونات Gradle.

لتطوير إضافات Gradle بكفاءة، بيئة تطوير مُهيأة جيدًا ضرورية. سيوفر لك الإعداد الجيد وقتًا، ويقلل من الإحباطات، ويضمن اتساق بنياتك.

يركز هذا الدليل على أربعة أعمدة أساسية :

  1. Le JDK(مجموعة تطوير جافا)، لأن Gradle وJBake يعملان على JVM.

  2. Un بيئة تطوير متكاملةmoderne (IntelliJ IDEA) مع دعم جيد لكوتلين وغردل.

  3. Gradleنفسه، لبدء المشاريع.

  4. JBake, محرك موقعنا الثابت

Figure 1. مكونات بيئة التطوير

JDK: محرك Gradle

Gradle هو تطبيق يعمل على الجهاز الظاهري لجافا (JVM). وبالتالي، فإن تثبيت JDK هو متطلب أساسي مطلق.

ما الإصدار الذي يجب اختياره؟

</think>ما الإصدار الذي يجب اختياره؟

يُوصى باستخدام نسخة LTS (دعم طويل الأمد) من Java. في الوقت الحالي,JDK 17 ou JDK 21هي خيارات ممتازة

التثبيت عبر SDKMAN! (مُوصى به)

SDKMAN! هو أداة رائعة لإدارة إصدارات许多 الـSDK، بما في ذلك Java وGradle.

تثبيت SDKMAN!

curl -s "https://get.sdkman.io" | bash source "$HOME/.sdkman/bin/sdkman-init.sh"

ثبت نسخة من JDK

# Pour lister les versions de Java disponibles sdk list java

# Pour installer Java 17 (par exemple, la distribution Temurin)
sdk install java 17.0.8-tem

تحقق من التثبيت

java -version

يجب أن ترى النسخة التي قمت لتثبيتها للتو تظهر.

2. بيئة التطوير المتكاملة : IntelliJ IDEA

لتطوير المكونات الإضافية لـ Gradle باستخدام DSL Kotlin,IntelliJ IDEAهو الأداة المفضلة. تكامله مع Gradle و Kotlin لا يضاهى

  • النسخة المجتمعية :مجانية وكافية بشكل كبير للبدء

  • النسخة المطلقة :مدفوعة، فهي تقدم ميزات متقدمة لتطوير الويب وقواعد البيانات.

حمل النسخة التي تناسبك من موقع JetBrains : https://www.jetbrains.com/idea/download/

سيكتشف IDE تلقائيًا ملفاتك`build.gradle.kts` et settings.gradle.kts, يقدم لك إكمالًا تلقائيًا قويًا، التنقل في الكود وأدوات تصحيح الأخطاء المدمجة.

3. Gradle : أداة البناء

على الرغم من أن كل مشروع سيستخدم نسخته الخاصة من Gradle عبر Gradle Wrapper، إلا أنه من المفيد وجود تثبيت عالمي لـ Gradle للمهام مثل تهيئة مشاريع جديدة (gradle init).

التثبيت عبر SDKMAN!

تمامًا مثل JDK، SDKMAN! يُسهّل تثبيت Gradle.

تثبيت Gradle

sdk install gradle

التحقق من التثبيت

gradle -v

ستعرض هذا الأمر إصدارات Gradle و Kotlin و Groovy و JDK المستخدمة.

4. JBake : مولّد الموقع الثابت

JBake هي الأداة التي سنستخدمها لتحويل ملفات المصدر لدينا (مثل هذا) إلى موقع ويب ثابت. الحصول على تثبيت محلي مفيد لمعاينة التغييرات.

التثبيت عبر SDKMAN!

كما هو الحال مع الأدوات الأخرى، فإن SDKMAN! هي أبسط طريقة.

تثبيت JBake

sdk install jbake

التحقق من التثبيت

jbake -v

سيعرض هذا الأمر إصدار JBake ومعلومات بيئة Java التي يستخدمها.

5. غلاف Gradle: الممارسة المطلقة الجيدة

بمجرد إنشاء مشروعك (الذي سنراه في المقال التالي)، لم تعد بحاجة إلى استخدام الأمر العالمي`gradle`. بدلاً من ذلك، ستستخدم الغلاف Gradle(./gradlew), سكريبت مضمّن في مشروعك.

لماذا؟

  • قابلية التكرار :يضمن الغلاف أن كل شخص يعمل على المشروع (بما في ذلك خادم CI/CD الخاص بك) يستخدم بالضبطنفس نسخة Gradle, مما يؤدي إلى إزالة أخطاء البناء بسبب بيئات مختلفة

  • البساطة :لا تحتاج إلى تثبيت Gradle يدويًا للمساهمة في مشروع

كل ما عليك فعله هو استنساخ المستودع وتشغيله`./gradlew`.

سيبدو أمر نموذجي كالتالي :

# Ne pas faire : gradle build
# À faire :
./gradlew build

6. دوكير وبورتينير : للبنّاءات القابلة للتكرار (اختياري)

على الرغم من عدم كونها ضروريةً بشكل صارم لكتابة إضافة، فإن Docker وPortainer هما أدوات DevOps الحديثة التي تسهّل كثيرًا إنشاء بنى قابلة للتكرار وإدارة بيئتك.

تثبيت Docker Engine

يسمح لك Docker بحزم تطبيقك والاعتماديات في حاوية.

تثبيت Docker عبر البرنامج النصي الرسمي :

curl -fsSL https://get.docker.com -o get-docker.sh sudo sh get-docker.sh

إدارة Docker دون sudo (مُستحسَن) :

أضف مستخدمك إلى المجموعة`docker`.

sudo usod -aG docker $USER
docker run hello-world

إدارة Docker مع Portainer (واجهة المستخدم الرسومية)

Portainer هي واجهة ويب خفيفة لإدارة حاويات Docker الخاصة بك.

إنشاء حجم لبيانات Portainer:

docker volume create portainer_data

تشغيل حاوية Portainer :

docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:latest

يمكنك الآن الوصول إلى واجهة Portainer على`https://localhost:9443`.

الخاتمة

بيئتك الآن جاهزة! لديك JDK، وأفضل بيئة تطوير متكاملة (IDE)، وGradle، وJBake. مع إضافة Docker، أنت أيضًا جاهز لإنشاء بنّاءات حاوية قابلة للتكرار. ستسمح لك هذه القاعدة الصلبة بالتركيز على الجوهر: تطوير إضافات قوية ومفيدة.

في المقالة القادمة، سنستخدم الأمر`gradle init`لتوليد هيكل مشروع الإضافة الأول لدينا
