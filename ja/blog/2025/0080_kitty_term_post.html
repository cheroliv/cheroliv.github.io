このガイドは、Xubuntu 上でターミナル kitty をインストールする方法、正しく設定する方法、そしてデフォルトシェルとして bash を zsh に置き換える方法をステップバイステップで説明します。 kitty プロジェクトはこちらから利用できます: https://github.com/kovidgoyal/kitty.

_ Kittyは、要求の厳しい開発者に特に適した、モダンで高速かつ設定可能なターミナルです。 _

Kitty と Zsh を選ぶ理由は？

Kittyは次の点で特徴があります：

  • GPUアクセラレーションによる高いパフォーマンス,

  • 1つのテキストファイルに完全に基づく設定,

  • フォントとリガチャの優れたサポートです。

Zshはそれに対して、強力なインタラクティブなシェルを提供します：

  • インテリジェントな補完、

  • カスタマイズ可能なプロンプト,

  • bashとの高い互換性

Kitty と Zsh を組み合わせることで、生産的で美的な環境を得られます。

@startuml
title シンプルなアーキテクチャ Kitty + Zsh
actor User

User --> Kitty : Lance le terminal
Kitty --> Zsh : Initialise le shell interactif
Zsh --> System : Interagit avec le système (fichiers, commandes)
@enduml

このガイドは意図的にスクリプトによるインストールとXubuntuに限定されています。

システムの前提条件

始める前に、必要なものを確認してください：

  • Xubuntu インストール済み

  • インターネットへのアクセス,

  • スクリプトを起動するための機能的なbashシェル。

環境を確認してください：

uname -a
lsb_release -a

Kittyのダウンロードとインストール

Kittyは公式スクリプトを使ってインストールすることを推奨し、そのスクリプトはファイルを配置します。~/.local/kitty.app。

この方法はパッケージマネージャに依存しない（なしの`apt`).

インストールスクリプトをダウンロード

次のコマンドを実行してください：

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

このコマンドは実行します：

  • バイナリのダウンロード,

  • 抽出 中に`~/.local/kitty.app`,

  • シンボリックリンクの作成。

@startuml
title Kittyのダウンロードとインストール
start
:curl -L installer.sh;
:sh /dev/stdin;
:Décompression dans ~/.local/kitty.app;
:create symlinks;
stop
@enduml

シンボリックリンクの作成

呼び出すことができるように`kitty`ターミナルから、シンボリックリンクを作成してください：

ln -s ~/.local/kitty.app/bin/kitty ~/.local/bin/kitty

追加してください`~/.local/bin`まだPATHに追加していない場合は :

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

インストールを確認できます：

kitty --version

XubuntuへのKittyの統合

Kitty がアプリケーションメニューに表示されるように：

デスクトップのファイルをコピー

ファイルをコピーしてください`.desktop`提供 :

cp ~/.local/kitty.app/share/applications/kitty.desktop ~/.local/share/applications/

デスクトップファイルを編集する

ファイルを編集してください：

nano ~/.local/share/applications/kitty.desktop

次の行を確認または編集してください：

[Desktop Entry]
Version=1.0
Type=Application
Name=Kitty Terminal
Comment=Fast GPU-based terminal emulator
Exec=/home/$USER/.local/kitty.app/bin/kitty
Icon=kitty
Categories=System;TerminalEmulator;

置き換えて`YOURUSER`あなたのユーザー名で。

@startuml
title XubuntuメニューへのKittyの統合プロセス
start
:Copier .desktop;
:Editer les chemins;
:Sauvegarder;
:Menu Applications;
stop
@enduml

Kitty を既定のターミナルとして関連付ける (オプション)

Kitty がデフォルトのターミナルとして起動されるようにする :

sudo update-alternatives --install /usr/bin/x-terminal-emulator x-terminal-emulator ~/.local/kitty.app/bin/kitty 50
sudo update-alternatives --config x-terminal-emulator

選択して`kitty`提案されたメニューに。

Zshのインストール

Zsh がまだインストールされていない場合は、実行してください :

sudo apt install zsh

インストールを確認してください：

zsh --version

Zshをデフォルトのシェルとして設定

シェルをグローバルに変更するか、Kitty内だけで変更することができます。

グローバルメソッド (すべての端末向け)

絶対パスを特定してください：

which zsh

一般的に`/usr/bin/zsh`。

デフォルトのシェルを変更：

chsh -s /usr/bin/zsh

ログアウトして、もう一度ログインしてください。

@startuml
title シェルのグローバルな変更
actor User

User --> Bash : Session actuelle
User --> System : chsh -s /usr/bin/zsh
System --> "/etc/passwd" : Modifie le shell
note right of "/etc/passwd" : Shell par défaut mis à jour
@enduml

Kitty専用のメソッド

Kitty のシェルだけを変更したい場合は、設定ファイルを編集してください :

nano ~/.config/kitty/kitty.conf

この行を追加してください:

shell zsh

Kittyを保存して再起動してください。

Zshの設定（オプション）

Zshをカスタマイズする：

.zshrc ファイルを作成する

touch ~/.zshrc
nano ~/.zshrc

最小構成の例

export ZSH_THEME="robbyrussell"
export PATH="$HOME/.local/bin:$PATH"
alias ll="ls -la"

ワークフロー全体のサマリー

以下の図は、プロセス全体をまとめています：

最終確認

キティを起動してください：

kitty

あなたはそれが見えるはずです`zsh`アクティブです :

echo $SHELL

期待される結果：

/usr/bin/zsh

フォントサイズを変更するキティ, パラメータを調整する必要があります`font_size`設定ファイル内で。以下は詳細な手順です。

�📂 設定ファイルを開く

メインの構成ファイルは通常、次の場所にあります：

~/.config/kitty/kitty.conf

このファイルがまだ存在しない場合は、作成することができます。 例 :

nano ~/.config/kitty/kitty.conf

�🖋️ 追加または変更 `font_size

次のディレクティブを追加し、すでに存在している場合はそれを変更してください：

font_size 14.0

ここ`14.0`希望のサイズに対応します。小数値であれば任意の値を入力できます。たとえば`12.0`, 15.5, など

💾 保存して Kitty を再起動

  • 保存 (Ctrl + O、そして`Entrée`)そして離れて(Ctrl + X) あなたが使っている場合`nano`.

  • Kitty のすべてのウィンドウを閉じ、ターミナルを再起動して変更を反映させてください。

✅ 動的調整 (一時ズーム)

一時的にズームイン/ズームアウトしたいが設定を変更しない場合は、デフォルトのキーボードショートカットを使用してください：

  • フォントサイズを増やす :

Ctrl + Shift + =

  • フォントサイズを小さくする:

Ctrl + Shift + -

  • サイズをリセット：

Ctrl + Shift + Backspace

これらの設定は端末を閉じた後も保持されません。

Oh My Zshのインストールと設定

Zshがインストールされ、デフォルトシェルとして設定された後、*Oh My Zsh*で環境を豊かにすることができます。Zshの構成管理フレームワークである*Oh My Zsh*は、以下を提供します：

  • プロンプト用のテーマのコレクション,

  • 多数のプラグイン,

  • 設定の明確な組織

Oh My Zshのインストール

Zsh がアクティブであることを確認してください：

zsh --version

必要なら、起動してください：

zsh

その後、公式インストールスクリプトをダウンロードして実行してください：

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

このスクリプト：

  • フォルダーを作成して`~/.oh-my-zsh`,

  • ファイルを保存する場合があります`~/.zshrc`,

  • 自動的に新しいプロンプトをアクティベートします。

テーマを変更する

設定ファイルを開いてください：

nano ~/.zshrc

変数を変更してください`ZSH_THEME`別のテーマを選択するために（例えば`agnoster`) :

ZSH_THEME="agnoster

設定を保存し、再読み込みしてください：

source ~/.zshrc

�検証

Kitty を起動して、プロンプトが確かに変わったことを確認してください。 次のコマンドを実行して、Oh My Zsh がアクティブであることを確認できます：

echo $ZSH

結果は次のように似ているはずです：

/home/あなたのユーザー/.oh-my-zsh

Kitty で透明性を有効にする

Kittyの最も気に入られた機能の1つは、ターミナルの背景に*透明性*を追加できることです。これにより、基盤となる環境（ウィンドウ、デスクトップなど）をわずかに見ることができ、これはマルチタスク時に特に役立ちます。

透明性のための前提条件

Kittyにおける透明性はウィンドウコンポーザーグラフィカル環境によって使用される。 Xubuntu (XFCEベース)では、次のことを確認してください：構成が有効になっています。

確認 :

  • 右クリック > デスクトップ > 設定 >ウィンドウマネージャーの設定,

  • タブ作曲家: 「"コンポジットを有効にする"」チェックボックスはチェックされている必要があります。

@startuml
title Use Case - Kitty で透明度を有効にする
actor Utilisateur

rectangle "グラフィカル環境 (XFCE/Xubuntu)" {
  usecase "合成を有効にする" as UC1
}

rectangle "Kittyターミナル" {
  usecase "kitty.conf で透明度を設定する" as UC2
}

@enduml

kitty.conf での透明度の設定

設定ファイルを開いてください`~/.config/kitty/kitty.conf`:

nano ~/.config/kitty/kitty.conf

次の行を追加または変更してください：

background_opacity 0.85

このパラメータは、次の範囲の値を受け付けます：

  • 1.0→ 不透明（透明性なし），

  • 0.0→ 完全に 透明 （使用できない），

  • 中間値のような`0.90`, 0.75, など

良いビジュアルな妥協点は通常、0.85 et 0.95。

Kitty を再起動

Kittyのすべてのインスタンスを閉じ、変更が反映されるように新しいウィンドウを再起動してください。

kitty

可能な補足

カスタム端末の背景を使用している場合、背景色に透明度を設定することもできます（RGBA）：

background #1e1e2eff

最後のコンポーネント(ff) 示す 不透明度 (で`00` à ff).

既知の制限

透明度が機能しない場合は： - XFCE コンポジタは無効になっています、 - 互換性のないウィンドウマネージャが使用されています, - あなたはKittyをバックグラウンドで透明度サポートなしの*tmux*モードで使用しています。

ビープ音（audible bell）を無効にする

デフォルトでは、Kitty は間違ったコマンドが入力されたときや、ターミナル イベントがトリガーされたときに bip 音を鳴らします。この音はすぐに鬱陶しくなることがあります、特に激しい開発環境では。

この動作を無効にするには、ファイルに次のディレクティブを追加してください。~/.config/kitty/kitty.conf(Note: Since there is no French source text provided, the translation is empty.)

audible_bell no

ビープ音の代わりに、*ビジュアルフィードバック*も有効にできます :

visual_bell yes

Kittyのアップデート

Kittyがスクリプトでインストールされ、パッケージマネージャーではないため、アップデートは公式インストールスクリプトを再実行することで行われます。これにより、最新バージョンをダウンロードし、既存のインストールをアップデートすることができますで`~/.local/kitty.app`.

接尾辞`.app`道の中`~/.local/kitty.app`これは、KittyのLinuxへの公式スクリプトによるインストールの慣習であり、macOSとの独占的な互換性を示すものではありません。

アップデートコマンドを実行する前に、ホームディレクトリにいることを確認してください。 (~)

以下のコマンドをホームディレクトリから実行してください。

curl -L https://sw.kovidgoyal.net/kitty/installer.sh | sh /dev/stdin

このスクリプトは次のように処理します：

  • 新しいバージョンのバイナリをダウンロード

  • ファイルを抽出する`~/.local/kitty.app`。

  • 必要に応じてシンボリックリンクを更新してください。

アップデート後は、すべての Kitty インスタンスを閉じてから再起動することをお勧めします。これにより、新しいバージョンが正しく反映されることを確認できます。
