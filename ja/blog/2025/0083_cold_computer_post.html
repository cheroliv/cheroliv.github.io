Ubuntuでノートパソコンが異常に熱くなっていると感じますか？ この記事は、あなたにアプローチを提案しますソフトウェアのための完全な冷却する, 監視する et 温度を制御するあなたの機械の。

このガイドの目的

  • コンピュータの全体温度を下げる

  • エネルギー管理を最適化する

  • クリティカルなコンポーネント（CPU、GPUなど）を監視する

  • 発生する遅延を避けるサーマルスロットリング

@startuml
start
:Installer les outils;
:Analyser les capteurs;
:Appliquer des réglages;
note right: cpufreq, tlp, auto-cpufreq
:Surveiller en temps réel;
stop
@enduml

前提条件

  • Ubuntuマシン (20.04以上推奨)

  • インターネット接続

  • コマンドラインスキル(初級～中級レベル)

ツールをインストールして設定する

lm-sensors` を使ってセンサーを検出する

sudo apt install lm-sensors
sudo sensors-detect
sensors

答えてください`YES`すべての質問に関する`sensors-detect`モジュールを検出するために。

tlp` : インテリジェントなエネルギー管理者

sudo apt install tlp tlp-rdw
sudo systemctl enable tlp
sudo systemctl start tlp
@startuml
(*) --> "TLP はアクティブですか？"
if "はい" then
  --> [yes] "消費削減"
  --> "CPUの周波数制限"
else
  --> [no] "TLP の起動"
  --> "自動アクティベーション"
endif
-->(*)
@enduml

cpufrequtils` : CPUの周波数を制限する

sudo apt install cpufrequtils
cpufreq-info
sudo cpufreq-set -g powersave

  • powersave: 周波数のピークを制限します

  • performance: 電力を優先し、温度を犠牲にする

auto-cpufreq` : 簡素化された動的管理

git clone https://github.com/AdnanHodzic/auto-cpufreq.git
cd auto-cpufreq
sudo ./auto-cpufreq-installer
sudo auto-cpufreq --install
@startuml
start
:Analyse charge système;
:Réglage fréquence CPU;
:Vérification température;
:Adaptation dynamique;
stop
@enduml

thermald` : 自動熱保護

sudo apt install thermald
sudo systemctl enable thermald
sudo systemctl start thermald

リアルタイム監視

sensors` コマンドラインで

watch -n 2 sensors

オプション GUI : `psensor

sudo apt install psensor

シンプルなグラフィカルインターフェース CPU、GPU、ファン用。

追加のコツ

  • タブと重いアプリケーション（例: ブラウザ）を閉じる

  • バッテリーでの過度な使用を避ける

  • プロセスを介して監視`htop`:

sudo apt install htop
htop

システムをクリーンアップしてオーバーロードを制限する

sudo apt autoremove
sudo apt autoclean
sudo journalctl --vacuum-time=3d
