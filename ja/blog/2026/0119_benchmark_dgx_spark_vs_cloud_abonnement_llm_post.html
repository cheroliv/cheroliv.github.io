読了時間：14 minutes

NVIDIAはDGX Sparkを4,699ドルの「デスクトップAIスーパーコンピューター」として販売しています。Ollamaはクラウドモデルを月額20ドルで提供しています。Vast.aiではH100が1時間1.38ドルでレンタル可能です。そして、DeepSeek、Qwen、GLMといった中国のオープンソースモデルは、カードを購入することなく、どこでも無料で利用できます。では、このSparkは一体何に役立つのでしょうか？計算してみました。

コンテキスト：転換した市場

2026年5月、AIの状況はCES 2025でのDGX Sparkの発表時から激変していました。3つの力が収束し、ローカルハードウェアを正当化することがますます困難になっていました。

  • GPUクラウド価格の暴落：H100のレンタル料金は、18ヶ月前の1時間あたり$5-8に対し、現在は$1.38から$3の間となっています。

  • 中国製オープンソースモデルの急増: DeepSeek-V4、Qwen-3、GLM-5は欧米のモデルに匹敵し、無料で利用可能です

  • マネージド推論プラットフォームの台頭: Ollama、Groq、Together AIは、寛容な無料枠を設けた競争力のある価格帯でAPIを提供しています

2,999ドルで発表され、後に4,699ドルに値上がりしたDGX Sparkは、もはやそれを必要としない世界に登場することになります。

CUDAではなく、MLXエコシステム

記載されているクラウドGPU価格は、2026年5月時点のVast.aiおよびRunPodのものです。これらはスポット/オンデマンド価格であり、予約済み価格ではありません。ハイパースケーラー（AWS、GCP、Azure）の価格は、依然として2〜3倍高くなっています。

除外したもの（およびその理由）

このベンチマークから、以下のオプションを意図的に除外しました：

  • OpenAI / Anthropic / Google API：ここでの目的は、自由に選択し、ファインチューニング可能なオープンソースモデルを動作させ、単一のベンダーに依存しないようにすることです。

  • Huawei Ascend / Atlas : HuaweiはDGX Sparkに相当するデスクトップ製品を販売していません。Ascend（910C, 910D）およびAtlas（300I Duo, 350）シリーズはデータセンター向け（PCIeカード、ラックサーバー）であり、プラグアンドプレイ可能なコンパクト筐体ではありません。Ascend 910Cチップは128 Go HBMを搭載していますが、これはサーバー用チップであり、独立したシステムではありません。Atlas 300I Duoは~$1 400で96 Goを提供しますが、ホストマシンが必要です。

単純推論：ローカルハードウェアの終焉

最も一般的なユースケースから始めましょう。LLMとのチャット、コードレビュー、テキスト生成などです。ファインチューニングやバッチ処理は行わず、単にインタラクティブな推論を行うだけです。

ヘビーユースであっても

クラウドにおける最悪のシナリオを考えてみましょう。H100を1日8時間、週5日、年間52週間稼働させる場合です。

  • 8 × 5 × 52 = 2 080 時間/年

  • 2 080 × $2/h (H100スポット平均価格) =年4,160ドル

Spark ($4,699)の投資回収期間は13ヶ月。ただし：

  1. H100は約10倍高速SparkのGB10よりも。Sparkが10時間かけて行うことを、あなたは1時間で完了させます。同じ作業量に対して、H100のコストは4,160ドルではなく、年間416ドルになります。

  2. Le H100 a 80 Go HBM à 3.35 To/s de bande passante. Le Spark a 128 Go LPDDR5X à 273 Go/s. Pour les gros modèles, la bande passante compte plus que la capacité.

H100の1時間とSparkの1時間を比較することに意味はありません。H100は10倍速く処理を行います。したがって、特定のワークロードにおける実際のクラウドコストは、時間ベースの単純な計算よりも約10倍低くなります。

ファインチューニング：クラウドは無敵である

Spark支持者的经典论点是：“没错，但对于`fine-tuning`来说，情况就不同了”。

いいえ、そうではありません。

ファインチューニングの真のコスト

Unslothを用いた7BモデルのLoRA/QLoRAファインチューニング：

  • H100で約2-3時間 =5ドルから9ドル

  • Sparkでも同様です =20-30時間（10倍低速）になり、マシンがフリーズします

Sparkの4,699ドルで、以下を賄うことができます：

  • 500から900のファインチューニングクラウドH100で

  • Ou 約23歳Ollama Proの

  • Ou 約4年Ollama Max の

そして、より大きなモデル（70B+）の場合：

  • Le Spark avec ses 128 Go peut charger un 70B en Q4 — mais le fine-tune sera extrêmement lent

  • Un H100 avec 80 Go peut fine-tuner un 70B en QLoRA 4-bit en quelques heures

  • フルファインチューニングを行うには、どのみちマルチGPUが必要です。Sparkでは不可能です。

専門事業者

2026年、Unsloth、Modal、Replicate、Together AIなどのプラットフォームがサーバーレスなファインチューニングを提供しています：

  • GPU管理なし

  • 環境設定は不要です

  • 分単位の支払い

  • 組み込みの最適化（flash attention、自動量子化）

唯一の真の理由：データ主権

推論、ファインチューニング、そしてコストパフォーマンスを排除した後、Sparkに何が残るでしょうか？

絶対的な機密性。

「OpenAIの従業員にプロンプトを読まれたくない」といったプライバシーの問題ではありません。それは2026年においては偽の問題です。Ollama、Groq、そしてほとんどの信頼できるプロバイダーは、ゼロログおよびゼロリテンションのポリシーを採用しています。

真のプライバシーとは、次のことです：

  • 規制上のエアギャップ：国防、外交、保健 — データが*物理的に*建物から外に出ることはありません

  • 機密プロプライエタリデータ：未公開製品のソースコード、産業機密、トレーディングアルゴリズム

  • ネットワークレジリエンス：インターネットが切断されても、AIは動作し続けなければなりません

ですが、正直に言いましょう。DGX Sparkの購入者のうち、実際にそのような状況にあるのは何パーセントでしょうか？1%でしょうか？残りは、「nice to have（あれば便利）」な機能が4,699ドルの出費に変わっただけのことです。

真のプライバシー計算

個人利用の場合：

  • Ollama Pro($20/月) + 中国のオープンソースモデル = 実用的ソリューション

  • もしプロンプトがOllamaから漏れたとしても、日々の数百万件ものリクエストの中に埋もれてしまいます。それは大海の一滴にすぎません。

  • 本当のリスクはプロンプトの流出ではなく、同意のないデータによる学習です。そして、信頼できるプロバイダーはそれを契約で禁止しています。

特例：中国製モデルに直面するプロプラン

一点強調しておくべきことがあります。それは、組み合わせです。月額20ドルのOllama Pro + 中国のオープンソースモデルは、おそらくコンシューマー向けAI史上最高のコストパフォーマンスです。

中国製モデルがすべてを変える理由

  • DeepSeek-V4-Pro: 1.6Tパラメータ、CSA+HCA、1Mコンテキスト、コードにおいてClaude 4およびGPT-5と同等

  • Qwen-3: 235B、256Kコンテキスト、フランス語と推論に優れている

  • GLM-5.1: 744B、MLA+DSA、200Kコンテキスト、エージェント向けに最適化

すべてOllamaで利用可能です。すべてオープンソース（寛容なライセンス）です。月額20ドルのサブスクリプションを介して、制限なくすべて利用可能です。

Ollama Proを利用すれば、クローズドモデル（Claude Pro）1つ分の価格で、約5つのオープンソースの「フロンティア」モデルにアクセスできます。この価値の非対称性は、ほとんど不条理なほどです。

ハードウェアにとってそれが何を意味するか

最高のコストパフォーマンスが月額20ドルのクラウドサブスクリプションであるならば、ローカルハードウェアを選択することは「快適さ」や「信念」による選択であり、経済的な選択ではありません。

4,699ドルのDGX Sparkは、以下と同等です：

  • Ollama Pro 235ヶ月分

  • 発売日のAAAゲーム23作品

  • 4 MacBook Air M4

  • リヨンにあるT2（1LDK）の1年分の家賃

計算用。低速。

Huaweiはどうでしょうか？

研究中にその質問を受けたのでお答えします。いいえ、HuaweiはDGX Sparkに相当する製品を販売していません。

既存のもの：

  • Ascend 910C : 128 Go HBM, 800 TFLOPS FP16 — ただし、これはサーバー用チップであり、デスクトップ用ではない

  • Atlas 300I Duo : 96 Go LPDDR4X, ~$1 400 の PCIe カード — ホストが必要

  • Atlas 350 : 112 Go HBM, 1.56 PFLOPS FP4 — データセンター用アクセラレータであり、コンパクトケースではない

Huaweiはサーバーおよびデータセンター市場に集中し続けています。120+ Go の VRAM を搭載した「プラグアンドプレイ」のコンパクトケースとしては、2026年時点で DGX Spark (128 Go ユニファイド) と Mac Studio M3 Ultra (192 Go ユニファイド) が唯一の選択肢です。そして現時点では、中国のメーカーでこのフォーマットの同等製品を発表したところはありません。

DGX Sparkは悪い製品ではありません。しかし、潜在的な買い手の99%にとって、それは悪い投資です。
